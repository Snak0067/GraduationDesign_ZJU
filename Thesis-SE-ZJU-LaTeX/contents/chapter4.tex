\chapter{结合强化学习微调的图推理技术}

尽管前文已在图结构序列化编码与跨模态对齐层面做出了改进，
并构建了图结构大模型，
但模型仍在复杂图推理任务上存在两类共性瓶颈：
其一，监督微调对高质量标注有依赖，模型易形成任务与数据集相关的启发式捷径，
难以学到本质的可迁移的结构化推理规律；
其二，真实图任务标注成本高、形态相对有限，缺少可规模化、可自动验证的训练信号，
从而制约模型图算法能力提升。

为此，本章在既有图结构大模型之上引入可验证奖励驱动的后训练技术，
在不尽量增加人工成本的前提下，通过监督冷启动和强化学习微调的两阶段训练，
促使模型在生成推理链与答案时更好地满足图论规则与任务约束。
本章目标是将图结构大模型从以判别式预测为主的能力形态，
拓展为具备更强可验证性与跨任务泛化能力的生成式图推理技术，
并在后续实验中评估该技术在图推理基准与真实图任务上的综合收益。


\section{概述}

本章在第~3~章图结构大模型之上，聚焦图推理能力的强化学习式后训练。
核心目标是学习条件生成策略 $\pi_\theta$，
使模型在给定图结构条件与自然语言查询的情况下，
能够生成可解释的推理链与最终答案，并使输出可被外部规则稳定校验。


\textbf{输入：}
给定图 $G=(V,E,\mathcal{T})$，
其中 $V$ 为节点集合、$E$ 为边集合，
$\mathcal{T}=\{t_i\}_{i=1}^{|V|}$ 为节点文本属性集合（合成图论任务中可为空）；
给定自然语言查询 $q$（例如最短路径查询、连通性判定等）。
在模型侧，图 $G$ 经由第~2~章欧拉路径编码得到结构序列表示，
并由图编码器 $\mathrm{Enc}_G$ 提取图侧条件特征，
再经跨模态投影层 $f_{\mathrm{proj}}:\mathbb{R}^{d_g}\!\to\!\mathbb{R}^{d_\ell}$
对齐至语言模型隐空间，作为解码器 $\mathrm{Dec}_T$ 的条件输入。
本章默认冻结图侧模块（$\mathrm{Enc}_G$ 与 $f_{\mathrm{proj}}$），
仅更新解码端策略参数 $\theta$。

\textbf{输出：}
模型输出序列 $y=(c,a)$，
其中 $c=(c_1,c_2,\dots,c_{L_c})$ 为链式推理过程，
每一步 $c_\ell$ 对应一次图结构分析或逻辑推导的自然语言描述；
$a$ 为最终答案，其形式随任务类型变化（数值、节点/边集合或布尔值等）。
训练与评测阶段，输出需满足查询约束与图论规则，
并可通过图算法验证器对答案及关键结构约束进行自动校验。

围绕上述目标，本章内容组织如下。

第~4.2~节给出面向图推理的后训练总体框架，
明确策略生成与优化目标的定义。

第~4.3~节介绍思维链监督的冷启动微调过程，
包括合成数据的构建与训练建模。

第~4.4~节进一步给出规则化可验证奖励的设计与实现，
并说明基于可验证奖励的 GRPO 强化学习训练流程与关键超参数配置。

第~4.5~节给出实验设置与结果分析，
从图推理基准与真实图任务迁移两个维度评估所提出方法的性能增益与泛化表现。

第~4.6~节对本章工作进行总结。


\section{基于GRPO的强化学习框架}
\label{subsec:grpo_objective}

本节设计了一种面向图推理任务的可验证强化学习微调框架。
针对PPO等传统强化学习在复杂推理任务中价值网络
训练困难且显存开销大的问题，
本文采用群组相对策略优化（Group Relative Policy Optimization, GRPO）
\cite{Shao2024DeepSeekMathPT}。
如\autoref{fig:overview_rl_framework} 所示，
该框架建立了一个从采样评估到优化更新的闭环训练：
模型在给定图结构与问题条件下生成一组候选推理轨迹，
并通过复合的可验证奖励函数对每条轨迹计算组内相对奖励，
从而构造优势信号并执行策略更新。

\begin{figure}[htbp]
    \centering
    \includegraphics[width=1\textwidth]{4_chapter/基于GRPO的强化学习微调整体框架图.pdf}
    \caption{基于GRPO的强化学习框架总体流程图}
    \label{fig:overview_rl_framework}
\end{figure}

整体训练流程如算法~\ref{alg:grpo_graph_reasoning}所示。
具体而言，
每轮迭代首先将当前策略参数 $\theta$ 复制并冻结为旧策略参数 $\theta_{\mathrm{old}}$，
并以 $\pi_{\theta_{\mathrm{old}}}$ 作为本轮采样的行为策略生成候选轨迹；
随后基于可验证奖励构造优势信号，并在同一批轨迹上仅执行一次参数更新（$K=1$），
以保持采样分布与更新分布的近似一致性，从而提高训练稳定性。

\begin{algorithm}[t]
\caption{基于 GRPO 的图推理强化学习训练流程}
\label{alg:grpo_graph_reasoning}
\KwIn{
冷启动后策略参数 $\theta_{\mathrm{CoT}}^\ast$；
RL 训练任务集 $\mathcal{D}_{\mathrm{RL}}$；
组大小 $M$；
批次大小 $B$；
裁剪阈值 $\varepsilon_{\mathrm{clip}}$；
KL 系数 $\beta$；
最大训练步数 $T_{\max}$；
评测间隔 $T_{\mathrm{eval}}$
}
\KwOut{强化学习后的策略参数 $\theta_{\mathrm{RL}}^\ast$}

初始化当前策略 $\theta \gets \theta_{\mathrm{CoT}}^\ast$，冻结参考策略 $\pi_{\mathrm{ref}} \gets \pi_{\theta_{\mathrm{CoT}}^\ast}$\;

\For{$t \gets 1$ \KwTo $T_{\max}$}{
  $\theta_{\mathrm{old}} \gets \theta$\;

  从 $\mathcal{D}_{\mathrm{RL}}$ 中采样 $\{(G_i,q_i)\}_{i=1}^{B}$\;

  \For{$i \gets 1$ \KwTo $B$}{
    构造条件输入 $x_i$（系统/任务提示 + 图结构条件 + 查询 $q_i$）\;
    \For{$m \gets 1$ \KwTo $M$}{
      采样轨迹 $y_i^{(m)} \sim \pi_{\theta_{\mathrm{old}}}(\cdot \mid x_i)$\;
      调用验证器计算奖励 $r_i^{(m)} \gets \mathcal{R}(G_i,q_i,y_i^{(m)})$\;
    }
    由 $\{r_i^{(m)}\}_{m=1}^{M}$ 计算组内均值与方差，得到优势 $A_i^{(m)}$\;
  }

  计算 $\mathcal{L}_{\mathrm{GRPO}}(\theta)$\;
  计算梯度 $g \gets \nabla_{\theta}\mathcal{L}_{\mathrm{GRPO}}$，并进行梯度裁剪 $\|g\|_2 \le 1.0$\;
  使用 AdamW 更新策略参数 $\theta$\;

  \If{$t \bmod T_{\mathrm{eval}} = 0$}{
    在验证集上评估平均奖励、答案正确率与 KL 漂移并保存最佳检查点\;
  }
}
\Return{$\theta_{\mathrm{RL}}^\ast \gets \theta$}\;
\end{algorithm}


\textbf{1) 组内采样与相对优势估计。}
对第 $i$ 个样本，GRPO 从旧策略 $\pi_{\theta_{\mathrm{old}}}$ 
在同一条件输入 $x_i$ 上采样 $M$ 条候选轨迹，如式~\ref{eq:grpo_sample}\ 所示：
\begin{equation}
  y_i^{(m)} \sim \pi_{\theta_{\mathrm{old}}}(\cdot \mid x_i), \quad m=1,\dots,M.
  \label{eq:grpo_sample}
\end{equation}
每条轨迹通过规则验证器获得可验证奖励 $r_i^{(m)}=\mathcal{R}(G_i,q_i,y_i^{(m)})$，
其中 $\mathcal{R}$ 的组成与计算见式~\ref{eq:reward_function}。
随后在组内标准化得到相对优势，如式~\ref{eq:grpo_adv}\ 所示：
\begin{equation}
  A_i^{(m)}=
  \frac{r_i^{(m)}-\mu_i}{\sigma_i+\epsilon}, \quad
  \mu_i=\frac{1}{M}\sum_{m=1}^{M}r_i^{(m)}, \quad
  \sigma_i=\sqrt{\frac{1}{M}\sum_{m=1}^{M}\big(r_i^{(m)}-\mu_i\big)^2}.
  \label{eq:grpo_adv}
\end{equation}
其中 $\epsilon=10^{-8}$ 为数值稳定项。该优势估计仅依赖同一输入下的相对奖励排序，从而降低不同问题难度与奖励尺度差异带来的方差。

\textbf{2) 裁剪式策略目标。}
记新策略与旧策略在轨迹 $y_i^{(m)}$ 上的序列级概率分别为
$\pi_{\theta}(y_i^{(m)}\mid x_i)$ 与 $\pi_{\theta_{\mathrm{old}}}(y_i^{(m)}\mid x_i)$，
定义重要性比率，如式~\ref{eq:grpo_ratio}\ 所示：
\begin{equation}
  \rho_i^{(m)}(\theta)=
  \frac{\pi_{\theta}(y_i^{(m)}\mid x_i)}{\pi_{\theta_{\mathrm{old}}}(y_i^{(m)}\mid x_i)}
  =
  \exp\!\Big(
    \log \pi_{\theta}(y_i^{(m)}\mid x_i)
    -
    \log \pi_{\theta_{\mathrm{old}}}(y_i^{(m)}\mid x_i)
  \Big).
  \label{eq:grpo_ratio}
\end{equation}
其中新策略的序列级对数概率由 token 级自回归概率累积得到，
如式~\ref{eq:seq_logprob}\ 所示：
\begin{equation}
  \log \pi_{\theta}(y_i^{(m)}\mid x_i)=\sum_t \log p_{\theta}\!\left(y_{i,t}^{(m)}\mid x_i, y_{i,<t}^{(m)}\right).
  \label{eq:seq_logprob}
\end{equation}
基于 PPO 的裁剪思想，GRPO 的策略损失定义如式~\ref{eq:grpo_policy_loss}\ 所示：
\begin{equation}
  \mathcal{L}^{\mathrm{policy}}(\theta)=
  -\frac{1}{B}\sum_{i=1}^{B}\frac{1}{M}\sum_{m=1}^{M}
  \min\!\Big(
    \rho_i^{(m)}(\theta)A_i^{(m)},
    \mathrm{clip}\big(\rho_i^{(m)}(\theta),1-\varepsilon_{\mathrm{clip}},1+\varepsilon_{\mathrm{clip}}\big)A_i^{(m)}
  \Big).
  \label{eq:grpo_policy_loss}
\end{equation}
该目标鼓励提升高优势轨迹的概率，同时通过裁剪抑制过大更新，从而稳定训练。

\textbf{3) 参考策略 KL 锚定。}
为抑制强化学习阶段的策略漂移，并保持 CoT-SFT 阶段形成的输出分布与推理格式，
将 $\pi_{\mathrm{ref}}=\pi_{\theta_{\mathrm{CoT}}^\ast}$ 
作为冻结参考策略并加入 KL 正则项。
采用基于采样轨迹的 token 级近似，如式~\ref{eq:grpo_kl}\ 所示：
\begin{equation}
  \mathcal{L}^{\mathrm{KL}}(\theta)=
  \frac{\beta}{B}\sum_{i=1}^{B}\frac{1}{M}\sum_{m=1}^{M}
  \sum_t \Big(
    \log p_{\theta}(y_{i,t}^{(m)}\mid x_i,y_{i,<t}^{(m)})
    -
    \log p_{\mathrm{ref}}(y_{i,t}^{(m)}\mid x_i,y_{i,<t}^{(m)})
  \Big).
  \label{eq:grpo_kl}
\end{equation}


\textbf{4) 总目标与参数更新范围。}
综合上述各项，基于GRPO的强化学习框架的整体训练目标如式~\ref{eq:grpo_obj}\ 所示：
\begin{equation}
  \mathcal{L}_{\mathrm{GRPO}}(\theta)=
  \mathcal{L}^{\mathrm{policy}}(\theta)+\mathcal{L}^{\mathrm{KL}}(\theta)+\mathcal{L}^{\mathrm{ent}}(\theta).
  \label{eq:grpo_obj}
\end{equation}
在参数层面，图结构编码器 $\mathrm{Enc}_G$、文本编码器 $\mathrm{Enc}_T$ 与
跨模态投影头\(f_G\)和\(f_T\)在 RL 阶段保持冻结，
仅更新语言模型解码器 $\mathrm{Dec}_T$ 及其LoRA适配层，
从而在保持跨模态对齐能力稳定的前提下对推理策略进行可控优化。


\section{基于思维链监督的冷启动微调}
\label{sec:cot_sft}
在强化学习驱动的图推理能力增强流程中，
初始策略的质量直接决定了后续 RL 训练的样本效率与最终性能上限。
直接对原始图模型开展 RL 训练，
易因初始推理策略的随机性与不规范性导致奖励信号稀疏、
训练过程震荡，甚至出现策略退化。

因此，本文借鉴 DeepSeek-R1\cite{DeepSeekAI2025DeepSeekR1IR} 的冷启动方法
与 G1\cite{Guo2025G1TL}  的思维链监督微调（CoT-SFT）方案， 
先通过图推理导向的监督式冷启动微调，
为模型注入结构化的图推理先验，
使其生成的推理链满足图论规则约束、具备可追溯的逻辑链条。
本阶段的核心目标是：在固定图结构编码器与跨模态对齐模块的前提下，
仅优化语言模型解码器参数，通过精细化的数据集构造与训练策略，
确保微调后模型兼具推理逻辑性与语言流畅性，为后续 RL 阶段奠定稳定且高性能的初始策略。
\subsection{思维链合成数据集构建}
\label{subsec:cot_dataset}

高质量监督数据是冷启动微调的关键前提。
本文构建图推理思维链数据集 $\mathcal{D}_{\text{CoT}}$，
同时覆盖两类来源：一类为可精确求解的合成图论任务，另一类为真实文本属性图上的结构推理任务。
数据标注采用教师模型生成候选序列，规则验证器进行可验证过滤，人工抽检进行语义质控。
整体构建流程如图~\ref{fig:cot_dataset_construction}\ 所示。

\subsubsection{样本定义与总体构建思路}
\label{subsubsec:cot_overview}

对每个图推理实例，记图为 $G$，欧拉路径结构编码为 $s=\Phi(G)$，自然语言查询为 $q$。
利用可精确实现的图算法得到真值答案 $a^\star$，并以教师模型生成自然语言推理链 $c^\star$。
最终每条监督样本统一为三元组 $(G,q,y^\star)$，其中 $y^\star=(c^\star,a^\star)$。

合成任务用于提供大规模、可控难度且可严格验证的监督信号，
真实任务用于提升模型在真实图分布与文本语义条件下的迁移能力。
两类样本在输入形式上保持一致，均以 $s=\Phi(G)$ 表示结构信息，从而保证训练接口统一。

\subsubsection{合成图论任务数据集构建}
\label{subsubsec:synth_tasks}

本文在现有基准数据集基础上，
补充构建了一套中等规模的合成图论任务数据集，
用于提供可规模化且可精确验证的冷启动思维链监督信号。
形式化地，记第 $t$ 类任务对应的参数化分布为 $\mathcal{G}_t$。
对每类任务采样 $N_t=200$ 个图实例 $G\sim\mathcal{G}_t$。
在图生成过程中，本文首先从Network Repository\cite{Rossi2015TheND} 等
若干真实大图中选取种子图，
随后在种子图上采用带重启的随机游走策略下采样连通子图，
并将子图规模约束在 $5$ 到 $35$ 个节点，以适配上下文窗口。
对每个子图按第~\ref{sec:graph2token}\ 节进行半欧拉序列化，
得到 $s=\Phi(G)$。

针对每类任务设计多种中文查询模板，
将任务类型、目标节点或节点集合以及必要的约束条件参数化注入模板中，
从而生成形式统一但实例多样的查询 \(q\)
（例如“请给出图中节点 1 到节点 5 的最短路径并说明理由”、
“请判断该图是否为欧拉图并说明原因”等）。
并对同一任务实例采样 $M=4$ 个模板
以减少模型对固定措辞的依赖并提升泛化能力。
随后调用NetworkX\cite{Rossi2015TheND}  等图算法库计算真值答案 $a^\star$，
从而得到合成任务实例池，其形式如式~\ref{eq:generate_dataset50k}\ 所示。
\begin{equation}
\mathcal{D}_{\text{synth}}^{(0)}
=
\Big\{
\big(G_i,q_i,s_i,a_i^\star\big)
\Big\}_{i=1}^{N_{\text{synth}}},
\quad
N_{\text{synth}}=\sum_{t} N_t\cdot M.
\label{eq:generate_dataset50k}
\end{equation}


参考 G1 \cite{Guo2025G1TL}中对任务难度的划分，
本文在自建数据集中对 50 类任务进行难度标注，
并在样本构建时保持与其近似的任务占比结构，具体如下：
\begin{enumerate}
  \item \textit{Easy 级任务}（约占全部任务类型的 $29.18\%$）：
  主要涵盖基础图属性与线性时间复杂度任务，例如节点计数、边计数、
  度数与平均度数计算、邻居查询、广度/深度优先遍历、是否存在环、
  最小生成树、边存在性与正则性判断等。
  这些任务主要考察模型对局部结构与基本图概念的掌握。

  \item \textit{Medium 级任务}（约占 $22.91\%$）：
  包括多项式时间复杂度、需要综合局部结构信息的任务，例如聚类系数与连通分量数计算、
  二分图最大匹配与最小边覆盖、局部连通性与资源分配指数、
  Jaccard 系数、是否欧拉图与是否二分图判定以及度中心性等。
  此类任务要求模型在多个局部结构之间进行多跳推理，
  对图结构表征和组合能力提出中等强度要求。

  \item \textit{Hard 级任务}（约占 $33.33\%$）：
  涉及更为复杂的图算法与全局结构度量，例如最短路径、
  多种中心性指标、图直径与半径、
  图中心与周边节点、三角形数量、平均邻居度以及桥边检测等。
  这些任务依赖于长程依赖建模和全局结构一致性，对图推理能力提出更高要求。

  \item \textit{Challenging 级任务}（约占 $14.58\%$）：
  主要覆盖 NP-hard 组合优化类问题及复杂全局指标，
  例如最大独立集、最小顶点覆盖、最大流、Wiener 指数、哈密顿路径判定以及图同构映射等。
  这一等级在计算复杂性上最为困难，用于测评模型在极端难度下的推理上限。
\end{enumerate}

综上，本文在任务定义与难度分层上参考 G1\cite{Guo2025G1TL} 的设计，
但在图采样策略、查询模板、图到 Token 编码以及真值计算等环节完全重新实现，
构建了规模为 \(10\)k、覆盖 50 类图论任务的自建合成图推理数据集，
为后续思维链生成与强化学习训练提供了可控且结构多样的基础数据。

\subsubsection{真实文本属性图上的结构推理任务构建}
\label{subsubsec:real_tasks}

为提高模型在真实场景下的迁移能力，
本文进一步从 Cora、PubMed 与 OGB-Arxiv 等典型文本属性图构造真实图推理任务。
任务类型覆盖节点可达性判别、多跳邻居检索、局部结构模式匹配以及带语义约束的结构检索，
共构造约 $2{,}000$ 个实例。
具体构造方式如下。

{Cora 引文网络。}
构建基于引文结构的推理任务，
如"论文A引用链中第3跳的节点类别是什么？"、"节点B与C是否在5跳内可达？"等。
从Cora的2,708个节点中，使用ShaDowKHop采样策略获取局部子图，
确保每个样本包含完整的k-hop邻域信息，采集约 $500$ 个样本。

{PubMed 生物医学网络。}
设计语义驱动的结构检索任务，
如"给定疾病类型D，找出与其在3跳内相连且描述包含关键词K的所有论文节点"。
此类任务要求模型同时理解节点文本语义与结构关系，
采集约 $600$ 个样本。

{OGB-Arxiv 大规模学术图。}
构建子图同构判定任务，
如"目标子图（描述为H）是否与查询节点v的3-hop邻域同构？"，此类任务测试模型对局部结构模式的识别能力。从169K节点中随机选择800个中心节点，
对每个节点生成6种不同同构判定查询，采集约 $900$ 个样本。

所有真实任务样本同样进行欧拉路径编码并保留原始文本属性，
以保证与合成任务在输入格式上的一致性。在生成思维链标注之前，
本文将合成实例池与真实实例池按约 $4:1$ 的比例进行均衡重采样与去重，
得到待标注实例集合规模约 $1.5\times 10^4$。
经过后续规则过滤后，最终保留约 $1.0\times 10^4$ 条高置信样本作为冷启动监督数据。

\subsubsection{教师模型生成与规则验证的拒绝采样}
\label{subsubsec:rejection_cot}

为获得高质量思维链标注，
本文采用类似DeepSeek-R1\cite{DeepSeekAI2025DeepSeekR1IR}\ 的
拒绝采样策略生成 $y^\star$。

{教师模型与提示形式。}
选用 Qwen2.5-32B-Instruct\cite{Yang2024Qwen25TR}\ 作为教师模型 $\pi_{\text{teach}}$。
对每个实例，将结构编码 $s=\Phi(G)$ 与查询 $q$ 拼接为统一中文提示，要求先给出分步推理过程，再输出标准化最终答案。

\begin{prompt}{System Prompt}
你是一位图论专家，擅长通过结构化步骤解决图推理问题。请严格遵循以下流程：
1) 解析图结构；2) 逐步推导；3) 验证中间结果；4) 给出最终答案。
\end{prompt}

\begin{prompt}{Task Prompt}
图结构编码：$\langle s \rangle$。查询：$\langle q \rangle$。\\[0.3em]
推导过程需符合图论规则，每步推理必须基于图结构特征，
最终答案请用$\boxed{}$包起来。
\end{prompt}

{候选采样与清洗。}
对每个实例生成 $K=8$ 条候选序列 $\{y^{(k)}\}_{k=1}^{K}$，
其中 $y^{(k)}=(c^{(k)},a^{(k)})$。
采样参数设定为温度 $T=1.0$，top-$p=0.95$，
最大生成长度设为 $L_{\max}=3|V|$，以保证推理步骤充分。
对候选序列进行清洗，移除未闭合的 $\boxed{}$，截断重复循环片段，过滤包含虚构节点标识的明显幻觉输出。

{多维度规则验证器。}
本文针对不同任务类型设计验证器 $\mathcal{V}(G,q,y^{(k)})$，
先用硬规则剔除明显不合法候选，
再计算可验证奖励 $\mathcal{R}(G,q,y)$ 进行排序，
其中奖励函数定义见式~\ref{eq:reward_function}。

数值型任务通过解析 $a^{(k)}$ 得到 $\hat v^{(k)}$ 并与真值 $v^\star$ 比较，
支持分数与小数等价形式，浮点误差阈值设为 $\epsilon=10^{-6}$。

集合型任务解析生成集合 $\hat S^{(k)}$ 与真值集合 $S^\star$，
用 Jaccard 系数衡量一致性，其定义如式~\ref{eq:jaccard}\ 所示。
对要求精确的任务仅在 $\mathrm{Jacc}=1$ 时通过，
对允许近似的任务采用 $J\ge 0.95$ 作为软门限。
\begin{equation}
  \mathrm{Jacc}\!\left(S^\star,\hat{S}^{(k)}\right)
  =
  \frac{\big|S^\star \cap \hat{S}^{(k)}\big|}
       {\big|S^\star \cup \hat{S}^{(k)}\big|}.
  \label{eq:jaccard}
\end{equation}

路径与结构型任务通过算法验证器检查路径合法性、优化最优性与结构等价性，
覆盖最短路径、哈密顿路径判定、子图匹配与同构判定等问题。

{接受规则与最优候选选取。}
候选序列的接受判定如式~\ref{eq:accept_rule}\ 所示。
当有效集合为空时，进行有限次数重试采样以避免奖励稀疏导致的数据缺失。
当存在多个有效候选时，采用 best-of-$n$ 规则选取奖励最高者作为最终标注，
其形式如式~\ref{eq:best_of_n}\ 所示。
\begin{equation}
  \mathcal{A}(G,q,y^{(k)})
  =
  \mathbb{I}\!\Big[
    \mathcal{R}(G,q,y^{(k)}) \ge \tau_{\mathrm{CoT}}
  \Big],
  \label{eq:accept_rule}
\end{equation}
\begin{equation}
  y^\star(G,q)
  =
  \arg\max_{y^{(k)} \in \mathcal{Y}_{\text{valid}}(G,q)}
  \mathcal{R}(G,q,y^{(k)}).
  \label{eq:best_of_n}
\end{equation}

\subsubsection{人工抽检与数据集最终定义}
\label{subsubsec:cot_finalize}

为进一步保证推理链的可读性与表达质量，
本文对最终样本进行 $10\%$ 比例人工抽检。
抽检标准包括逻辑一致性、结构证据充分性与表述清晰度，
并要求关键中间结论能够对应到明确的结构依据。
不合格样本被剔除或替换为次高奖励的有效候选，
同时对高频失败模式进行汇总，用于迭代验证规则与提示策略。

最终得到的冷启动思维链数据集定义如\ref{eq:cot_dataset_def}\ 所示。
\begin{equation}
  \mathcal{D}_{\text{CoT}}
  =
  \Big\{
    \big(G_i, q_i, y_i^\star\big)
  \Big\}_{i=1}^{N_{\text{CoT}}},
  \qquad
  N_{\text{CoT}} \approx 4.8\times 10^4.
  \label{eq:cot_dataset_def}
\end{equation}

综上，本文在图算法可验证器支撑下构建了规模可观、结构可验证且语义质量可控的图推理思维链数据集 $\mathcal{D}_{\text{CoT}}$，
为后续冷启动微调与基于 GRPO 的强化学习训练提供数据基础。
\subsection{思维链监督微调目标建模}
\label{subsec:cot_sft_objective}

在获得思维链监督数据集 $\mathcal{D}_{\mathrm{CoT}}$ 后，
本文将图结构大模型视作条件语言模型，
对解码器执行自回归监督微调，
以对齐图结构、查询、推理链与答案的联合生成分布，
从而为后续基于可验证奖励的强化学习阶段提供结构化的初始策略。
整体框架如图~\ref{fig:cot_sft_overview}\ 所示。

\begin{figure}[htbp]
    \centering
    \includegraphics[width=1\textwidth]{4_chapter/cot_sft_overview.pdf}
    \caption{基于思维链的监督微调建模调优框架图}
    \label{fig:cot_sft_overview}
\end{figure}

为与第~\ref{sec:graph_llm_inference}\ 节的推理模板一致，
记第 $i$ 个样本的图与问题为 $(G_i,q_i)$，
监督目标为 $y_i^\star=(c_i^\star,a_i^\star)$，
其中 $c_i^\star$ 为思维链，$a_i^\star$ 为最终答案。

\textbf{输入序列定义。}
输入由系统提示、任务提示、图结构编码与自然语言查询拼接得到，
如式~\ref{eq:cot_input_seq}\ 所示。
\begin{equation}
  x_i
  =
  P_{\mathrm{sys}}
  \oplus
  P_{\mathrm{task}}(t_i)
  \oplus
  \mathrm{EncGraph}(G_i)
  \oplus
  q_i,
  \label{eq:cot_input_seq}
\end{equation}
其中 $\mathrm{EncGraph}(G_i)$ 表示图到语言嵌入的固定映射流程，
先对 $G_i$ 执行欧拉化序列化，
再经图编码器 $\mathrm{Enc}_G$ 编码并由跨模态投影头\(f_G\)映射到语言模型隐空间。
符号 $\oplus$ 表示序列维度拼接。

\textbf{输出序列定义。}
输出侧采用固定格式函数将推理链与最终答案封装为统一文本，
保证训练与推理阶段输出形态一致，
其定义如式~\ref{eq:cot_output_seq}\ 所示。
\begin{equation}
  y_i
  =
  \mathrm{format}\big(c_i^\star,a_i^\star\big),
  \label{eq:cot_output_seq}
\end{equation}
其中 $\mathrm{format}(\cdot)$ 生成包含 \texttt{Reasoning:} 与 \texttt{Final Answer:} 两个段落的规范化序列，
并对答案字段施加统一标记，便于后续可验证奖励计算与解析。

{训练建模。}
可训练参数集合记为 $\theta_{\mathrm{CoT}}$。
训练目标是在 $\mathcal{D}_{\mathrm{CoT}}$ 上最小化条件语言模型的负对数似然，
并仅对助手回复段落对应的 token 位置计算损失，
其形式如式~\ref{eq:cot_sft_loss}\ 所示。
\begin{equation}
  \mathcal{L}_{\mathrm{CoT\text{-}SFT}}(\theta_{\mathrm{CoT}})
  =
  - \mathbb{E}_{(x,y)\sim\mathcal{D}_{\mathrm{CoT}}}
  \sum_{t=1}^{|y|}
  m_t
  \log p_{\theta_{\mathrm{CoT}}}\big(y_t \mid x, y_{<t}\big),
  \label{eq:cot_sft_loss}
\end{equation}
其中 $m_t\in\{0,1\}$ 为监督掩码，
当 $y_t$ 属于助手回复段落时取 $1$，
其余位置取 $0$。
该目标与第~\ref{sec:training_sft}\ 节的监督微调形式一致，
区别在于此处的目标序列显式包含完整推理链与最终答案，
从而将先推理后作答的生成模式内化为条件分布的一部分。
训练采用教师强制策略（Teacher Forcing），
在每个时间步以真实前缀 $y_{<t}$ 作为条件预测下一个 token。
损失仅在 $m_t=1$ 的位置累积，
系统提示与用户提示不参与梯度更新，
从而将参数更新集中在推理组织方式与答案生成行为上。
该阶段得到的策略为后续基于可验证奖励的强化学习优化提供稳定初始化。
\subsection{冷启动阶段的训练策略与实现}
\label{subsec:cot_sft_train_detail}

本节给出冷启动阶段的训练策略，
目标是在有限算力预算下快速获得较优的初始推理策略。

{参数更新范围与稳定性约束。}
冷启动阶段仅更新 $\theta_{\mathrm{CoT}}$，
冻结 $\mathrm{Enc}_G$、$\mathrm{Enc}_T$ 与
跨模态投影层\(f_G\)，
以降低灾难性遗忘风险并保护图到语言隐空间的对齐关系。
语言模型主干 $\mathrm{Dec}_T$ 内采用 LoRA 形式注入可训练参数，
将更新集中在注意力投影与前馈子层，
使模型学习更规范的步骤化推理表达，
同时尽量不损伤原始指令模型的语言能力与知识。

{优化器与学习率调度。}
采用 AdamW 优化 $\theta_{\mathrm{CoT}}$，
使用较小基准学习率并结合线性预热与余弦退火调度，
以抑制冷启动阶段的梯度震荡。
训练引入梯度裁剪以避免极端样本导致的梯度爆炸，
并采用混合精度以降低显存开销并提升吞吐。

{长度控制与截断策略。}
在上下文窗口约束下，
输入与输出的总长度限制在预训练模型最大上下文长度以内。
对超长推理链，
在保证 \texttt{Final Answer:} 段落完整的前提下进行尾部截断，
以在推理细节保真与训练成本之间取得折中。
该策略保证答案字段可被稳定解析与验证，
同时避免过长序列导致的训练不稳定。

以在保持图论正确性的约束下进一步优化推理策略。

\subsection{规则化可验证奖励建模}
\label{subsec:rule_reward_design}

\subsubsection{问题设定与设计原则}
\label{subsubsec:reward_setup}

强化学习阶段将图推理视为单步生成决策过程。
给定图与查询 $(G,q)$，
策略模型 $\pi_\theta$ 生成完整输出 $y=(c,a)$，
其中 $c$ 为思维链文本，$a$ 为最终答案片段。
环境侧由确定性验证器对输出进行解析与核验，
并返回标量奖励 $\mathcal{R}(G,q,y)$ 作为策略优化信号。

本节奖励设计遵循三条原则。
第一条原则是可验证性，奖励必须由图算法与规则系统直接计算，避免人工偏好数据依赖。
第二条原则是可分解性，奖励由若干语义清晰的分量组成，便于诊断与消融。
第三条原则是稳定性，解析失败或格式异常应给出保守奖励，避免奖励抖动与被利用。

{解析失败的统一处理。}
若验证器无法从 $a$ 或 $c$ 中解析出所需结构化对象，
对应分量奖励记为 $0$，
并由格式分量对该类输出施加额外惩罚，
从而将策略引导回可解析的输出形态。

\subsubsection{总奖励函数分解}
\label{subsubsec:reward_decompose}

本文将总奖励拆分为四个分量，
分别对应答案正确性、拓扑一致性、格式可读性与长度正则化。
总奖励定义如式~\ref{eq:reward_function}\ 所示。
\begin{equation}
  \mathcal{R}(G,q,y)
  =
  \lambda_{\mathrm{ans}} \, R_{\mathrm{ans}}(G,q,a)
  +
  \lambda_{\mathrm{topo}} \, R_{\mathrm{topo}}(G,q,c,a)
  +
  \lambda_{\mathrm{fmt}} \, R_{\mathrm{fmt}}(y)
  +
  \lambda_{\mathrm{len}} \, R_{\mathrm{len}}(y),
  \label{eq:reward_function}
\end{equation}
其中 $\lambda_{\mathrm{ans}},\lambda_{\mathrm{topo}},\lambda_{\mathrm{fmt}},\lambda_{\mathrm{len}} \ge 0$ 为权重超参数。
实现中各分量均限制在 $[0,1]$，
因此总奖励的数值范围由权重线性决定，便于跨任务与跨批次保持尺度稳定。

\subsubsection{答案正确性奖励 $R_{\mathrm{ans}}$}
\label{subsubsec:reward_ans}

答案正确性是图推理任务中最关键且最易可验证的信号。
本文沿用数据构建阶段的验证器思想，
按任务输出形态将 $R_{\mathrm{ans}}$ 划分为三类规则，
并以任务类型 $t$ 对应选择其一。

{数值型任务。}
对于具有唯一数值真值的任务，
首先从最终答案片段 \(a\) 中解析出标量
\(\hat{v}\)，并通过 NetworkX\cite{Rossi2015TheND} 计算真值
\(v^\star\)，并执行数值等价判断。
奖励定义如式~\ref{eq:reward_num}\ 所示。
\begin{equation}
  R_{\mathrm{ans}}^{\mathrm{num}}(G,q,a)
  =
  \mathbb{I}\big[\mathrm{equiv}(\hat{v}, v^\star)\big],
  \label{eq:reward_num}
\end{equation}
其中 \(\mathbb{I}[\cdot]\) 为指示函数，
$\mathrm{equiv}(\cdot,\cdot)$ 表示在容差下的数值一致性检查，
用于兼容分数与小数等价表达。

{集合型任务。}
对答案为无序集合的任务，
从答案片段 \(a\) 解析生成集合 $\hat S$，
由图算法得到真值集合 $S^\star$，
并以 Jaccard 系数给出连续奖励。
定义如式~\ref{eq:reward_set}\ 所示，
其中 $\mathrm{Jacc}(\cdot,\cdot)$ 的定义与式~\ref{eq:jaccard}\ 一致。
\begin{equation}
  R_{\mathrm{ans}}^{\mathrm{set}}(G,q,a)
  =
  \mathrm{Jacc}\big(S^\star,\hat{S}\big),
  \label{eq:reward_set}
\end{equation}

{路径与结构型任务。}
对最短路径、欧拉路径、哈密顿路径与同构判定等任务，
从 $a$ 解析候选路径 $\hat P$ 或映射 $\hat f$，
并由任务对应的算法验证器检查约束是否满足。
验证通过给予奖励 $1$，否则为 $0$，
定义如式~\ref{eq:reward_path}\ 所示。
\begin{equation}
  R_{\mathrm{ans}}^{\mathrm{path}}(G,q,a)
  =
  \mathbb{I}\big[\mathrm{VerifyStruct}(G,q,a)=\mathrm{true}\big],
  \label{eq:reward_path}
\end{equation}

综合写法如式~\ref{eq:reward_ans_all}\ 所示。
\begin{equation}
  R_{\mathrm{ans}}(G,q,a)
  =
  \begin{cases}
    R_{\mathrm{ans}}^{\mathrm{num}}(G,q,a),  & \text{数值型任务}, \\
    R_{\mathrm{ans}}^{\mathrm{set}}(G,q,a),  & \text{集合型任务}, \\
    R_{\mathrm{ans}}^{\mathrm{path}}(G,q,a), & \text{路径与结构型任务}.
  \end{cases}
  \label{eq:reward_ans_all}
\end{equation}

\subsubsection{拓扑一致性奖励 $R_{\mathrm{topo}}$}
\label{subsubsec:reward_topo}

仅奖励最终答案可能诱导模型跳过推理链，
或在思维链中产生与图结构不一致的叙述。
为鼓励可追溯的结构化推理，
本文引入拓扑一致性奖励，
对思维链中出现的结构证据进行保守核验。

给定输出 $y=(c,a)$，
验证器从 $c$ 中抽取节点集合 $\mathcal{V}_c$ 与边对集合 $\mathcal{E}_c$，
抽取规则基于确定性正则与有限模式匹配，
仅在证据明确时才计入集合，
从而降低误抽取带来的噪声。

{结构引用合法性。}
统计思维链中引用的节点与边在真实图中的合法比例，
定义如式~\ref{eq:reward_topo_valid}\ 所示。
\begin{equation}
  R_{\mathrm{topo}}^{\mathrm{valid}}(G,c)
  =
  \frac{
    \big|\{(u,v)\in\mathcal{E}_c : (u,v)\in E(G)\}\big|
    +
    \big|\{v\in\mathcal{V}_c : v\in V(G)\}\big|
  }{
    |\mathcal{E}_c| + |\mathcal{V}_c| + \varepsilon
  },
  \label{eq:reward_topo_valid}
\end{equation}
其中 $\varepsilon$ 为极小常数。
当未抽取到结构证据时，
该分量趋于 $0$，
从而避免空洞推理链获得高奖励。

{路径任务的一致性约束。}
当任务类型为路径输出时，
从思维链中抽取候选路径集合 $\{\tilde P_j\}$，
并将其与最终答案路径 $\hat P$ 的边集合做一致性比较。
该分量仅在路径类任务中启用，
非路径任务中记为 $0$。
定义如式~\ref{eq:reward_topo_path}\ 所示。
\begin{equation}
  R_{\mathrm{topo}}^{\mathrm{path}}(G,c,a)
  =
  \max_j
  \mathrm{Jacc}\big(E(\tilde{P}_j), E(\hat{P})\big),
  \label{eq:reward_topo_path}
\end{equation}

最终拓扑一致性奖励为两者的加权和，
定义如式~\ref{eq:reward_topo_all}\ 所示。
\begin{equation}
  R_{\mathrm{topo}}(G,q,c,a)
  =
  \alpha_{\mathrm{valid}} R_{\mathrm{topo}}^{\mathrm{valid}}(G,c)
  +
  \alpha_{\mathrm{path}} R_{\mathrm{topo}}^{\mathrm{path}}(G,c,a),
  \label{eq:reward_topo_all}
\end{equation}
其中 $\alpha_{\mathrm{valid}},\alpha_{\mathrm{path}} \ge 0$ 为归一化权重。

\subsubsection{格式与可读性奖励 $R_{\mathrm{fmt}}$}
\label{subsubsec:reward_fmt}

强化学习训练中，
仅用正确性奖励容易导致输出形态退化，
表现为标签缺失、段落混乱或符号噪声增加。
为维持输出结构稳定与文本可读性，
本文采用轻量的格式奖励，
其作用是约束输出满足可解析与可审计的基本形态，
而非替代任务正确性目标。

{标签完整性。}
要求输出包含 \texttt{Reasoning:} 与 \texttt{Final Answer:} 两个段落标记，
定义如式~\ref{eq:reward_fmt_tag}\ 所示。
\begin{equation}
  R_{\mathrm{fmt}}^{\mathrm{tag}}(y)
  =
  \mathrm{hasTag}(y),
  \label{eq:reward_fmt_tag}
\end{equation}
其中 $\mathrm{hasTag}(y)\in\{0,1\}$ 为确定性判定函数。

{语言一致性。}
统计思维链文本 $c$ 中中文字符占比，
并对大量非目标字符的输出给予惩罚。
定义如式~\ref{eq:reward_fmt_lang}\ 所示。
\begin{equation}
  R_{\mathrm{fmt}}^{\mathrm{lang}}(y)
  =
  \frac{\#\text{中文字符}(c)}{\#\text{字符总数}(c) + \varepsilon},
  \label{eq:reward_fmt_lang}
\end{equation}

综合格式奖励定义如式~\ref{eq:reward_fmt_all}\ 所示。
\begin{equation}
  R_{\mathrm{fmt}}(y)
  =
  \beta_{\mathrm{tag}} R_{\mathrm{fmt}}^{\mathrm{tag}}(y)
  +
  \beta_{\mathrm{lang}} R_{\mathrm{fmt}}^{\mathrm{lang}}(y),
  \label{eq:reward_fmt_all}
\end{equation}

\subsubsection{长度正则化项 $R_{\mathrm{len}}$}
\label{subsubsec:reward_len}

过短的思维链往往缺乏可追溯的解释，
过长的思维链易引入冗余推理或噪声证据。
本文对思维链长度施加软约束，
鼓励其落在与图规模相匹配的区间内。
设思维链 token 长度为 $|c|$，
目标区间为 $[L_{\min},L_{\max}]$，
定义如式~\ref{eq:reward_len}\ 所示。
\begin{equation}
  R_{\mathrm{len}}(y)
  =
  \exp\Big(
    -\gamma \cdot d\big(|c|,[L_{\min},L_{\max}]\big)
  \Big),
  \label{eq:reward_len}
\end{equation}
其中 $\gamma>0$ 为惩罚强度，
$d(\ell,[L_{\min},L_{\max}])=\max(0,L_{\min}-\ell,\ell-L_{\max})$ 表示长度偏离距离。
实现中 $L_{\min},L_{\max}$ 随子图规模设定，
以保证不同规模图的推理链长度约束具有一致口径。

\subsubsection{小结}
\label{subsubsec:reward_summary}

综上，本文构建了面向图推理的可验证奖励函数 $\mathcal{R}(G,q,y)$，
其形式由式~\ref{eq:reward_function}\ 给出。
该奖励以答案正确性为核心，
以拓扑一致性约束推理链中的结构证据，
并以格式与长度分量维持输出的可解析性与可读性。
在后续 GRPO 训练中，
该奖励作为唯一环境反馈信号，
驱动策略在图推理空间中进行自我改进与稳定收敛。


\subsection{强化学习训练流程与实现配置}
\label{subsec:grpo_train_detail}

在 GRPO 目标之上，本文采用组内多轨迹采样与可验证奖励进行强化学习训练。
每次迭代从强化学习任务池 $\mathcal{D}_{\mathrm{RL}}$ 采样一个批次
$\{(G_i,q_i)\}_{i=1}^{B}$，批次大小 $B=64$，
其中 Erd\H{o}s\cite{Guo2025G1TL}  风格合成图任务与真实文本属性图任务按 $4{:}1$ 混合采样。
对每个样本构造条件输入 $x_i$，其定义与式~\ref{eq:cot_input_seq}\ 一致，
并保持系统提示与任务模板固定。

对每个 $x_i$，使用旧策略 $\pi_{\theta_{\mathrm{old}}}$ 采样生成 $M=5$ 条候选轨迹
$\{y_i^{(m)}\}_{m=1}^{M}$，采样配置为温度 $T=1.0$ 与 top-$p=0.9$，
采样形式与式~\ref{eq:grpo_sample}\ 一致。
最大生成长度设为 $L_{\max}=4096$，超长序列在保证答案字段完整的前提下截断。
对每条轨迹计算可验证奖励 $\mathcal{R}(G_i,q_i,y_i^{(m)})$。
对解析失败或硬约束违反的轨迹将奖励置为 $0$ 并标记为无效；
若某个样本的 $M$ 条轨迹全部无效，则跳过该样本并在后续迭代重新采样。

对保留样本按式~\ref{eq:grpo_adv}\ 计算组相对优势 $A_i^{(m)}$，
并裁剪到 $[-5,5]$。
随后基于当前策略 $\pi_\theta$、旧策略 $\pi_{\theta_{\mathrm{old}}}$ 与参考策略 $\pi_{\mathrm{ref}}$
计算对数概率与重要性比率 $\rho_i^{(m)}(\theta)$，
构造策略项与 KL 正则项，得到样本级 GRPO 损失 $\mathcal{L}^{\mathrm{GRPO}}_i(\theta)$。
训练采用 token 级对数概率回放，将优势对各 token 的对数概率项加权累积以更新 $\theta$。

优化器采用 AdamW，学习率 $\eta=1\times10^{-6}$，
权重衰减 $\lambda_{\mathrm{wd}}=1\times10^{-2}$，仅作用于解码器适配层参数。
学习率调度采用 $10\%$ 线性预热与余弦退火，末端学习率衰减至 $1\times10^{-7}$。
每间隔 $100$ 个训练步将 $\pi_{\theta_{\mathrm{old}}}$ 同步为 $\pi_\theta$，
参考策略 $\pi_{\mathrm{ref}}$ 始终冻结不变。
训练过程中监控平均奖励 $\bar r$、有效轨迹比例、答案正确率 $Acc_{\mathrm{ans}}$、
约束违反率、平均思维链长度与平均 KL 散度 $\bar D_{\mathrm{KL}}$，
其中 $\bar D_{\mathrm{KL}}$ 采用 batch 内序列平均的 token KL 口径计算。
当 $\bar r$ 与 $Acc_{\mathrm{ans}}$ 在评估窗口内无提升且 $\bar D_{\mathrm{KL}}$ 稳定在目标范围附近时触发早停。
最终得到的强化学习检查点参数记为 $\theta_{\mathrm{RL}}^\ast$。


通过上述训练流程，
本文在保持基模语言能力与跨模态对齐能力稳定性的前提下，
利用可验证奖励显式鼓励模型探索并固化高回报的图推理策略。
规则化奖励为答案正确性与结构一致性提供确定性反馈，
组相对优势与 KL 约束共同提升训练稳定性并促进收敛。
最终得到的强化学习检查点参数记为 $\theta_{\mathrm{RL}}^\ast$，
作为后续图推理性能与可解释性评测的模型版本。

\textbf{1)\ 实验目标}

\textbf{4)\ 实验细节配置}

本文实验遵循监督式冷启动与强化学习优化两阶段方法。
所有训练与评测均基于 DeepSpeed ZeRO-2 进行分布式加速，
语言模型解码器选用 Qwen2.5-7B-Instruct\cite{Yang2024Qwen25TR}，
图结构编码器使用第 3 章预训练得到的 GET-Base24 权重。
除特别说明外，训练的全局批次大小均设为 64。

{阶段一：思维链监督微调。}
冷启动阶段在 $\mathcal{D}_{\mathrm{CoT}}$ 的训练集（18,000 条）上进行 CoT-SFT，
目标是规范化输出格式并注入基础图论推理模式。
训练时冻结图欧拉路径编码器 $\mathrm{Enc}_G$ 与跨模态投影层 $f_{\mathrm{proj}}$，
仅对 LLM 解码器进行参数高效微调。
具体实现为在解码器的线性层与注意力相关线性映射中注入 LoRA 适配器，
秩设为 $r=64$，缩放系数 $\alpha=128$，Dropout 率为 0.05。
优化器采用 AdamW，最大学习率设为 $\eta_{\mathrm{SFT}}=1\times10^{-5}$，
学习率调度采用带预热的余弦退火，预热步数占总步数的 3\%。
为容纳完整推理链，最大序列长度限制为 3072 tokens。
训练共进行 2 个 epoch，
并以验证集上的 token-level 准确率与格式合规率作为早停监控指标，
其中格式合规率按是否同时包含 \texttt{Reasoning:} 与 \texttt{Final Answer:} 标签进行判定。
最终选择验证集指标最优的检查点作为强化学习初始化参数。

{阶段二：基于 GRPO 的强化学习优化。}
强化学习阶段以阶段一得到的模型参数初始化策略网络 $\pi_{\theta}$，
并冻结参考模型 $\pi_{\mathrm{ref}}$ 以计算 KL 约束项。
训练任务集采用 $\mathcal{D}_{\mathrm{RL}}$ 中的 100,000 条训练任务，
每次迭代从中采样全局批次大小为 64 的图--问题对 $(G,q)$。
对每个输入，策略网络采用核采样生成 $M=5$ 条独立推理轨迹，
采样温度设为 $T=1.0$，top-$p$ 设为 0.95，
最大生成长度设为 4096 tokens。
奖励函数各分量权重取
$\lambda_{\mathrm{ans}}=1.0$，
$\lambda_{\mathrm{topo}}=0.5$，
$\lambda_{\mathrm{fmt}}=0.1$，
$\lambda_{\mathrm{len}}=0.01$，
与第 4.4.1 节的定义保持一致。
为稳定训练，强化学习阶段学习率设为 $\eta_{\mathrm{RL}}=1\times10^{-6}$，
KL 惩罚系数设为 $\beta=0.001$，梯度裁剪阈值设为 1.0；
每隔 100 步将旧策略 $\pi_{\mathrm{old}}$ 同步为当前策略。
训练共进行约 3000 步，
对应处理的输入样本数约为 $3000\times64=1.92\times10^{5}$，
生成的轨迹总数约为 $3000\times64\times5=9.60\times10^{5}$。
训练过程中在验证集上周期性评估平均奖励与 KL 散度，
当平均奖励在连续评估窗口内的相对波动小于 1\% 时终止训练，
并输出最终强化学习检查点参数 $\theta_{\mathrm{RL}}^\ast$。

\textbf{3) \ 实验分析}

表~\ref{tab:main_erdos_result}、表~\ref{tab:graphwiz_result} 与
表~\ref{tab:grapharena_result}
汇报了不同模型在三类图推理基准上的测试准确率。
总体上，方案5在三个基准上均达到本组方法的最高准确率，
并在多个分组设置下与现有同规模模型形成稳定差异。

\textbf{1)\ 方案4与方案5的分阶段对比。}
在 Erd\H{o}s\cite{Guo2025G1TL} 上，方案5的平均准确率相较方案4提升了13.9\%；
在 GraphWiz\cite{Chen2024GraphWizAI} 与 GraphArena\cite{Tang2024GraphArenaBL} 上，
方案5的平均准确率相较方案4提升7.38\% 与 8.73\%。
这一现象与两阶段训练信号的差异相匹配：
方案4在合成思维链数据上进行最大似然训练，优化目标是复现标注分布；
方案5在相同验证器下使用可验证奖励作为优化信号，使训练目标与评测口径直接一致。
因此，三基准上的同向变化更符合目标对齐带来的效果，而非单一数据集的偶然波动。

\textbf{2)\ 图结构大模型的预训练表征优势。}
本文方案5与 G1-7B 采用一致的强化学习技术和奖励评测规则，
但在 Erd\H{o}s\cite{Guo2025G1TL}  主基准上本文方案具有1.21 个百分点的准确率提升，
该差异更可能与输入侧结构表征与预训练初始化的不同有关。
一方面，本文采用欧拉遍历式的结构序列化，并配合第3章图编码器预训练，
使输入序列中显式保留边遍历证据与节点复现模式，从而在进入强化学习阶段前提供更确定的连通性线索；
相较之下，边列表线性化对同一图结构可能对应多种等价排列，
容易在序列空间引入额外的排列不确定性。
另一方面，跨模态对齐预训练为图子结构与文本指令建立了稳定的对应关系，
使模型在解析自然语言任务描述时更容易将语义约束映射为可验证的结构条件。
这一点在 Easy 与 Medium 难度上的准确率上体现明显，
说明改进的图表征与对齐为后续强化学习提供了表征优势。

\textbf{3)\ 能力边界分析。}
尽管方案5在整体性能上优于各类对比模型，
但在 Challenging 等级任务上，其准确率仍明显低于 Medium，
与 G1-7B 的表现大致持平。
这揭示了当前基于 LLM 的图推理技术仍存在两点结构性瓶颈：
其一，许多 Challenging 任务对应 NP 难问题，
解空间呈指数级增长，LLM 的自回归生成本质上是线性扫描，
难以完全模拟动态规划或回溯搜索等复杂算法过程；
其二，欧拉路径编码虽然在结构上近似无损，
但在大规模或稠密图场景下会带来极长的输入序列，
注意力在超长上下文中被稀释，长程依赖建模难度增加。
因此，即便在更强的图表征和 RL 训练下，
Challenging 子集上的提升仍然有限。

\textbf{(1)算法保真度与时序规划。}

如图~\ref{fig:resoning_task1}所示，在求解两点间最短路径时，模型并未通过死记硬背直接生成答案，

这一结果表明，本文的编码器克服了传统无向图处理技术对方向信息的丢失，使模型具备了处理严格时序约束和因果推理的能力。

\textbf{(2)NP-难问题中的约束满足。}
针对计算复杂度较高的组合优化问题，模型展示了在硬约束下的{启发式搜索能力}。
如图~\ref{fig:resoning_task2}所示，该任务要求选出的节点集合中任意两点互不相邻，属于典型的 NP-hard 问题。
模型的思维链展示了一种选择-屏蔽的策略：在选定一个节点后，显式地在推理空间中标记并排除其邻居节点。
这种对互斥约束的严格遵守，证明了强化学习中的规则奖励有效地抑制了违规采样，
使大语言模型能够模拟回溯或剪枝算法的逻辑过程。并且，
在图~\ref{fig:resoning_task4}所示的关键节点识别任务中，
模型不仅计算了节点的度中心性，还结合了节点的语义角色（如“核心枢纽”、“备用链路”）进行综合判断。
它成功识别出移除后会导致网络连通性剧烈下降的桥接点，
表明模型已学会将抽象的图论指标映射到具体的物理意义上。最后，如图~\ref{fig:resoning_task5}所示。
在引用网络节点分类任务中，模型面对的是具有模糊边界的跨学科论文。
推理轨迹显示，模型并未单纯依赖文本内容，而是通过分析引用结构来辅助分类决策。
这种利用同质性与结构模式增强语义理解的行为，有力佐证了跨模态对齐模块在处理异构信息时的协同增益。

综上所述，定性分析证实了本章提出的训练框架不仅提升了模型的预测准确率，更使其习得了可解释、可验证且符合图论规则的推理技术。

揭示了不同训练技术对模型泛化性能的影响。
综合对比基准模型与本文提出的两种方案，本文得出以下实验结论：

首先，在零样本设定下，
通用指令模型
（Llama-3.1\cite{grattafiori2024llama3} 、Qwen2.5\cite{Yang2024Qwen25TR}）在零样本节点分类上的表现整体弱于专门面向推理优化的
DeepSeek-R1 与 G1模型，
说明仅依靠模型拥有较好的语义遵循能力并不足以让它真正理解图结构本身，
节点分类需要的是对邻接关系、局部结构模式等图特征的感知，
而这些信息在纯语言指令微调中没有被系统性建模。

同时，在相同强化学习技术下，
方案5的零样本节点分类能力优于同参数量级的图推理模型G1-7B。
方案5 在训练时与 G1-7B 使用同类合成图论任务与可验证奖励，
但在平均准确率指标（Avg.）上相较于 G1-7B提升了2.68\%。
两者的差异不来自数据集规模或者训练任务，
而来自各自接受的不同质量的图结构表征。
G1 采用简单边列表线性化，部分打乱了局部拓扑与全局连通性的结构信息。
本文在第三章中引入的欧拉路径无损编码和多层次跨模态对齐预训练，
使模型在进入强化学习阶段前就已经具备更清晰的图状态感知能力。
图编码改进的预训练图结构大模型
不仅知道有哪些点和边，更知道这些结构在序列中的组织方式
及其与文本描述的对应关系。
在此基础上应用同样的强化学习策略，
奖励信号能够更准确地指向真正与结构相关的策略更新方向，
从而在同一 RL 训练数据下得到略强但稳定的零样本节点分类性能。


其次，进一步对比方案3与方案5可知，
任务特化监督可达到性能上限，而强化学习则提供可迁移的方法论。
方案3 在训练中直接使用 Cora 与 PubMed 的节点标签进行监督微调，
因此在两个数据集上分别达到 91.27\% 与 94.48\% 的准确率，  
属于有标注条件下的任务上限；而方案5 在训练全过程从未使用过这些标签，
仅依靠合成图论任务中的奖励信号，就能在同一评测上达到约 83\% 的准确率。
说明强化学习让模型学会了一套与具体数据集无关的
图分析策略，在完全没有新标签时仍然能给出合理预测。

此外，冻结图编码器有效避免灾难性遗忘。
本文在强化学习阶段始终冻结第三章训练好的图编码器，
只更新 LLM 解码器与对齐层。
从结果上看，方案5 的零样本性能不仅没有相对 G1-7B 退化，
在 PubMed 等真实图上甚至略有优势，说明底层结构表示保持稳定，
这验证了本文所采用的训练策略的有效性，
既保留了第三章中通过欧拉编码和对齐预训练获得的强表征，
又在此基础上增加了可迁移的图推理能力。

\subsection{消融实验}
\label{sec:ablation}

为解析强化学习微调框架中各功能模块及关键超参数对图推理性能的边际贡献，
本文在统一的实验基准下设计了三组控制变量实验。
实验旨在探究：
\begin{enumerate}
\item 奖励函数消融实验：量化不同奖励组件在模型性能提升与
思维链质量方面的贡献；
\item 训练策略对比实验：测评不同训练方法对模型最终性能的影响；
\item 超参数消融实验：
考察奖励权重与 KL 散度约束对训练稳定性及收敛结果的鲁棒性。
\end{enumerate}

除另有说明外，
本节实验均基于 Erdős 图推理基准进行，
并报告 Easy 至 Challenging 四个难度层级的准确率及其加权平均值。

体现出在过程约束强度和策略稳定性之间较为合理的折中。
下面从拓扑奖励权重和 KL 正则两方面进行分析。

拓扑一致性奖励 $R_{\text{topo}}$ 用于衡量推理链与真实图结构的匹配程度，
在训练中提供比答案奖励更密集的中间反馈。
当 $\lambda_{topo}$ 过低（\textit{Low-Topo}, 0.2）时，
优化几乎完全由答案正确性 $R_{ans}$ 主导，
模型只能在稀疏的终点信号上更新参数，
难以及时修正中间推理步骤中的结构错误，
导致 Hard 与 Avg. 均有下降，CoT 合法率也随之降低。
相反，当 $\lambda_{topo}$ 过高（\textit{High-Topo}, 1.0）时，
虽然过程监督更强，但平均性能不升反降，
说明过大的拓扑权重会诱导模型偏向保守且结构安全的推理链，
即优先满足局部结构约束而忽略全局目标，出现轻度的奖励偏置现象。
默认设置 $\lambda_{topo}=0.5$ 在两者之间取得平衡，
既提供了足够密集的结构引导，又避免过程奖励喧宾夺主，
从而在 Hard 难度和整体性能上获得最优结果。

KL 正则系数 $\beta$ 控制策略 $\pi_\theta$ 相对初始模型策略 $\pi_{\text{ref}}$ 的偏离程度，
本质上限定了强化学习的“信任域”大小。
当 $\beta$ 过小（\textit{Weak-KL}）时，
模型可以大幅偏离初始模型策略进行探索，
但表现在验证集上的收益有限，
且训练中后期会出现更明显的性能波动，
说明策略过度追随局部高奖励样本，
削弱了 SFT 阶段获得的语言与结构先验，存在策略漂移风险。
当 $\beta$ 过大（\textit{Strong-KL}）时，
策略更新被强力约束在初始模型附近，
虽然 CoT 合法率保持较高水平，但 Avg. 明显下降，
强化学习在很大程度上退化为对 SFT 模型的保守微调，
难以探索到新的高质量推理模式。
默认设置 $\beta=10^{-3}$ 在允许必要的策略更新
与保持分布稳定性之间达成折中，
既避免了激进探索带来的泛化退化，又保证了 RL 相较 SFT 的实质性增益。

综上，本节消融结果表明：
适中的拓扑奖励权重与 KL 正则系数对于图推理强化学习至关重要，
它们共同决定了模型在利用已有先验和探索更优策略之间的动力学平衡，
也是方案5 能够在各项基准上稳定优于基线模型的重要原因之一。

\section{本章小结}

本章针对图结构大模型在复杂逻辑推理任务中面临的可验证性缺失与泛化能力受限等核心问题，
研究并提出了一种融合思维链监督与强化学习微调的推理增强方法。

本章首先提出基于思维链监督的冷启动微调策略。
通过构建高质量的思维链数据集 $\mathcal{D}_{\mathrm{CoT}}$，将合成图论任务与真实图任务统一为可监督的推理生成样本，
为预训练图结构大模型注入了结构推理先验。
在此基础上，本章引入组式相对策略优化算法，设计了由答案正确性、拓扑一致性及约束满足度构成的复合可验证奖励机制。
该机制能够利用图算法校验器对推理路径中的结构合法性进行自动反馈，
在无需依赖大规模人工偏好标注的条件下，有效引导模型策略从单纯的概率拟合向深层的逻辑探索演进。

在多项图推理基准上的测评表明，经过强化学习优化的图结构大模型在多跳推理、
子图匹配及高题组合优化任务上均取得了一定的性能突破，并展现出零样本跨域迁移能力。
结合定性案例分析可以进一步看到，
强化学习后的模型能够更稳定地给出结构化的推理步骤，并减少因结构证据缺失导致的错误结论。

综上所述，本章提出的监督冷启动与可验证奖励驱动的强化学习微调框架，
为图结构大模型提供了一条低标注依赖、
可规模化扩展的推理能力增强路径，使模型在准确性、可核验性与跨任务泛化方面实现一定提升。
该能力增强结果为下一章面向金融反欺诈场景的生成式深度归因推理模块提供了推理内核与可解释输出基础。
