\chapter{结合强化学习微调的图推理技术}

现有图基座模型在复杂图推理任务上仍面临两大瓶颈：
其一，传统监督微调范式高度依赖高质量人工标注，模型往往倾向于记忆任务特定“捷径”，
而非抽取可迁移的图结构推理规律，导致跨任务与跨领域泛化性能显著衰减；
其二，缺乏可规模化、自动化的训练信号，真实图数据标注成本高且任务形态单一，
难以支撑模型对通用图算法能力的系统性学习与测评。

为突破上述局限，本章在前文构建的图基座模型之上，借鉴 DeepSeek-R1\cite{DeepSeekAI2025DeepSeekR1IR} 与 G1\cite{Guo2025G1TL} 等工作的思想，提出一种基于可验证奖励的图推理强化学习框架。整体方法分为两个阶段：思维链冷启动微调与基于 GRPO 的可验证强化学习微调。第一阶段，利用图算法验证器（如 NetworkX\cite{Rossi2015TheND} ）在合成图论任务与真实图数据集的混合样本上自动筛选高置信度推理链，构建大规模 CoT 监督数据集；在此基础上，冻结图欧拉路径编码器（GET）与跨模态投影层，仅微调大语言模型解码器，以注入基本的链式推理能力并稳定初始策略。第二阶段，构建无需人工偏好的自动奖励机制，设计融合答案正确性、路径拓扑一致性与约束满足度的复合可验证奖励函数，替代传统基于人类偏好的强化学习信号；随后采用组式策略优化（GRPO）对模型推理策略进行迭代更新，优先保留高奖励轨迹对应的推理模式，既缓解了经典策略梯度训练的不稳定性，又显式引导模型探索符合图论规则的推理路径，从而显著提升生成推理链的可验证性与逻辑自洽性。

综上，本章在图基座模型的基础上系统性地强化其图推理能力，使模型从面向垂直任务的判别式预测扩展到具备通用图算法能力的生成式推理范式，缓解了现有 Graph-LLMs 推理能力弱、泛化性差的核心问题，为构建可解释、高可靠的通用图推理大模型提供了关键技术支撑。

\section{概述}

本章在第~2 章构建的图基座模型之上，聚焦于图推理能力的强化学习式后训练过程。
聚焦图推理任务的能力增强，其核心目标是学习一个条件策略生成器 \(\pi_\theta\)，实现从图 - 查询输入到 “推理链 - 答案” 输出的映射。

\textbf{输入：}
给定文本属性图 \(G=(V,E,A,T)\)（符号定义同第 2 章，
其中 $V$ 为节点集合，$E$ 为边集合，\(A\in\{0,1\}^{N\times N}\) 为邻接矩阵，
\(T=\{t_i\}_{i=1}^N\) 为节点文本属性集合），
以及图推理类自然语言查询 q（如最短路径查询、连通分量判定等）；
同时输入前文预训练的图编码器 \(Enc_G\)、
跨模态投影层 \(f_{proj}:\mathbb{R}^{d_g}\to\mathbb{R}^{d_\ell}\) 与
冻结的大语言模型解码器 \(Dec_T\) 构成的基座模型参数。

\textbf{输出：}
模型输出包含两部分的序列 \(y=(c,a)\)：
链式推理过程 \(c=(c_1,c_2,\dots,c_T)\)，
其中每个 \(c_t\) 为一步图结构分析或逻辑推导的自然语言描述；
最终答案 a，其形式随任务类型变化（可为数值、节点 / 边集合、布尔值等），
且需满足图论规则与查询约束。

围绕上述目标，本章内容组织如下：
第~4.2 节首先从监督学习角度出发，在固定图侧模块的约束下，
基于 \(\mathcal{D}_{\mathrm{CoT}}\) 对解码器进行图推理导向的冷启动微调，
其训练目标沿用式~(\ref{eq:sft_loss}) 所定义的条件语言建模损失；
第~4.3 节在此基础上系统介绍基于 GRPO 的可验证强化学习框架，
包括奖励设计、策略目标与训练策略，
并与式~(\ref{eq:reward_function})–~(\ref{eq:rl_loss}) 中
的通用策略梯度目标建立对应关系；第~4.4 节详细说明思维链图推理数据集的构建过程，
包括合成图任务设计、自动 CoT 生成与过滤策略；
第~4.5 节给出实验设置与结果分析，
测评所提出方法在图推理与节点分类任务上的性能提升与泛化特性；
第~4.6 节对本章工作进行总结。

\section{基于GRPO的强化学习框架}

\section{基于思维链监督的冷启动微调}
\label{sec:cot_sft}
如第~\ref{sec:problem_graph_reasoning} 节所述，图推理任务被形式化为在给定图–文本输入 \((G,q)\) 的条件下，学习生成推理链与答案的条件语言模型
\(
p_\theta(y \mid G,q)
\)，其中 \(y = (c,a)\) 由自然语言思维链 \(c\) 与最终答案片段 \(a\) 组成。
在强化学习（RL）驱动的图推理能力增强流程中，
初始策略的质量直接决定了后续 RL 训练的样本效率与最终性能上限。
直接对原始图基座模型开展 RL 训练，易因初始推理策略的随机性与不规范性导致奖励信号稀疏、
训练过程震荡，甚至出现策略退化\cite{DeepSeekAI2025DeepSeekR1IR}。
借鉴 DeepSeek-R1 的冷启动范式与 G1 的思维链监督微调（CoT-SFT）方案， 
本研究先通过图推理导向的监督式冷启动微调，
为基座模型注入结构化的图推理先验，使其生成的推理链满足图论规则约束、具备可追溯的逻辑链条，
为后续 RL 阶段奠定稳定且高性能的初始策略。
本阶段的核心目标是：在固定图结构编码器与跨模态对齐模块的前提下，
仅优化语言模型解码器参数，学习 “图结构 - 查询 - 思维链 - 答案” 的映射关系，
其形式化目标与公式~(\ref{eq:sft_loss})保持一致，同时通过精细化的数据集构造与训练策略，
确保微调后模型兼具推理逻辑性与语言流畅性。

\subsection{思维链合成数据集构建}
\label{subsec:cot_dataset}

高质量的监督数据是冷启动微调的前提。本文构建的图推理思维链数据集
\(\mathcal{D}_{\text{CoT}}\)
融合了图论任务与真实图推理任务两类样本，
并通过教师模型生成、规则验证器过滤、人工抽检的三级筛选流程，
在控制数据规模的同时最大程度保证推理链的正确性与逻辑一致性。
整体上，数据构建遵循基于拒绝采样的范式，
以 Qwen2.5-32B-Instruct \cite{Yang2024Qwen25TR}作为教师模型生成候选推理–答案序列，
再经多维度可验证规则筛选得到最终监督样本。
本节下文将详细展开数据集构建过程。

\subsubsection{图论合成任务与难度分层策略}

本文在现有基准数据集基础上，\emph{参照} Guo 等人\cite{Guo2025G1TL} 提出的图推理任务设计与
难度分层范式，
补充构建了一套中等规模的合成图论任务数据集，用于思维链监督微调。

形式化地，记第 \(t\) 类图论任务对应的参数化任务分布为 \(\mathcal{G}_t\)。
对于每一类任务，本文从 \(\mathcal{G}_t\) 中随机采样
\(
N_t = 200
\)
个图实例 \(G \sim \mathcal{G}_t\)。
在图生成过程中，本文首先从若干真实大图
（如 Network Repository\cite{Rossi2015TheND} 中的网络）中选取种子图，
随后在种子图上采用带重启的随机游走策略下采样连通子图，
将子图规模约束在 \(5\!\sim\!35\) 个节点，以兼顾拓扑多样性与大语言模型的上下文窗口限制。
对每个采样得到的子图 \(G\)，按照第~\ref{sec:graph2token} 节的欧拉路径编码流程执行半欧拉序列化，
获得图结构编码\(s = \Phi(G)\)。

在构造自然语言查询时，针对每一类任务设计一组中文模板，
将任务类型、目标节点（或节点集合）以及必要的约束条件参数化注入模板中，
从而生成形式统一但实例多样的查询 \(q\)（例如“请给出图中节点 1 到节点 5 的最短路径并说明理由”、
“请判断该图是否为欧拉图并说明原因”等）。
随后，利用 NetworkX\cite{Rossi2015TheND}  等图算法库对每个图–任务对 \((G,q)\) 精确计算真值答案 \(a^\star\)，
从而得到本文自建的合成任务初始样本池，其数学形式如公式~(\ref{eq:generate_dataset50k}) 所示：
\begin{equation}
  \mathcal{D}_{\text{synth}}^{(0)}
  =
  \big\{ (G, q, s, a^\star) \big\},
  \label{eq:generate_dataset50k}
\end{equation}
其中样本总规模约为
\(
\sum_{t} N_t = 10{,}000
\)
个实例。

参考 G1 中对任务难度的划分\cite{Guo2025G1TL}，本文在自建数据集中对 50 类任务进行难度标注，
并在样本构建时保持与其近似的任务占比结构，具体如下：
\begin{enumerate}
  \item \textit{Easy 级任务}（约占全部任务类型的 $29.16\%$）：
  主要涵盖基础图属性与线性时间复杂度任务，例如节点计数、边计数、
  度数与平均度数计算、邻居查询、广度/深度优先遍历、是否存在环、
  最小生成树、边存在性与正则性判断（Edge Existence, Is Regular）等。
  这些任务主要考察模型对局部结构与基本图概念的掌握。

  \item \textit{Medium 级任务}（约占 $22.91\%$）：
  包括多项式时间复杂度、需要综合局部结构信息的任务，例如聚类系数与连通分量数计算、
  二分图最大匹配与最小边覆盖、局部连通性与资源分配指数、
  Jaccard 系数、是否欧拉图与是否二分图判定以及度中心性等。
  此类任务要求模型在多个局部结构之间进行多跳推理，对图结构表征和组合能力提出中等强度要求。

  \item \textit{Hard 级任务}（约占 $33.33\%$）：
  涉及更为复杂的图算法与全局结构度量，例如最短路径、
  多种中心性指标、图直径与半径、
  图中心与周边节点、三角形数量、平均邻居度以及桥边检测等。
  这些任务依赖于长程依赖建模和全局结构一致性，对图推理能力提出更高要求。

  \item \textit{Challenging 级任务}（约占 $14.58\%$）：
  主要覆盖 NP-hard 组合优化类问题及复杂全局指标，
  例如最大独立集、最小顶点覆盖、最大流、Wiener 指数、哈密顿路径判定以及图同构映射等。
  这一等级在计算复杂性上最为困难，用于测评模型在极端难度下的推理上限。
\end{enumerate}

综上，本文在任务定义与难度分层上参考 G1 的设计，但在图采样策略、查询模板、图到 Token 编码以及真值计算等环节完全重新实现，构建了规模为 \(5\)k、覆盖 50 类图论任务的自建合成图推理数据集，为后续思维链生成与强化学习训练提供了可控且结构多样的基础数据。


\subsubsection{真实属性图上的图推理任务构建}
为提高在真实场景下的迁移能力，进一步从 Cora、PubMed、OGB-Arxiv 等典型文本属性图中构造真实图推理任务。
针对每张图，选取若干种节点级或子图级查询，
包括节点连通性判别、多跳邻居检索、局部子图同构判定、学科子领域覆盖度估计等，
共采样约 \(10,000\) 个实例。
以下是从各个数据集上构建真实图推理数据的细节：

\begin{itemize}
\item \textit{Cora学术引用网络}：构建基于引文结构的推理任务，
如"论文A引用链中第3跳的节点类别是什么？"、"节点B与C是否在5跳内可达？"等。
从Cora的2,708个节点中，使用ShaDowKHop采样策略获取局部子图，
确保每个样本包含完整的k-hop邻域信息，共采集2,000个样本
\item \textit{PubMed生物医学网络}：设计语义驱动的结构检索任务，
如"给定疾病类型D，找出与其在3跳内相连且描述包含关键词K的所有论文节点"。
此类任务要求模型同时理解节点文本语义与结构关系，共采集3,500个样本。

\item \textit{OGB-Arxiv大规模学术图}：构建子图同构判定任务，
如"目标子图（描述为H）是否与查询节点v的3-hop邻域同构？"，此类任务测试模型对局部结构模式的识别能力。从169K节点中随机选择800个中心节点，
对每个节点生成6种不同同构判定查询，共4,500样本。
\end{itemize}

所有真实图任务样本均经过欧拉路径编码，保留原始文本属性。
在拒绝采样和任务均衡重采样之后，
本文将合成任务与真实任务按约 \(4:1\) 的比例混合，
得到规模约为
\(
|\mathcal{D}_{\text{CoT}}|\approx 2.0\times 10^4
\)
的思维链冷启动数据集，
其最终样本格式统一为三元组
\(
(G, q, y^\star)
\)，其中
\(
y^\star = (c^\star,a^\star)
\) 为标注目标输出，
\(c^\star\) 为符合图论逻辑的自然语言推理链，
\(a^\star\) 为与图算法真值一致的精确答案。

\subsubsection{结合教师模型与规则验证的拒绝采样式思维链生成}
\label{subsubsec:rejection_cot}

为获得高质量的思维链标注，
本文采用类似 G1\cite{Guo2025G1TL} 与 
DeepSeek-R1\cite{DeepSeekAI2025DeepSeekR1IR} 的教师模型采样及规则过滤的
拒绝采样策略自动生成 \(y^\star\)。

\textbf{教师模型与提示模板。}
选用 Qwen2.5-32B-Instruct 作为教师模型 \(\pi_{\text{teach}}\)，
其具备较强的通用推理与代码理解能力。
对于每个图–问题对 \((G,q)\)，首先将图结构编码 \(s = \Phi(G)\) 与
自然语言查询 \(q\) 拼接为统一的中文提示模板\(\text{Prompt}(G,q)\)：
% “给定图的结构编码s和查询q，
% 请先分步推导图推理过程，再给出最终答案。推理过程需严格遵循图论规则，
% 最终答案用\{\}包裹。”
\begin{prompt}{System Prompt}
你是一位图论专家，擅长通过结构化步骤解决图推理问题。请严格遵循以下流程：
1) 解析图结构；2) 逐步推导；3) 验证中间结果；4) 给出最终答案。
\end{prompt}

\begin{prompt}{Task Prompt}
图结构编码：$\langle s \rangle$。查询：$\langle q \rangle$。\\[0.3em]
推导过程需符合图论规则，每步推理必须基于图结构特征，
最终答案请用$\boxed{}$包起来。
\end{prompt}
该模板明确要求模型先解析欧拉路径编码的结构特征，再分步推导，
最后将答案标准化输出，显著提升生成推理链的结构一致性。

随后对候选序列进行采样。对于每个图–问题对 \((G,q)\)，采样策略如下：

（1）设置采样参数：温度系数\(T=1.0\)（平衡探索与利用），
Top-p阈值0.95（保留高概率token），
最大生成长度\(L_{\max}\)为图节点数的3倍，以此确保充分推理；
（2）采样$K=8$条独立候选序列$\{y_k\}_{k=1}^8$，
每条序列$y_k=(c_k,a_k)$包含推理链$c_k$和答案$a_k$；
（3）对序列进行基础清洗：移除未闭合的$\boxed{}$标签、截断重复循环、
过滤包含幻觉内容的序列（如虚构节点ID）。

\textbf{多维度规则验证器。}
为过滤无效或逻辑错误的候选，
针对不同任务类型设计规则验证器
\(
\mathcal{V}(G,q,y^{(k)})
\),
其输出可以是二元判定或 \([0,1]\) 区间的置信度得分。
本文采用“硬约束 + 软得分”的组合形式：
首先利用硬规则剔除结构明显错误的候选，
再基于可验证奖励函数 \(\mathcal{R}(G,q,y)\)
(公式~(\ref{eq:reward_function}))对剩余候选排序。

具体而言，验证逻辑按任务类型划分为三类：

\begin{itemize}
  \item \textit{数值型任务验证}（占比35.7\%）：针对节点数、图半径、聚类系数等任务，
  实现高精度数值校验模块。
  解析候选答案 \(a^{(k)}\) 中的数值 \(\hat{v}^{(k)}\)，
  与 NetworkX\cite{Rossi2015TheND}  计算的真值 \(v^\star\) 比较，一方面考虑整数完全一致；
  另一方面允许部分等价形式，
  支持分数-小数等价转换，例如 $\frac{1}{2}$  和0.5视为等价。
  处理浮点误差，误差阈值\(\epsilon=10^{-6}\)，并处理单位一致性（如"5个节点"与"5"视为一致）。
  记验证结果为
  \(
  \mathcal{V}_{\text{num}}(G,q,y^{(k)})\in\{0,1\}
  \)。

  \item \textit{集合型任务验证}（占比28.4\%）：
  针对公共邻居、最大独立集等集合答案，
  解析生成集合 \(\hat{S}^{(k)}\) 与真值集合 \(S^\star\)，
  核心指标是计算 Jaccard 系数，如公式~(\ref{eq:jaccard})所示：
  \begin{equation}
    \mathrm{Jacc}\!\left(S^\star,\hat{S}^{(k)}\right)
    =
    \frac{\big|S^\star \cap \hat{S}^{(k)}\big|}
         {\big|S^\star \cup \hat{S}^{(k)}\big|}.
    \label{eq:jaccard}
  \end{equation}
  当
  \(
  \mathrm{Jacc}(S^\star,\hat{S}^{(k)}) = 1
  \)
  时视为完全匹配，\(\mathcal{V}_{\text{set}}=1\)；否则记为 \(0\)。
此外，对顺序敏感任务（如排序列表），
引入Levenshtein距离验证序列顺序；对部分匹配任务（如近似最大独立集），
设计动态阈值$J\geq0.95$作为软性标准。
  \item \textit{路径/结构型任务验证}（占比35.9\%）：实现图论验证器库，包含：
\begin{itemize}
    \item \textit{路径合法性验证}：检查路径连通性（路径中相邻节点必须有边连接）、无重复节点访问（除欧拉回路外）、起点终点正确性。
    \item \textit{最优性验证}：对最短路径等优化任务，调用NetworkX\cite{Rossi2015TheND} 的Dijkstra算法获取全局最优解，比较生成路径长度是否等于最短距离。
    \item \textit{结构完整性验证}：对子图同构、桥边检测等任务，通过图同构算法（VF2）或边割检测验证结构等价性。
\end{itemize}
\end{itemize}

将上述验证结果整合为整体可验证奖励
\(
\mathcal{R}(G,q,y^{(k)})
\)
（具体定义见式~(\ref{eq:reward_function})），再结合对推理链长度、格式完整性（必须显式包含“Reasoning:”与“Final Answer:”段落）等启发式约束，
得到最终的接受判定，如公式~(\ref{eq:accept_rule})所示：
\begin{equation}
  \mathcal{A}(G,q,y^{(k)})
  =
  \mathbb{I}\!\Big[
    \mathcal{R}(G,q,y^{(k)}) \ge \tau_{\mathrm{CoT}}
  \Big],
  \label{eq:accept_rule}
\end{equation}
其中 \(\tau_{\mathrm{CoT}}\) 为经验设定的阈值，
\(\mathbb{I}[\cdot]\) 为指示函数。

\textbf{拒绝采样与样本选取。}
对每个 \((G,q)\) 实例，首先从 \(K\) 条候选中选出所有满足
\(
\mathcal{A}(G,q,y^{(k)}) = 1
\)
的有效集合
\(
\mathcal{Y}_{\text{valid}}(G,q)
\)。
若
\(
|\mathcal{Y}_{\text{valid}}(G,q)| = 0
\)，则重复采样过程直至获得至少一条有效序列或达到最大尝试次数。
当存在多个有效候选时，按照奖励得分选取奖励最高的那条作为最终监督标签，
起计算过程如公式~(\ref{eq:best_of_n})所示：
\begin{equation}
  y^\star(G,q)
  =
  \arg\max_{y^{(k)} \in \mathcal{Y}_{\text{valid}}(G,q)}
  \mathcal{R}(G,q,y^{(k)}).
  \label{eq:best_of_n}
\end{equation}
最终得到的思维链监督数据集可写为公式~(\ref{eq:cot_dataset_def})：
\begin{equation}
  \mathcal{D}_{\text{CoT}}
  =
  \Big\{
    \big(G_i, q_i, y_i^\star\big)
  \Big\}_{i=1}^{N_{\text{CoT}}},
  \qquad
  N_{\text{CoT}} \approx 4.8\times 10^4.
  \label{eq:cot_dataset_def}
\end{equation}

\textbf{人工抽检与语义质量控制。}
验证流程采用级联过滤策略：
\begin{itemize}
\item \textit{一级过滤}：应用规则验证器\(
  \mathcal{V}_{\text{num}}(G,q,y^{(k)})
  \)对每条候选序列输出二元判定（有效/无效）或置信度得分。
\item \textit{二级筛选}：仅保留验证器判定为"有效"的序列；若有效序列数为0，则调整采样参数（$T\leftarrow T-0.2$）重新生成；若有效序列数超过1，按生成概率排序选取最高置信度序列。

\item \textit{三级人工抽检}：对最终选取的序列进行10\%比例的人工抽检，制定严格质量标准：
\begin{itemize}
    \item \textit{逻辑一致性}：检查推理步骤是否自洽，是否存在矛盾（如先声明"节点无邻居"，后又使用该邻居计算度数）
    \item \textit{结构合理性}：验证中间推理是否符合图论基本原理（如三角不等式、连通性约束等）
    \item \textit{表述清晰度}：过滤表述冗余、语义模糊的推理链，强制要求关键步骤包含图结构特征引用
\end{itemize}
\end{itemize}

抽检不合格样本被替换为次高置信度有效序列，或标记为难样本进行重点分析。
对于存在严重冗余或逻辑问题的样本予以剔除或人工修正，
从而提升数据集整体的语义质量与可读性。

综上，本文基于拒绝采样范式，在图算法可验证器的支撑下构建了一个规模可观、结构可验证且语义高质量的图推理思维链数据集 \(\mathcal{D}_{\text{CoT}}\)，为后续冷启动微调与基于 GRPO 的强化学习提供了坚实的数据基础。

\subsection{思维链监督微调目标建模}
\label{subsec:cot_sft_objective}

在获得思维链监督数据集 \(\mathcal{D}_{\mathrm{CoT}}\) 后，
本文将前文构建的图基座模型视作条件语言模型，
对其解码器执行基于合成思维链数据集的自回归监督微调（CoT-SFT），
显式对齐“图结构–查询–推理链–答案”的生成分布，从
而为后续基于可验证奖励的强化学习阶段提供结构化的初始策略。

为与第~\ref{sec:graph_llm_inference} 节中的推理模板保持一致，
记第 \(i\) 个训练样本的图–问题对为 \((G_i,q_i)\)，
其对应的监督目标为 \(y_i^\star = (c_i^\star,a_i^\star)\)，
其中 \(c_i^\star\) 为思维链、\(a_i^\star\) 为最终答案。
输入侧首先由系统提示、任务提示、图结构编码与自然语言查询拼接而成，
其公式定义如~(\ref{eq:cot_input_seq})所示：
\begin{equation}
  x_i
  =
  P_{\mathrm{sys}}
  \oplus
  P_{\mathrm{task}}(t_i)
  \oplus
  \mathrm{EncGraph}(G_i)
  \oplus
  q_i,
  \label{eq:cot_input_seq}
\end{equation}

其中 \(P_{\mathrm{sys}}\) 为固定系统提示，\(P_{\mathrm{task}}(t_i)\) 
为标明任务类型 \(t_i\) 的自然语言前缀；
\(\mathrm{EncGraph}(\cdot)\) 
表示将图 \(G_i\) 欧拉化并经图编码器 \(\mathrm{Enc}_G\) 与
跨模态投影层映射到语言嵌入空间的过程，
\(\oplus\) 表示在序列维度上的拼接操作。
输出侧构造包含 “\texttt{Reasoning:}” 段落与 “\texttt{Final Answer:}” 
段落的完整目标序列，其公式定义如~(\ref{eq:cot_output_seq})所示：
\begin{equation}
  y_i
  =
  \mathrm{format}\big(c_i^\star,a_i^\star\big),
  \label{eq:cot_output_seq}
\end{equation}
其中 \(\mathrm{format}(\cdot)\) 为固定文本模板函数，将推理过程与最终答案封装为规范化的 CoT 文本，使训练与推理阶段在输出格式上保持一致。

在 CoT-SFT 阶段，图欧拉路径编码器 \(\mathrm{Enc}_G\)、文本特征编码器
 \(\mathrm{Enc}_T\) 以及跨模态对齐模块参数均保持冻结，
 仅更新语言模型解码器 \(\mathrm{Dec}_T\) 及其上附加的轻量适配层
 （如 LoRA/MLP 投影层）。记可训练参数集合为 \(\theta_{\mathrm{CoT}}\)，
 则训练目标可形式化为在 \(\mathcal{D}_{\mathrm{CoT}}\) 上
 最小化条件语言模型的负对数似然损失，其公式定义如~(\ref{eq:cot_sft_loss})所示：
\begin{equation}
  \mathcal{L}_{\mathrm{CoT\text{-}SFT}}(\theta_{\mathrm{CoT}})
  =
  - \mathbb{E}_{(x,y)\sim\mathcal{D}_{\mathrm{CoT}}}
  \sum_{t=1}^{|y|}
  \log p_{\theta_{\mathrm{CoT}}}\big(y_t \mid x, y_{<t}\big),
  \label{eq:cot_sft_loss}
\end{equation}
其中 \(y_t\) 表示输出序列在位置 \(t\) 的目标 Token，\(y_{<t}\) 为其之前的前缀。
~\eqref{eq:cot_sft_loss} 
与第~\ref{sec:training_sft} 节给出的通用监督微调目标式~(\ref{eq:Standard_supervision_fine_tuning_loss}) 在形式上一致，但此处的目标序列显式包含完整思维链与最终答案，从而将“先推理、后作答”的生成模式内化为条件分布的一部分，而非仅对最终答案进行标注。

在具体实现中，本文采用标准的 Teacher Forcing 策略，即在每个时间步 \(t\) 使用真实前缀 \(y_{<t}\) 作为条件，训练解码器预测下一个 Token \(y_t\)，并在损失计算时仅对助手回复（即 “\texttt{Reasoning:}” 和 “\texttt{Final Answer:}” 段落）对应的位置施加监督，系统提示与用户提示部分不参与梯度更新。
与 DeepSeek-R1 和 G1 中的 CoT-SFT 阶段类似，本文对推理链与答案部分采用统一权重的全序列监督，而不额外区分链内/链外 Token 的重要性。
实验结果表明，这一简单而统一的目标已足以显著提升模型在图论任务上的思维链可读性与答案可验证性，并为后续基于可验证奖励的 RL 阶段提供稳定且结构化的初始策略。

\subsection{冷启动阶段的训练策略与实现}
\label{subsec:cot_sft_train_detail}

为了在有限算力预算下高效提升图推理能力，同时尽量保留预训练语言模型的通用知识，本文在 CoT-SFT 阶段采用了参数冻结、任务均衡采样与稳定优化相结合的训练策略。

\begin{itemize}
  \item \textbf{任务混合与采样策略。}
  思维链监督数据集 \(\mathcal{D}_{\mathrm{CoT}}\) 覆盖从 Easy 到 Challenging 的多类图论任务，并同时包含合成图与真实图样本。
  训练时对不同任务类型采用近似均匀的采样概率，而非按照原始频率分布直接采样，避免模型在冷启动阶段过度拟合少数简单任务，从一开始就接触多样化的拓扑结构与推理模式。
  对于极少数复杂任务（如 NP-hard 组合优化类），适当提高采样比例，以增强模型对高难度推理模式的记忆。

  \item \textbf{参数冻结与轻量适配。}
  为防止前期通过对比学习和节点分类训练获得的图–文对齐关系在 CoT-SFT 中被破坏，图欧拉路径编码器 \(\mathrm{Enc}_G\)、文本编码器 \(\mathrm{Enc}_T\) 与跨模态投影层在整个冷启动阶段保持完全冻结。
  在语言模型主干 \(\mathrm{Dec}_T\) 内，仅在注意力投影与前馈网络中插入低秩适配模块（如 LoRA）或轻量 MLP 投影层作为可训练参数，记其集合为 \(\theta_{\mathrm{CoT}}\)。
  这一设计遵循参数高效微调（PEFT）的通行做法，在显著降低训练开销的同时，将更新严格限制在“推理策略”层面，最大程度保留预训练模型的通用语言能力。

  \item \textbf{优化器与学习率调度。}
  本文采用 AdamW 优化器，对 \(\theta_{\mathrm{CoT}}\) 使用较小基准学习率，并结合线性预热与余弦退火日程控制训练过程的平稳收敛。
  同时引入梯度裁剪抑制极端样本引发的梯度爆炸，配合混合精度训练（FP16/BF16）降低显存开销。
  每个训练样本的总长度被限制在预训练模型的上下文窗口内，对超长思维链在保证 “\texttt{Final Answer:}” 段落完整的前提下进行尾部截断，以平衡推理链细节与训练成本。

  \item \textbf{正则化与稳定性控制。}
  为减轻灾难性遗忘，训练过程中对可训练参数施加适度权重衰减，并在小比例通用指令数据上进行混合训练，使模型在获得图推理能力的同时保留基本的指令遵循与对话能力。
  此外，在早期若干个 epoch 内，监控验证集上思维链长度分布与可验证奖励 \(\mathcal{R}(G,q,y)\) 的统计量，防止模型陷入“极短答案”（跳过推理）或“无约束长链”（冗余推理）两种极端模式，一旦发现趋势异常，则通过降低学习率或增加通用指令样本比例进行修正。
\end{itemize}

通过上述思维链监督冷启动微调，本文在不引入额外人工标注的前提下，使图基座模型获得一套稳定且结构化的图推理初始策略：一方面，模型学会在统一的图–文提示格式下生成步骤清晰、与图算法真值一致的推理链；另一方面，在面对合成与真实图任务时，其答案质量与可验证性均显著优于原始指令模型。
该阶段训练得到的参数
\(
\theta_{\mathrm{CoT}}^\ast
\)
将作为后续 GRPO 强化学习阶段的初始化，为基于可验证奖励的策略优化提供结构良好、分布合理的起点。


\section{可验证奖励与GRPO强化学习训练微调}
\label{sec:grpo_rl}

在第~\ref{sec:cot_sft} 节中，本文通过思维链监督微调（CoT-SFT）将图基座模型初始化为具备基本“先推理、后作答”行为的条件语言模型，得到参数
\(\theta_{\mathrm{CoT}}^\ast\)。
然而，受限于监督数据规模与分布偏差，仅依靠 CoT-SFT 难以充分挖掘模型在复杂图论任务中的潜在推理能力，也难以确保在更宽泛任务分布上的鲁棒性。
近期工作表明，将大语言模型视作策略，结合可扩展的规则奖励进行强化学习，
是增强推理能力的有效途径：G1 在图论任务上采用基于 GRPO 的强化学习配合规则奖励，
实现了显著性能提升\cite{Guo2025G1TL}；
DeepSeek-R1 则在数学、代码等领域通过大规模 RL 与
规则/可验证奖励大幅增强了模型的推理表现\cite{DeepSeekAI2025DeepSeekR1IR}。
受此启发，本文在 CoT-SFT 初始化的基础上，
引入 基于组式策略优化（Group Relative Policy Optimization, GRPO）\cite{Shao2024DeepSeekMathPT} 的强化学习阶段，
并围绕图推理特点设计可验证的规则奖励函数，使模型在保持图论正确性的前提下进一步自我提升。
区别于传统依赖人类偏好的强化学习方法（如PPO-DPO），
本框架通过规则化、可程序验证的自动奖励机制引导策略优化，无需人工标注偏好数据即可规模化训练。
该方法将强化学习目标与图论先验知识深度融合，
使模型在合成图任务上习得可迁移的通用推理能力，并在真实图任务上展现出卓越的零样本泛化性能。

在本节中，本文首先在
~\ref{subsec:rule_reward_design} 节给出面向图推理的可验证奖励设计，
再在第~\ref{subsec:grpo_objective} 节中形式化推导 GRPO 训练目标与基模约束，
并在第~\ref{subsec:grpo_train_detail} 节系统说明强化学习训练流程与工程细节。

\subsection{规则化可验证奖励建模}
\label{subsec:rule_reward_design}
\subsubsection{奖励建模问题设定与总体设计思路}

规则可验证奖励机制是本框架的核心创新，
其设计目标是在无需人工干预的前提下，为不同类型的图推理任务提供精确、细粒度且可扩展的自动化测评信号。
该机制通过可程序验证的规则系统对模型生成的推理链与答案进行即时评判，生成连续值奖励信号指导策略优化。
与传统人工偏好标注相比，规则可验证奖励具有三重优势：
其一，测评结果完全客观且可复现；
其二，奖励信号可在训练过程中动态生成，支持无限规模的数据扩展；
其三，奖励设计直接关联图论基本原理，引导模型学习符合数学规律的推理模式，而非拟合人类标注的统计偏好。

在强化学习阶段，图推理任务被视为一个单步决策过程：
给定图–问题对 \((G,q)\)，策略模型 \(\pi_\theta\)（以 \(\theta_{\mathrm{CoT}}^\ast\) 为初始化）生成包含思维链与答案的完整输出
\(
y = (c,a)
\)，
环境随后通过图算法验证器与格式检查器对 \(y\) 进行测评，
返回标量奖励
\(
\mathcal{R}(G,q,y) \in \mathbb{R}
\)，
作为 GRPO 中的回报信号。
本文将奖励函数拆分为四个可解释分量：
答案正确性奖励、拓扑一致性奖励、格式与可读性奖励以及长度正则项，
其整体形式化定义如公式~(\ref{eq:reward_function}) 所示：
\begin{equation}
  \mathcal{R}(G,q,y)
  =
  \lambda_{\mathrm{ans}} \, R_{\mathrm{ans}}(G,q,a)
  +
  \lambda_{\mathrm{topo}} \, R_{\mathrm{topo}}(G,q,c,a)
  +
  \lambda_{\mathrm{fmt}} \, R_{\mathrm{fmt}}(y)
  +
  \lambda_{\mathrm{len}} \, R_{\mathrm{len}}(y),
  \label{eq:reward_function}
\end{equation}
其中
\(
\lambda_{\mathrm{ans}},\lambda_{\mathrm{topo}},\lambda_{\mathrm{fmt}},\lambda_{\mathrm{len}} \ge 0
\)
为超参数权重，控制各分量的相对重要性。
在实现中，各分量均被归一化至 \([0,1]\) 区间，以便于在不同任务与批次间保持数值稳定。

\subsubsection{答案正确性奖励 \(R_{\mathrm{ans}}\)的规则化建模}

答案正确性是图推理任务最核心、也最易通过规则验证的部分。
延续 CoT 数据构建阶段的验证器设计（见第~\ref{subsubsec:rejection_cot} 节），
本文参照“值匹配–集合匹配–算法验证”三类规则奖励\cite{Guo2025G1TL}，
针对不同任务类型定义统一的答案正确性奖励
\(R_{\mathrm{ans}}\)。

\textbf{（1）数值型任务：严格值匹配。}
对于具有唯一数值真值的任务（如节点数、边数、图直径等），
首先从最终答案片段 \(a\) 中解析出标量
\(\hat{v}\)，并通过 NetworkX\cite{Rossi2015TheND} 计算真值
\(v^\star\)。
为兼容分数/小数等等价表达，采用“数值等价”判定而非字符串匹配。
对应的奖励定义为公式~(\ref{eq:reward_num})所示：
\begin{equation}
  R_{\mathrm{ans}}^{\mathrm{num}}(G,q,a)
  =
  \mathbb{I}\big[\mathrm{equiv}(\hat{v}, v^\star)\big],
  \label{eq:reward_num}
\end{equation}
其中 \(\mathbb{I}[\cdot]\) 为指示函数，\(\mathrm{equiv}(\cdot,\cdot)\) 表示在给定容差下的数值一致性检查。
该设计与 G1 中的 strict value matching 保持一致\cite{Guo2025G1TL}。

\textbf{（2）集合型任务：Jaccard 集合匹配。}
对于答案为无序节点集合或边集合的任务（如公共邻居、最大独立集候选等），
从答案片段 \(a\) 中解析生成集合
\(\hat{S}\)，并由图算法求得真值集合 \(S^\star\)。
奖励定义为生成集合与真值集合的 Jaccard 系数（公式~(\ref{eq:jaccard}) 在此复用）：
\begin{equation}
  R_{\mathrm{ans}}^{\mathrm{set}}(G,q,a)
  =
  \mathrm{Jacc}\big(S^\star,\hat{S}\big)
  =
  \frac{\big|S^\star \cap \hat{S}\big|}
       {\big|S^\star \cup \hat{S}\big|},
  \label{eq:reward_set}
\end{equation}
\(\mathrm{Jacc}(\cdot,\cdot) \in [0,1]\) 为连续奖励，使得模型在集合任务中即便部分正确也能获得非零回报。

\textbf{（3）路径/结构型任务：算法可验证奖励。}
对于最短路径、哈密顿路径、欧拉路径以及图同构等结构型任务，
答案通常为节点序列或映射，存在多个正确解且难以穷举
本文为每类任务实现对应的算法验证器：
从 \(a\) 中解析出路径
\(\hat{P} = (v_0,\dots,v_L)\) 或映射 \(\hat{f}\)，
依次检查：
（i）所有相邻节点对 \((v_i,v_{i+1})\) 是否为 \(G\) 中的边；
（ii）是否满足“每节点访问一次”“覆盖指定端点/节点集”等结构约束；
（iii）对最短路径任务，还需检查路径长度是否等于全局最短距离。
若所有约束均满足，则给予奖励 $1$，否则为 $0$，其公式定义如~(\ref{eq:reward_path})：
\begin{equation}
  R_{\mathrm{ans}}^{\mathrm{path}}(G,q,a)
  =
  \mathbb{I}\big[\mathrm{VerifyPath}(G,q,\hat{P}) = \mathrm{true}\big].
  \label{eq:reward_path}
\end{equation}

综合上述三类任务，答案正确性奖励统一写为公式~(\ref{eq:reward_ans_all})：
\begin{equation}
  R_{\mathrm{ans}}(G,q,a)
  =
  \begin{cases}
    R_{\mathrm{ans}}^{\mathrm{num}}(G,q,a),  & \text{数值型任务}, \\
    R_{\mathrm{ans}}^{\mathrm{set}}(G,q,a),  & \text{集合型任务}, \\
    R_{\mathrm{ans}}^{\mathrm{path}}(G,q,a), & \text{路径/结构型任务}.
  \end{cases}
  \label{eq:reward_ans_all}
\end{equation}

\subsubsection{图拓扑一致性奖励 \(R_{\mathrm{topo}}\)的过程约束}

仅考察最终答案正确性仍可能导致模型“直接给结果而不解释”，或在 CoT 中出现与图结构不一致的推理步骤。
为引导模型学习符合图论规则的“结构化思维链”，
本文在 DeepSeek-R1 的“过程可读性奖励”思想\cite{DeepSeekAI2025DeepSeekR1IR}基础上，
进一步引入面向图拓扑的一致性奖励 \(R_{\mathrm{topo}}\)。

给定输出 \(y=(c,a)\)，
首先对思维链 \(c\) 进行结构化解析：
利用正则规则与简单的语法分析，将其中出现的节点 ID、边对、路径描述等符号化为序列
\(\mathcal{E}_c\) 与 \(\mathcal{P}_c\)。
在此基础上，定义两个互补的拓扑一致性分量：

\textbf{（1）边/节点引用合法性。}
统计思维链中引用的边/节点在真实图中的合法比例，其公式定义如~(\ref{eq:reward_topo_valid})所示：
\begin{equation}
  R_{\mathrm{topo}}^{\mathrm{valid}}(G,c)
  =
  \frac{
    |\{(u,v)\in\mathcal{E}_c : (u,v)\in E(G)\}| + |\{v\in\mathcal{V}_c : v\in V(G)\}|
  }{
    |\mathcal{E}_c| + |\mathcal{V}_c| + \varepsilon
  },
  \label{eq:reward_topo_valid}
\end{equation}
其中 \(\mathcal{V}_c\) 为思维链中出现的节点集合，\(\varepsilon\) 为防止分母为零的极小常数。
当思维链频繁引用不存在的节点或边时，\(R_{\mathrm{topo}}^{\mathrm{valid}}\) 会显著下降。

\textbf{（2）推理路径与答案路径的一致性。}
对于以路径为答案的任务，从思维链中提取“中间路径”或“候选路径”集合 \(\{\tilde{P}_j\}\)，
并与最终答案路径 \(\hat{P}\) 的边集进行比较。
直观地，希望模型在 CoT 中呈现的推理步骤与最终给出的路径在拓扑上高度一致。
对应奖励可写为~(\ref{eq:reward_topo_path})：
\begin{equation}
  R_{\mathrm{topo}}^{\mathrm{path}}(G,c,a)
  =
  \max_j
  \mathrm{Jacc}\big(E(\tilde{P}_j), E(\hat{P})\big),
  \label{eq:reward_topo_path}
\end{equation}
其中 \(E(\cdot)\) 表示路径对应的边集合，\(\mathrm{Jacc}(\cdot,\cdot)\) 为式~(\ref{eq:jaccard}) 中的 Jaccard 系数。
当模型在推理链中描述的路径与最终答案路径几乎一致时，
\(R_{\mathrm{topo}}^{\mathrm{path}}\) 接近 1，否则接近 0。

最终，拓扑一致性奖励综合上述两项，公式定义如~(\ref{eq:reward_topo_all})所示：
\begin{equation}
  R_{\mathrm{topo}}(G,q,c,a)
  =
  \alpha_{\mathrm{valid}} R_{\mathrm{topo}}^{\mathrm{valid}}(G,c)
  +
  \alpha_{\mathrm{path}} R_{\mathrm{topo}}^{\mathrm{path}}(G,c,a),
  \label{eq:reward_topo_all}
\end{equation}
其中 \(\alpha_{\mathrm{valid}},\alpha_{\mathrm{path}}\) 为归一化权重。
该设计在保证最终答案正确的基础上，进一步鼓励“图上推理过程”的真实可追溯性。

\subsubsection{输出格式与语言可读性奖励 \(R_{\mathrm{fmt}}\)}

本文发现仅基于准确率的奖励容易使 CoT 出现语言混杂、格式混乱等问题，因此引入了语言一致性与格式奖励，以提高输出的可读性\cite{DeepSeekAI2025DeepSeekR1IR}。
本文采用类似思想，为图推理场景定义轻量的格式与可读性奖励 \(R_{\mathrm{fmt}}\)，约束模型在强化学习阶段保持统一的输出结构与目标语言。
具体而言，格式奖励由两部分组成：

\textbf{（1）结构标签完整性。}
要求模型输出的 CoT 严格遵循
“\texttt{Reasoning:} … \texttt{Final Answer:} …” 的固定模板。
记
\(\mathrm{hasTag}(y)\in\{0,1\}\) 表示是否包含全部必要标签，
则有公式表示如~(\ref{eq:reward_fmt_tag})所示：
\begin{equation}
  R_{\mathrm{fmt}}^{\mathrm{tag}}(y)
  =
  \mathrm{hasTag}(y).
  \label{eq:reward_fmt_tag}
\end{equation}

\textbf{（2）语言与标点一致性。}
本文计算 CoT 部分中目标语言（中文）词/字符比例，
并惩罚混入大量其他语言或无意义符号的情况，公式表示如~(\ref{eq:reward_fmt_lang})所示：
\begin{equation}
  R_{\mathrm{fmt}}^{\mathrm{lang}}(y)
  =
  \frac{\#\text{中文字符}(c)}{\#\text{全部字符}(c) + \varepsilon},
  \label{eq:reward_fmt_lang}
\end{equation}
其中 \(\varepsilon\) 为极小常数。
当模型在推理过程中大量使用非中文或符号噪声时，奖励会显著降低。

综合上述两项，格式与可读性奖励写为~(\ref{eq:reward_fmt_all})所示：
\begin{equation}
  R_{\mathrm{fmt}}(y)
  =
  \beta_{\mathrm{tag}} R_{\mathrm{fmt}}^{\mathrm{tag}}(y)
  +
  \beta_{\mathrm{lang}} R_{\mathrm{fmt}}^{\mathrm{lang}}(y),
  \label{eq:reward_fmt_all}
\end{equation}
其中 \(\beta_{\mathrm{tag}},\beta_{\mathrm{lang}}\) 为权重超参数。

\subsubsection{思维链长度正则化项 \(R_{\mathrm{len}}\)}

在实际训练中，过短的 CoT 往往意味着缺乏足够解释，而过长的 CoT 则可能包含冗余推理甚至“幻觉步骤”。
为此，本文设计了一个简单的长度正则项，用于鼓励 CoT 长度落在经验上合理的范围。
设输出序列的 Token 长度为 \(|y|\)，目标长度区间为
\([L_{\min}, L_{\max}]\)，则定义其公式如~(\ref{eq:reward_len})所示：
\begin{equation}
  R_{\mathrm{len}}(y)
  =
  \begin{cases}
    1, & \text{若 } L_{\min} \le |y| \le L_{\max}, \\
    \exp\big(-\gamma \cdot d(|y|,[L_{\min},L_{\max}])\big), & \text{否则},
  \end{cases}
  \label{eq:reward_len}
\end{equation}
其中
\(d(|y|,[L_{\min},L_{\max}])\) 表示长度偏离区间的距离，
\(\gamma>0\) 控制惩罚强度。
该项与准确率奖励相加后，可有效抑制极端短链或“无穷长链”的出现。

\subsubsection{可验证奖励函数的分解与性质小结}

综上，本文在规则结果奖励与 
推理导向奖励建模框架基础上，
针对图推理任务设计了一个完全可验证、可分解的奖励函数 \(\mathcal{R}(G,q,y)\)（式~(\ref{eq:reward_function})）：
既依托图算法与结构验证器确保答案与路径的拓扑正确性，
又通过格式与长度约束维持思维链的可读性与稳定性。
在后续 GRPO 训练中，这一奖励将作为唯一的环境反馈信号，
用于驱动策略在图推理空间中不断自我优化。

\subsection{GRPO 策略优化目标与基模约束}
\label{subsec:grpo_objective}

在 CoT-SFT 阶段获得初始策略
\(
\pi_{\theta_{\mathrm{CoT}}^\ast}
\)
之后，本文进一步引入基于
GRPO（Group Relative Policy Optimization）\cite{Shao2024DeepSeekMathPT}
的强化学习阶段，对图推理策略进行面向奖励的细化优化。
GRPO 通过组内轨迹的相对奖励构造优势信号，同时结合 KL 散度正则项锚定
CoT-SFT 阶段的基模策略，在提升图推理性能的同时抑制策略退化与语言能力坍缩。
与 DeepSeek-R1\cite{DeepSeekAI2025DeepSeekR1IR} 类似，
本文将每个图–问题对 \((G_i,q_i)\) 视为一次完整的环境交互回合，模型在条件输入
\(x_i\)（~\eqref{eq:cot_input_seq}）下自回归生成推理–答案序列
\(y=(c,a)\)，在序列结束时由可验证奖励函数
\(\mathcal{R}(G_i,q_i,y)\)（~\eqref{eq:reward_function}）给出单步回合回报。

整体过程形式化如算法~\ref{alg:grpo_graph_reasoning}所示，
\begin{algorithm}[t]
\caption{基于 GRPO 的图推理强化学习训练流程}
\label{alg:grpo_graph_reasoning}
\KwIn{冷启动后图推理基座参数 $\theta_{\mathrm{CoT}}^\ast$；RL 训练任务集 $\mathcal{D}_{\mathrm{RL}}$；组大小 $G$；批次大小 $B$；最大训练步数 $T_{\max}$}
\KwOut{强化学习后的策略参数 $\theta_{\mathrm{RL}}^\ast$}

初始化当前策略参数 $\theta \gets \theta_{\mathrm{CoT}}^\ast$，旧策略参数 $\theta_{\mathrm{old}} \gets \theta$，参考基模参数 $\theta_{\mathrm{ref}} \gets \theta$\;

\For{$t \gets 1$ \KwTo $T_{\max}$}{
  从 $\mathcal{D}_{\mathrm{RL}}$ 中采样一个批次图--问题对 $\{(G_i,q_i)\}_{i=1}^B$\;
  \For{$i \gets 1$ \KwTo $B$}{    % 组内多轨迹采样与奖励计算
    构造条件输入提示 $x_i$（包含系统提示、任务提示、图编码与查询）\;
    \For{$g \gets 1$ \KwTo $G$}{
      用旧策略采样一条推理--答案轨迹 $y_i^{(g)} \sim \pi_{\theta_{\mathrm{old}}}(\cdot \mid x_i)$\;
      调用规则验证器计算可验证奖励 $r_i^{(g)} \gets \mathcal{R}(G_i,q_i,y_i^{(g)})$\;
    }
    由 $\{r_i^{(g)}\}_{g=1}^G$ 计算组内均值与方差，得到标准化优势 $A_i^{(g)}$\;
    计算序列级比率 $\rho_i^{(g)}$，构造裁剪后的策略损失 $\mathcal{L}_i^{\mathrm{policy}}$\;
    计算相对参考策略 $\pi_{\theta_{\mathrm{ref}}}$ 的 KL 正则项 $\mathcal{L}_i^{\mathrm{KL}}$\;
    得到样本级损失 $\mathcal{L}_i^{\mathrm{GRPO}} \gets \mathcal{L}_i^{\mathrm{policy}} + \mathcal{L}_i^{\mathrm{KL}}$\;
  }
  计算批次损失 $\mathcal{L}_{\mathrm{GRPO}} \gets \frac{1}{B}\sum_{i=1}^{B} \mathcal{L}_i^{\mathrm{GRPO}}$\;
  计算梯度 $g \gets \nabla_{\theta} \mathcal{L}_{\mathrm{GRPO}}$，并进行梯度裁剪 $\|g\|_2 \le 1.0$\;
  按调度器更新学习率，使用 AdamW 更新策略参数 $\theta$\;

  \If{$t \bmod 100 = 0$}{
    同步旧策略参数：$\theta_{\mathrm{old}} \gets \theta$\;
  }

  \If{$t \bmod T_{\mathrm{eval}} = 0$}{
    在验证集上测评平均奖励、答案正确率和 KL 散度等指标，更新并保存最佳模型检查点\;
  }
}
\Return{$\theta_{\mathrm{RL}}^\ast \gets \theta$}\;
\end{algorithm}
具体而言，对第 \(i\) 个样本，从当前旧策略
\(
\pi_{\theta_{\mathrm{old}}}
\)
在同一条件输入 \(x_i\) 上采样一组候选轨迹，
其定义如~\eqref{eq:grpo_sample}：
\begin{equation}
  y_i^{(g)}
  \sim
  \pi_{\theta_{\mathrm{old}}}(\cdot \mid x_i),
  \quad
  g = 1,\dots,G,
  \label{eq:grpo_sample}
\end{equation}
其中 \(G\) 为组大小（实验中设为 \(G=5\)）。
对每条轨迹 \(y_i^{(g)}\) 计算奖励
\(
r_i^{(g)} = \mathcal{R}(G_i,q_i,y_i^{(g)})
\)，
并在组内进行标准化以获得相对优势
\(A_i^{(g)}\)，其定义如~\eqref{eq:grpo_adv}：
\begin{equation}
  A_i^{(g)}
  =
  \frac{
    r_i^{(g)} - \mu_i
  }{
    \sigma_i + \epsilon
  },
  \quad
  \mu_i = \frac{1}{G}\sum_{g=1}^G r_i^{(g)},
  \quad
  \sigma_i^2 = \frac{1}{G}\sum_{g=1}^G \big(r_i^{(g)} - \mu_i\big)^2,
  \label{eq:grpo_adv}
\end{equation}
其中 \(\mu_i\) 与 \(\sigma_i\) 分别为第 \(i\) 个样本在组内的奖励均值与标准差，
\(\epsilon=10^{-8}\) 为数值稳定项。
该设计仅依赖组内奖励的相对排序而非绝对尺度，
在不同任务奖励区间差异较大时仍能提供稳定的优势信号。

为限制策略更新幅度，GRPO 采用与 PPO 一致的裁剪思想。
记新策略与旧策略在轨迹 \(y_i^{(g)}\) 上的序列级对数概率分别为
\(\log \pi_\theta(y_i^{(g)}\!\mid x_i)\) 与
\(\log \pi_{\theta_{\mathrm{old}}}(y_i^{(g)}\!\mid x_i)\)，
则序列级重要性权重比率定义如~\eqref{eq:grpo_ratio}：
\begin{equation}
  \rho_i^{(g)}(\theta)
  =
  \frac{
    \pi_\theta\big(y_i^{(g)} \mid x_i\big)
  }{
    \pi_{\theta_{\mathrm{old}}}\big(y_i^{(g)} \mid x_i\big)
  }
  =
  \exp\!\Big(
    \log \pi_\theta(y_i^{(g)}\!\mid x_i)
    -
    \log \pi_{\theta_{\mathrm{old}}}(y_i^{(g)}\!\mid x_i)
  \Big),
  \label{eq:grpo_ratio}
\end{equation}
其中
\(
\log\pi_\theta(y_i^{(g)}\!\mid x_i)
=
\sum_t \log p_\theta(y_{i,t}^{(g)} \mid x_i, y_{i,<t}^{(g)})
\)
由语言模型的自回归概率沿轨迹累积得到。
在此基础上，构造裁剪后的策略损失，如~\eqref{eq:grpo_policy_loss}：
\begin{equation}
  \mathcal{L}^{\mathrm{policy}}_i(\theta)
  =
  -\frac{1}{G} \sum_{g=1}^G
  \min \Big(
    \rho_i^{(g)}(\theta)\, A_i^{(g)},
    \mathrm{clip}\big(\rho_i^{(g)}(\theta), 1-\varepsilon_{\mathrm{clip}}, 1+\varepsilon_{\mathrm{clip}}\big)\, A_i^{(g)}
  \Big),
  \label{eq:grpo_policy_loss}
\end{equation}
其中 \(\varepsilon_{\mathrm{clip}}=0.2\) 为裁剪阈值。
当 \(A_i^{(g)}>0\) 时，损失鼓励新策略提高高奖励轨迹的概率，但通过
\(\mathrm{clip}(\cdot)\) 限制权重过大；
当 \(A_i^{(g)}<0\) 时，则抑制低奖励轨迹的概率，同时避免过度更新导致策略振荡。

为防止强化学习阶段策略偏离 CoT-SFT 阶段学到的结构化推理范式，本文引入 KL 散度正则项，将
CoT-SFT 后的策略
\(\pi_{\mathrm{ref}}=\pi_{\theta_{\mathrm{CoT}}^\ast}\) 作为冻结参考基模，
约束新策略与之的分布距离。
借鉴 DeepSeek-R1\cite{DeepSeekAI2025DeepSeekR1IR}，本文采用序列级“反向 KL”近似：
\begin{equation}
  \mathcal{L}^{\mathrm{KL}}_i(\theta)
  =
  \frac{\beta}{G}
  \sum_{g=1}^G
  \Bigg(
    \frac{\pi_{\mathrm{ref}}(y_i^{(g)}\!\mid x_i)}{\pi_\theta(y_i^{(g)}\!\mid x_i)}
    -
    \log
    \frac{\pi_{\mathrm{ref}}(y_i^{(g)}\!\mid x_i)}{\pi_\theta(y_i^{(g)}\!\mid x_i)}
    - 1
  \Bigg),
  \label{eq:grpo_kl}
\end{equation}
其中 \(\beta = 1\times10^{-3}\) 控制 KL 惩罚强度。
该形式可视为对
\(D_{\mathrm{KL}}(\pi_{\mathrm{ref}}\parallel\pi_\theta)\)
的一阶近似，便于与重要性采样结合，并有效限制策略“偏离基模”的程度。

综合策略损失与 KL 正则，单个样本的 GRPO 目标写为~\eqref{eq:grpo_obj_single}：
\begin{equation}
  \mathcal{L}^{\mathrm{GRPO}}_i(\theta)
  =
  \mathcal{L}^{\mathrm{policy}}_i(\theta)
  +
  \mathcal{L}^{\mathrm{KL}}_i(\theta),
  \label{eq:grpo_obj_single}
\end{equation}
整个 RL 阶段的优化目标为最小化期望损失，如~\eqref{eq:grpo_obj}：
\begin{equation}
  \mathcal{L}_{\mathrm{GRPO}}(\theta)
  =
  \mathbb{E}_{(G,q)\sim\mathcal{D}_{\mathrm{RL}}}
  \big[
    \mathcal{L}^{\mathrm{GRPO}}_i(\theta)
  \big],
  \label{eq:grpo_obj}
\end{equation}
其中 \(\mathcal{D}_{\mathrm{RL}}\) 为 RL 阶段使用的图推理任务分布。
在参数层面，图欧拉路径编码器 \(\mathrm{Enc}_G\)、文本编码器 \(\mathrm{Enc}_T\) 
以及跨模态对齐模块在整个 RL 过程中保持冻结，
更新仅作用于语言模型解码器 \(\mathrm{Dec}_T\) 及其轻量适配层，
实现“在保持基模语义与对齐结构的前提下，对推理策略进行最小干预的强化调整”。

\subsection{强化学习训练流程与实现配置}
\label{subsec:grpo_train_detail}

在上述 GRPO 目标之上，本文构建了一套面向图推理任务的强化学习训练流程，
将可验证奖励与 group 采样机制结合，以实现稳定、高效的策略优化。
关键实现细节如下。

\textbf{(1) 批次构造与多轨迹采样。}
每次 RL 迭代中，从 RL 训练任务池 \(\mathcal{D}_{\mathrm{RL}}\) 中采样
批次大小为 \(B=64\) 的图–问题对
\(\{(G_i,q_i)\}_{i=1}^B\)，其中 Erdős 风格合成图与真实文本属性图任务按 \(4{:}1\) 比例混合。
对每个样本构造条件输入
\(x_i\)（~\eqref{eq:cot_input_seq}），保持系统提示与任务模板不变。
随后，使用当前旧策略 \(\pi_{\theta_{\mathrm{old}}}\) 在温度 \(T=1.0\)、Top-\(p=0.9\) 的采样配置下，对每个 \(x_i\) 采样
\(G=5\) 条候选轨迹
\(\{y_i^{(g)}\}_{g=1}^G\)（~\eqref{eq:grpo_sample}），
最大生成长度限制在 \(L_{\max}=4096\) 以内，超长序列在保证答案完整的前提下截断。

\textbf{(2) 可验证奖励测评与过滤。}
对每条候选轨迹 \(y_i^{(g)}\)，调用可验证奖励函数
\(\mathcal{R}(G_i,q_i,y_i^{(g)})\)（~\eqref{eq:reward_function}）。
实现上先应用硬规则过滤：对答案错误、路径非法或显式违反约束的样本赋予极低奖励并标记为“不可用”；其余样本保留原始奖励值用于优势计算。
若某个 \((G_i,q_i)\) 对应的所有 \(G\) 条轨迹均被判为无效，则丢弃该样本并在后续迭代中重新采样，以避免在纯噪声轨迹上更新策略。

\textbf{(3) 组内优势计算与梯度构造。}
对每个保留样本，按~\eqref{eq:grpo_adv} 计算组相对优势 \(A_i^{(g)}\)，
并将其裁剪至 \([-5,5]\) 以抑制极端值导致的梯度不稳定。
随后，基于当前待更新策略 \(\pi_\theta\)、
旧策略 \(\pi_{\theta_{\mathrm{old}}}\) 
和参考策略 \(\pi_{\mathrm{ref}}\) 计算序列级对数概率及比率
 \(\rho_i^{(g)}(\theta)\)，
构造策略损失
\(\mathcal{L}^{\mathrm{policy}}_i(\theta)\)
与 KL 正则项
\(\mathcal{L}^{\mathrm{KL}}_i(\theta)\)，
最终得到样本级 GRPO 损失
\(\mathcal{L}^{\mathrm{GRPO}}_i(\theta)\)。
训练时采用 teacher-forcing 在整条轨迹上回放生成 token，
对每个 token 的对数概率梯度进行加权累积，从而将序列级奖励反向传播至解码器参数。

\textbf{(4) 优化器配置与策略更新节奏。}
采用 AdamW 优化器对可训练参数集合 \(\theta\) 进行更新，
学习率设为 \(\eta=1\times10^{-6}\)（低于 CoT-SFT 阶段的 \(1\times10^{-5}\)），
权重衰减系数为 \(\lambda_{\mathrm{wd}}=1\times10^{-2}\)，仅作用于解码器适配层参数。
学习率调度采用 10\% 线性预热加余弦退火的组合策略：预热阶段逐步提升学习率至峰值，退火阶段缓慢衰减至 \(1\times10^{-7}\)，在保证训练稳定性的同时促进收敛。
为缓解重要性权重分布漂移，每间隔 100 个训练步将旧策略
\(\pi_{\theta_{\mathrm{old}}}\) 同步为当前策略 \(\pi_\theta\)，
并始终保持参考策略 \(\pi_{\mathrm{ref}}\) 冻结不变，形成“actor–old–ref”三模型结构。

\textbf{(5) 监控指标与早停策略。}
训练过程中实时监控平均奖励 \(\bar{r}\)、有效样本比例、答案正确率 \(Acc_{\mathrm{ans}}\)、约束违反率、平均思维链长度以及 KL 散度 \(\bar{D}_{\mathrm{KL}}\) 等关键统计量。
当 \(\bar{r}\) 与 \(Acc_{\mathrm{ans}}\) 在连续三个 epoch 内不再提升，且
\(\bar{D}_{\mathrm{KL}}\) 稳定在与 \(\beta\) 对应的目标范围附近
（约 \(10^{-3}\) 量级）时，触发早停，避免过度优化导致语言质量下降或模式坍缩。
最终得到的 RL 检查点参数记为
\(\theta_{\mathrm{RL}}^\ast\)，即本文图基座模型在可验证奖励驱动下的强化图推理策略。

通过上述强化学习训练流程，本文在基本保持基模语言与对齐能力的前提下，
显式鼓励模型在图论任务上探索并固化高奖励的推理模式：
一方面，规则化奖励确保生成的推理链在结构与答案层面均可被图算法验证；
另一方面，组相对优势机制与 KL 基模约束共同保证了训练过程的稳定收敛，
为后续章节中对图推理性能与可解释性的系统测评提供了坚实的算法基础。



\section{实验测评与分析}
\subsection{实验设置与评测目标}
\textbf{1)\ 实验目标}

针对现有图基座模型在复杂推理任务中对高质量标注数据依赖度高、泛化性能受限等瓶颈问题，
本章提出一种结合思维链冷启动与可验证奖励强化学习的图推理框架。
本实验旨在系统测评该框架在合成与真实图数据上的推理性能，
验证基于GRPO的策略优化算法能否在无人工偏好反馈的条件下，
引导模型习得符合图论公理的通用推理范式 。具体而言，实验目标聚焦于以下三个关键维度
\begin{itemize}
  \item {复杂图推理能力的量化测评（Effectiveness）：}
  基于Erdős合成图论基准及真实场景图推理任务，系统测评模型的综合性能 。实验不仅关注最终答案的准确率，
  将进一步通过路径合法性与逻辑自洽性指标，量化测评引入可验证奖励机制后，模型在多步逻辑推导中的过程正确性

  \item {跨域零样本泛化能力的验证（Generalization）：} 
  考察模型从合成图任务中习得的结构推理策略向真实文本属性图迁移的有效性 。
  重点测评模型在未见图结构与未见查询类型下的零样本表现。

  \item {强化学习机制的消融与归因分析（Mechanism）：} 采用解耦实验设计，
  定量分离思维链监督微调与强化学习优化阶段各自的性能贡献。
  深入剖析奖励函数分量对策略更新的具体影响机制，
  从实验角度阐明可验证奖励在提升模型推理能力、提升任务泛化性中的核心作用。
\end{itemize}

围绕上述目标，本节设计了四组实验分别对以上三点目标展开实验，对改
进方案进行全面测评。

\textbf{4)\ 实验细节配置}

本研究的实验流程遵循监督式冷启动与强化学习优化两阶段范式。所有实验均采用DeepSpeed ZeRO-2 分布式训练策略，基础语言模型解码器选用 Qwen2.5-14B-Instruct，图结构编码器沿用第 3 章预训练完成的 GET-Base24 权重。

{阶段一：思维链监督微调：}
为了解决强化学习在复杂推理任务中的冷启动难题，我们首先在 $\mathcal{D}_{CoT}$ 的包含18,000个样本的训练集上进行监督微调，
以规范化模型的思维链格式并注入基础图论知识。本阶段冻结图欧拉路径编码器Enc$_G$与跨模态投影层$f_{proj}$，
仅对 LLM 解码器实施参数高效微调。具体而言，我们在所有线性层（Query, Key, Value, Output, MLP）注入 LoRA 适配器，
设置秩 $r=64$，缩放系数 $\alpha=128$，Dropout 率为 $0.05$。优化器采用 AdamW，全局批次大小设为 64。
学习率调度遵循带预热的余弦退火策略，初始最大学习率设为 $\eta_{SFT} = 1 \times 10^{-5}$，预热步数占总步数的 3\%。为了容纳完整的推理路径，
最大序列长度限制为 3072 tokens。训练持续 2 个 Epoch，以{验证集}上的 Token 准确率与格式合规率作为早停指标。

{阶段二：基于 GRPO 的强化学习优化：}
在 RL 阶段，以 CoT-SFT 后的模型权重初始化策略网络 $\pi_{\theta}$，并冻结参考模型 $\pi_{ref}$ 以计算 KL 散度约束。
训练采用组式策略优化算法，在 $\mathcal{D}_{RL}$ 的 {100,000} 个训练任务上进行迭代。对于每个输入的图-问题对 $(G, q)$，
策略网络通过核采样（Nucleus Sampling，Temperature $T=1.0$，Top-$p=0.95$）生成 $G=5$ 条独立的推理轨迹，
最大生成长度扩展至 4096 tokens 以允许模型探索复杂的推理步骤。奖励函数 $\mathcal{R}$ 的各项权重系数依据第 4.4.1 节定义设定为：
答案正确性 $\lambda_{ans}=1.0$，拓扑一致性 $\lambda_{topo}=0.5$，格式规范性 $\lambda_{fmt}=0.1$，
长度正则项 $\lambda_{len}=0.01$。为了稳定训练过程并防止策略坍塌，
采用更低的学习率 $\eta_{RL} = 1 \times 10^{-6}$，并将 KL 散度惩罚系数 $\beta$ 设为 $0.001$，梯度裁剪阈值设为 1.0。
此外，每隔 100 步将旧策略 $\pi_{old}$ 同步为当前策略。训练过程持续约 3000 步，全局批次大小设为 64，覆盖约 19.2万次采样，
实时监控{验证集}上的平均奖励与 KL 散度，当平均奖励在连续验证区间内波动小于 $1\%$ 时终止训练。
