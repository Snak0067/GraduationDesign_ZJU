\chapter{融合节点分类与图推理的金融反欺诈系统设计与实现}
在数字金融生态日益复杂的背景下，金融欺诈已演变为一种具有高度对抗性、隐蔽性及团伙化的系统性风险。
传统的基于独立同分布假设的统计模型或孤立的图节点分类算法，往往难以应对跨模态、长链路的复杂攻击模式。
为验证本文提出的结合强化学习推理微调的图结构基座模型范式在垂直领域的有效性与泛化能力，
本章设计并实现了一套面向金融风控场景的原型系统。该系统旨在通过统一的图表征框架，
实现从基于节点分类的风险感知到基于图推理的风险归因的端到端闭环，为复杂金融网络中的反欺诈决策提供可解释、可核验的技术支撑。

因本场景涉及私有数据难以获取等问题，
本系统定位为用于方法验证的科研原型，
以评估本文所提出模型在真实世界复杂图数据上的建模与推理能力
。基于该定位，系统主要服务于离线批处理，输入数据以结构化交易日志、用户行为序列与设备指纹为主，
通过时间窗聚合构建动态图快照，从而支持风险研判与事后审计；
其次原型选取互联网广告反作弊与模拟信贷反团伙欺诈作为代表性场景，
该类任务具有显著的异构交互结构
与强对抗属性，可用于检验模型对团伙结构的挖掘能力；
最后，系统输出以决策支持为导向，提供风险评分、
风险等级及结构化推理证据链的联合结果，
用于辅助风控专家开展复核分析与策略迭代，而非直接生成强制阻断指令。

\section{金融反欺诈场景需求分析}
\textbf{1)\ 业务需求分析}

面向金融反欺诈场景，具体业务需求问题拆解如\autoref{fig:Financial_Requirements} 所示。
面向金融欺诈团伙化与策略快速演变的现实特征，系统在业务层面需同时满足精准降损与体验控扰的双重目标。
首先，系统应具备超越传统规则引擎的泛化识别能力，能够利用图拓扑与跨实体关联线索，
定位被黑产手法掩护机制所遮蔽的高隐蔽性风险主体，
并在样本稀缺或模式突变时保持对零日攻击的敏感性与可迁移性。
其次，业务关注的不仅是个体风险判别，更是风险在群体结构中的传播与组织化协同机制；
因此系统需能够在异构交互网络中挖掘隐性关联与团伙拓扑指纹，实现对欺诈链条的结构化刻画与批量化打击。
最后，考虑到风控合规审计与人工复核的刚性要求，系统必须提供可解释、可追溯的决策依据：
在给出风险评分与等级的同时，能够明确呈现关键关联邻居、风险传导路径与支撑证据，并以结构化证据链与自然语言解释的形式降低复核成本。

使构图输入与预训练阶段保持分布一致；二是构建分类与推理的级联协同流程，
以节点分类承担全量高吞吐初筛与候选排序，以图推理聚焦高风险与边界样本开展深度归因，
从而在计算开销可控的前提下提升检测收益与证据质量；三是对推理结果施加可验证性约束，集成基于图拓扑一致性的校验机制，对推理链路中的节点连接与推导步骤逐步核验并剔除不成立内容，保证输出证据链能够在图结构中回溯与核验，满足业务复核与审计要求。

\section{总体系统架构设计}
为实现上述业务目标，本系统自底向上形成从原始数据到可解释风险决策的端到端闭环。
该架构遵循数据流向的递进关系：下层负责将多源业务日志抽象为可计算的动态图结构，
中间层以节点分类完成全量风险筛查并产出高风险候选，上层以图推理生成可核验的证据与报告，
最终通过可视化与导出能力支撑人工复核与策略迭代。整体如\autoref{fig:Fraud_System_Functional_Architecture} 所示。

\textbf{1）数据接入与图构建层：}
本层面向多源离线数据提供统一接入能力，覆盖 CSV、JSON 与交易流水等输入形式，并提供缺失处理、异常裁剪与时间窗聚合等预处理流程，以提升数据可用性与口径一致性。在此基础上，本层通过图结构映射组件将用户、设备、IP 等实体及其交互关系编码为异构图，并进一步构建按时间窗口切分的动态图快照，用于保留行为演化与跨实体关联结构。本层的目标是将复杂业务事件转化为可复现、可版本化的图数据输入，为后续模型推断提供稳定的数据底座。

\textbf{2）分类感知层：}
本层以通用图基座模型为核心，面向目标节点执行高通量风险评分，并完成风险等级划分，承担系统的前置过滤与候选筛选职责。该层输出两类结果：一是面向全量实体的可排序风险清单，支撑批处理筛查；二是供上游推理模块使用的高风险候选集合，用于将计算资源集中于最有价值的审查对象。本层的目标是在保证覆盖面的前提下实现快速定位与资源分配，为深度归因建立可控的输入范围。

\textbf{3）风险推理归因层：}
本层以强化学习推理模型为核心，围绕候选高风险实体开展结构化归因，生成具备逻辑一致性的推理链路，并同步完成关键风险路径提取与异常子图模式识别。在输出形态上，本层形成两类交付物：其一为可回溯的证据链，用于支撑审计与复核；其二为面向业务人员的自然语言风险报告，用于降低解读成本并提升处置效率。本层的目标是将判别式评分转化为可解释的关联证据，实现从风险发现到风险成因的闭环连接。

\textbf{4）全链路回溯与可视化层：}
本层面向分析与复核场景提供交互式图谱探索能力，支持多跳邻域展开与关键关系高亮，便于对风险链路进行逐步核验与定位。同时，本层提供风险清单导出与推理证据摘要沉淀能力，并支持离线复盘与策略迭代所需的结果留痕与对照管理。本层的目标是将模型输出转化为可操作的分析界面与可复现的实验记录，支撑人工审核闭环与论文实验复现。

系统首先从原始日志接入开始，对交易与行为记录进行数据预处理与特征工程处理，完成缺失修复、异常裁剪与时间窗聚合，
并据此构建满足业务语义的异构图结构，明确实体类型与交互关系的统一 Schema，为后续模型推断提供稳定一致的图输入。

在阶段一的全量风险感知中，系统调用第~3~章图节点分类基座模型对目标节点进行批量风险评分，并以阈值规则完成风险分流：当风险评分低于阈值时，样本直接判定为低风险并通过；当风险评分超过阈值时，样本被标记为高风险候选并进入阶段二。该阶段以高吞吐与全量覆盖为目标，输出可排序的高风险候选集合，从而将后续计算更为密集的归因分析聚焦于少量关键对象。

在阶段二的深度风险归因中，系统围绕高风险候选先执行目标子图提取，构造与当前决策相关的上下文子图作为推理输入；随后调用第~4~章强化学习图推理模型生成逻辑一致的推理链路，并输出风险定性结论与结构化证据链。最终，系统将证据链与风险要点映射到可视化研判界面，支持多跳邻域展开、关键关系高亮与报告生成，实现模型输出的可核验呈现与可复盘沉淀，形成“筛查—归因—解释—回溯”的闭环工作流。


\section{金融风控图数据构建与推理样本生成}
本节旨在详细阐述如何将原始的多源金融业务数据，转化为图基座模型可理解、可推理的高质量序列化输入。
这一过程涵盖了从底层的图谱本体设计、多源异构数据的清洗与动态图构建，到适配欧拉路径编码的序列化处理，
以及基于强化学习需求的高质量思维链推理样本生成的全生命周期。通过构建这一标准化的数据流水线，我们旨在解决金融图数据“入模难”、黑盒模型“解释难”以及推理逻辑“落地难”的核心痛点，
为第5.4节的模型训练与第5.6节的系统测评奠定坚实的数据基础。

\textbf{1)金融异构图谱本体设计与多模态属性建模}

不同于通用知识图谱，风控图谱的设计需紧密围绕“风险定义”展开，强调实体属性的区分度与关系类型的因果性。
基于对真实信贷与支付风控业务的深入拆解，本文构建了一个包含5类核心节点与6类关键边关系的异构信息网络（HIN）。

\textbf{节点类型定义}： 在金融网络中，节点是风险的载体。我们不仅关注账户本身，更关注承载账户的物理媒介与环境。

\begin{enumerate}
    \item 用户： 交易的主体。不仅包含注册ID，还聚合了如年龄段、职业的静态身份画像与动态风险标签。

    \item 设备： 风险攻防的第一战场。通过设备指纹唯一标识，承载了操作系统、模拟器特征、越狱状态等关键环境属性，是识别团伙作案的核心锚点。

    \item IP地址： 网络环境标识。包含地理归属、运营商类型等属性，用于识别代理攻击与地理位置异常。

    \item 商户： 资金流转的汇聚点。包含商户类别码、经营主体信息，用于识别虚假交易与套现窝点。

    \item 关联实体： 如Wi-Fi MAC地址、加密的身份证号、手机号等，用于构建跨账户的隐性关联。
\end{enumerate}

\textbf{边关系类型定义：}边承载了风险传播的动态语义。

\begin{enumerate}
    \item 资金交易： 有向边（User $\to$ User/Merchant）。这是图谱中最稠密、最重要的边，
携带了金额、时间、附言等核心属性。

    \item 设备登录： 无向边（User - Device）。刻画账户的使用环境，高频切换往往意味着盗号或代办风险。

    \item 网络接入： 无向边（Device - IP）。用于发现聚集性风险，如同一网段下的批量注册。

    \item 社交关联： 无向边（User - User）。基于转账频繁联系人、通讯录或担保关系构建。

    \item 物理共现： 无向边（Device - Wi-Fi/GPS）。用于挖掘线下聚集的黑产窝点。
    \item 属性共享： 无向边（User - Linked Entity）。如共用手机号、共用身份证，是团伙识别的强特征。
\end{enumerate}

为了适配第3章提出的文本属性图（TAGs）处理架构，
我们将金融数据中的数值、类别与非结构化文本进行了统一的多模态建模
。传统的GNN通常将属性简单拼接为向量，而本研究利用大语言模型的语义理解能力，

\textbf{2)面向金融交易网络的欧拉路径图编码实现}

第3章提出的欧拉路径编码是本研究的核心技术底座。
然而，通用算法针对的是无向或简单有向图，而金融交易网络是典型的强有向、多重边且属性密集的图结构。
本节详细阐述如何将该技术适配于金融场景，实现对资金流向的无损序列化。
具体实现而言，包含以下步骤：

\textbf{资金流向保真的欧拉化预处理}:欧拉路径存在的充要条件是
图中每个节点的入度等于出度或存在两个奇度数节点。
真实的交易子图往往是不平衡的。直接加虚边可能会混淆真实资金流与虚拟平衡流。
因此，引入以下适配处理流程：
\begin{itemize}
    \item 连通性增强： 引入全局虚拟节点$``$，单向连接至子图中的所有孤立分量核心节点，
    确保图连通，并作为全局风险上下文信息的注入接口。
    \item 流向平衡补图： 针对度数不平衡节点，添加标记为 $``$ 的回溯虚边。
    不同于通用算法的随机加边，我们优先在属于同一资金链路的节点间添加回溯边，
    在序列化时， 边会被分配特殊的Mask Token，
    使模型在Self-Attention计算时能够区分真实交易与补图路径，
    既满足了欧拉路径的数学存在性，又保留了真实资金流向的单向语义。
\end{itemize}

\textbf{时序优先的深度搜索序列化:}在生成欧拉路径时，
节点遍历的顺序直接决定了序列的语义连贯性。针对金融场景，我们改进了路径搜索策略，
采用{时序优先的深度搜索}。具体而言：在节点 $u$ 选择下一条边 $(u, v)$ 进行遍历时，不进行随机选择，
    而是对所有出边按交易时间戳 $t$ 进行升序排列，优先遍历发生时间最早的交易。
    从而生成的结果序列 $ User_A -> Trans_1(t1) -> User_B -> Trans_2(t2) -> User_C $
    自然地蕴含了 $t1 < t2$ 的时序约束。这使得Transformer的位置编码
    能够隐式地捕捉到资金流动的因果链条，极大增强了模型对“快进快出”、“分层转账”模式的识别能力。

\textbf{全属性模式序列构建:}为了承载5.3.2节定义的多模态丰富属性，
系统采用第3章定义的全属性模式进行最终的Token序列构建。
每个“边步长”被展开为包含节点、边及其属性的复合序列。
具体序列结构示例如\autoref{tab:sequence_token_input}所示。
这种极其稠密的编码方式虽然增加了序列长度，但最大限度地保留了风控所需的全部细节，
使基座模型能够同时利用拓扑结构（谁转给谁）和语义特征（备注是什么）进行联合推理。

\textbf{3)风险推理样本的定义与生成体系}

为了支撑第4章所述的结合强化学习微调的图推理，
必须构建高质量、包含显式思维链的样本集。
在金融风控领域，这意味着模型不仅要输出“通过/拒绝”，
还要输出“因为A在短时间内从B处收到大额资金并立即转给高风险账户C，
且设备环境与历史习惯不符，判定为洗钱风险”的完整逻辑链条。

因此，我们将金融图推理任务形式化为三元组 $(G, q, y)$：
$G$表示为经欧拉路径序列化后的风控子图Token序列，
$q$是自然语言形式的风险排查指令，覆盖三个层次的认知需求：
\begin{prompt}{风险感知类的风险排查指令}
请分析中心用户$User_X$是否存在异常，并给出风险评分（0-100）。
\end{prompt}
\begin{prompt}{归因解释类的风险排查指令}
$User_X$被标记为高风险，请列出导致该判定的3个关键交易和1个关联团伙，并说明理由。
\end{prompt}
\begin{prompt}{模式挖掘类的风险排查指令}
图中是否存在资金闭环或设备共享行为？请输出具体的节点路径$ID$。
\end{prompt}

以及$y$，包含思维链与答案的序列 $y = (c, a)$。
$c$是分步骤的推理过程。例如：“步骤1：检查$User_X$的一度邻居，发现与黑名单设备$Dev_9$关联；
步骤2：追踪资金流向，发现资金汇入$User_Y$后在5分钟内流出...”。$a$代表结构化的结论，通常是JSON格式，便于下游系统解析。

\textbf{4)基于教师模型蒸馏的冷启动样本生成}

由于缺乏大规模的专家标注CoT数据，本系统采用
结合教师模型蒸馏和规则校验的策略生成冷启动样本库（参考章节 \autoref{subsec:grpo_train_detail}）。
教师模型配置选用推理能力较强的通用大模型Qwen2.5-32B-Instruct作为教师。
提示词工程设计包含领域知识的系统提示词：

\begin{prompt}{基于教师模型蒸馏的冷启动样本生成系统提示词}
你是一名资深金融反欺诈/反洗钱专家。
给定输入的“欧拉序列文本”（将图事件按欧拉路径/游走序列化），
你需要{还原图结构}并{判断是否命中典型欺诈拓扑}，生成可用于教师模型蒸馏的推理样本。
\end{prompt}



最后将构建好的子图序列 $G$ 和指令 $q$ 输入教师模型，
要求其按照实体分析$\to$ 路径追踪 $\to$ 模式匹配 $\to$ 结论汇总的步骤生成思维链结果。

为了确保生成的推理样本逻辑正确且符合事实，我们利用第4章提出的可验证奖励函数 $\mathcal{R}(G, q, y)$ 
对生成的CoT进行严格过滤，只有高分样本才会被纳入训练集1。
利用拓扑一致性校验解析CoT中提及的所有交易链路（如 $A \to B$），
检查其是否真实存在于输入图 $G$ 中。若模型出现幻觉（捏造交易），则该样本直接剔除。
并且使用图算法辅助验证，
针对资金闭环类Query，调用NetworkX算法在子图中运行环检测。若算法检测有环但模型回答无环，或模型输出的环路径不连通，则视为错误。
针对关联风险类Query，验证提及的风险邻居是否确实在K-Hop范围内。
最后检查推理过程中的定性与最终评分是否一致。

通过上述流水线，我们构建了包含 5,000条 高质量图推理指令样本的数据集 Fin-CoT-5K。
\begin{enumerate}
    \item 
样本分布： 风险感知类（40\%）、归因解释类（35\%）、模式挖掘类（25\%）。
\item 
覆盖度： 覆盖了洗钱、赌博、电信诈骗、信贷中介、设备农场等5大类典型黑产场景。
\item 

质量指标： 经过人工抽检，生成样本的拓扑准确率达到98.5\%，逻辑连贯性达到95\%以上。
\end{enumerate}

该数据集将直接用于第5.4节模型的SFT冷启动，并作为第4章所述GRPO强化学习环境的基础任务池，
使模型能够在自我博弈中不断提升对复杂金融图结构的洞察力。
