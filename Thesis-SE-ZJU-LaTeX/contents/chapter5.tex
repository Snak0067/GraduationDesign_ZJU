\chapter{融合节点分类与图推理的金融反欺诈系统设计与实现}

在数字金融生态持续扩张与业务链路日益复杂的背景下，金融欺诈呈现出更强的对抗性、隐蔽性与团伙化特征，
其行为往往跨账户、跨设备、跨场景协同发生，并通过长链路交互关系掩盖真实风险来源。
在此情形下，依赖独立同分布假设的传统统计模型，或仅针对局部邻域进行判别的孤立节点分类方法，
难以稳定捕获跨实体、多跳关联的结构化攻击模式，也难以向风控决策提供可核验的证据链支撑。

为验证本文提出的结合强化学习推理微调的图结构基座模型在垂直风控领域的有效性与泛化能力，
本章设计并实现一套面向金融反欺诈的科研原型系统。
系统以统一的预训练图表征为核心，将\emph{节点分类的风险感知}与\emph{图推理的风险归因}结合，
形成从风险筛查、证据聚合到可解释结论输出的端到端闭环，
从而为复杂金融网络中的反欺诈研判与事后审计提供可解释、可追溯的技术支撑。

\section{金融反欺诈场景需求分析}
\textbf{1)\ 业务需求分析}

面向金融反欺诈场景，具体业务需求问题拆解如\autoref{fig:Financial_Requirements} 所示。
面向金融欺诈团伙化与策略快速演变的现实特征，系统应具备超越传统规则引擎的泛化识别能力，
利用图拓扑与跨实体关联线索，定位高隐蔽性风险主体，
并在样本稀缺或黑产作弊手法发生变化时保持模型与系统准确率和召回率的保持。
其次，业务关注的不仅是个体风险判别，更是风险在群体结构中的传播与组织化协同机制；
因此系统需能够在异构交互网络中挖掘隐性关联与团伙拓扑指纹，实现对欺诈链条的结构化刻画与批量化打击。
最后，考虑到风控合规审计与人工复核的刚性要求，系统必须提供可解释、可追溯的决策依据：
在给出风险评分与等级的同时，能够明确呈现关键关联邻居、风险传导路径与支撑证据，并以结构化证据链与自然语言解释的形式降低复核成本。


\textbf{2)\ 功能需求分析}

在设计融合节点分类与图推理的金融反欺诈系统时，其主要的功能需求如下：
首先，系统应当首先提供宏观的风险态势感知能力，允许快速识别高风险群体；
同时，必须支持对微观个体、交易链路及子图结构的像素级穿透分析，确保从“面”到“点”的逻辑连续性。
其次，针对图结构基座模型的黑盒特性，
可视化界面需将隐式的推理路径以及中间层的融合评分显性化，
将其转化为图谱上的高亮路径、关键节点标记以及自然语言解释报告。
另外，系统不应是单向的信息展示终端，而应是人机协作的接口。系统需要复核结论、标签修正以及对推理逻辑的反馈，
应能够实时回流至系统，用于后续的模型微调与策略迭代。

\textbf{3)\ 性能与可用性指标}

基于科研原型定位，性能指标以可用交互与可复现实验为约束，
侧重计算准确性、吞吐能力与结果一致性。在离线批处理层面，系统应在单机多卡环境下支持千级节点、万级边规模的中等图数据构建与评分，
并在分钟级时间内完成全量风险覆盖，以保证评测与演示的可操作性。在交互推理层面，面向专家审核的单次图推理端到端延迟应稳定在秒级（例如 $<5$s），
以维持分析流程的连续性。与此同时，系统需建立严格的版本化与复现机制，确保在相同输入与配置下风险评分与推理路径输出具有可追溯的一致性，
从而满足学术验证的严谨性要求。


\section{总体系统架构设计}
为实现上述业务目标，本系统自底向上形成从原始数据到可解释风险决策的端到端闭环。
该架构遵循数据流向的递进关系：下层负责将多源业务日志抽象为可计算的动态图结构，
中间层以节点分类完成全量风险筛查并产出高风险候选，上层以图推理生成可核验的证据与报告，
最终通过可视化与导出能力支撑人工复核与策略迭代。整体如\autoref{fig:Fraud_System_Functional_Architecture} 所示。

\textbf{1）数据接入与图构建层：}
本层面向多源离线数据提供统一接入能力，覆盖 CSV、JSON 与交易流水等输入形式，并提供缺失处理、异常裁剪与时间窗聚合等预处理流程，以提升数据可用性与口径一致性。在此基础上，本层通过图结构映射组件将用户、设备、IP 等实体及其交互关系编码为异构图，并进一步构建按时间窗口切分的动态图快照，用于保留行为演化与跨实体关联结构。本层的目标是将复杂业务事件转化为可复现、可版本化的图数据输入，为后续模型推断提供稳定的数据底座。

\textbf{2）分类感知层：}
本层以通用图基座模型为核心，面向目标节点执行高通量风险评分，并完成风险等级划分，承担系统的前置过滤与候选筛选职责。该层输出两类结果：一是面向全量实体的可排序风险清单，支撑批处理筛查；二是供上游推理模块使用的高风险候选集合，用于将计算资源集中于最有价值的审查对象。本层的目标是在保证覆盖面的前提下实现快速定位与资源分配，为深度归因建立可控的输入范围。

\textbf{3）风险推理归因层：}
本层以强化学习推理模型为核心，围绕候选高风险实体开展结构化归因，生成具备逻辑一致性的推理链路，并同步完成关键风险路径提取与异常子图模式识别。在输出形态上，本层形成两类交付物：其一为可回溯的证据链，用于支撑审计与复核；其二为面向业务人员的自然语言风险报告，用于降低解读成本并提升处置效率。本层的目标是将判别式评分转化为可解释的关联证据，实现从风险发现到风险成因的闭环连接。

\textbf{4）全链路回溯与可视化层：}
本层面向分析与复核场景提供交互式图谱探索能力，支持多跳邻域展开与关键关系高亮，便于对风险链路进行逐步核验与定位。同时，本层提供风险清单导出与推理证据摘要沉淀能力，并支持离线复盘与策略迭代所需的结果留痕与对照管理。本层的目标是将模型输出转化为可操作的分析界面与可复现的实验记录，支撑人工审核闭环与论文实验复现。

结合\autoref{fig:Flowchart} 的分层功能栈与数据流向，
原型系统采用“判别式全量筛查—生成式深度归因”的两阶段闭环。
其核心思想是先用高吞吐判别模型完成全量风险分流，再仅对高风险少量样本调用生成式推理进行可解释归因。

具体流程如下：从原始日志出发，系统对交易与行为日志执行缺失修复、异常裁剪、时间窗聚合与统计特征抽取，得到结构化的实体与交互记录。
基于清洗后的实体与交互记录，系统按统一 Schema 将数据映射为异构图。
明确节点类型和边类型并固化字段、方向与约束，使后续模型在训练与推断时共享同一图输入规范。

在阶段一的全量风险感知中，
系统调用第~3~章图节点分类基座模型对目标节点进行批量风险评分，并以阈值规则完成风险分流：
当风险评分低于阈值时，样本直接判定为低风险并通过；当风险评分超过阈值时，样本被标记为高风险候选并进入阶段二。
该阶段的输出是可排序的高风险候选集合，以最小化阶段二的计算负载并保证全量覆盖。

在阶段二的深度风险归因中，系统围绕高风险候选先执行目标子图提取，
构造与当前决策相关的上下文子图作为推理输入；随后调用第~4~章强化学习图推理模型生成逻辑一致的推理链路，
并输出风险定性结论与结构化证据链。

最终，系统将证据链与风险要点映射到可视化研判界面，支持多跳邻域展开、关键关系高亮与报告生成，
实现模型输出的可核验呈现与可复盘沉淀，形成闭环工作流。


\section{金融风控图数据构建与推理样本生成}
本节旨在详细阐述如何将原始的多源金融业务数据，转化为图基座模型可理解、可推理的高质量序列化输入。
这一过程涵盖了从底层的图谱本体设计、多源异构数据的清洗与动态图构建，到适配欧拉路径编码的序列化处理，
以及基于强化学习需求的高质量思维链推理样本生成的全生命周期。
为第5.4节的模型训练与第5.6节的系统测评奠定坚实的数据基础。

\textbf{1)金融异构图谱本体设计与多模态属性建模}

不同于通用知识图谱，风控图谱的设计需紧密围绕风险定义展开，强调实体属性的区分度与关系类型的因果性。
基于对真实信贷与支付风控业务的深入拆解，本文构建了一个包含5类核心节点与6类关键边关系的异构信息网络。
具体的数据项定义与处理方式如\autoref{tab:feature_processing_cn}所示。


\textbf{节点类型定义}： 在金融网络中，节点是风险的载体。本文不仅关注账户本身，更关注承载账户的物理媒介与环境。

\begin{enumerate}
    \item 用户： 交易的主体。
    包含注册ID、年龄段、职业的静态身份画像与动态风险标签。

    \item 设备：设备指纹唯一标识，承载了操作系统、
    模拟器特征、越狱状态等关键环境属性。

    \item IP地址：网络环境标识。包含地理归属、运营商类型等属性，
    用于地理位置异常。

    \item 商户：资金流转的汇聚点。包含商户类别码、经营主体信息，用于识别虚假交易。

    \item 关联实体：如MAC地址、加密的身份证号、手机号等，构建跨账户的隐性关联。
\end{enumerate}

\textbf{边关系类型定义：}边承载了风险传播的动态语义。

\begin{enumerate}
    \item 资金交易： 有向边。携带金额、时间、附言等核心属性。

    \item 设备登录： 无向边。高频切换设备往往意味着盗号或代办风险。

    \item 网络接入： 无向边。用于发现聚集性风险，如同一网段下的批量注册。

    \item 社交关联： 无向边。基于转账频繁联系人、通讯录或担保关系构建。

    \item 物理共现： 无向边。用于挖掘线下聚集的黑产窝点。
    \item 属性共享： 无向边。如共用手机号、共用身份证等团伙强特征。
\end{enumerate}

\textbf{2)面向金融交易网络的欧拉路径图编码实现}

第3章提出的欧拉路径编码是本系统的核心技术支撑。
然而，通用图算法针对的是无向或简单有向图，
而金融交易网络是典型的强有向、多重边且属性密集的图结构。
本节详细阐述如何将该技术适配于金融场景，实现对资金流向的无损序列化。
具体实现而言，包含以下步骤：

\begin{itemize}
    \item {资金流向保真的欧拉化预处理}:欧拉路径存在的充要条件是
图中每个节点的入度等于出度或存在两个奇度数节点。
真实的交易子图往往是不平衡的。直接加虚边可能会混淆真实资金流与虚拟平衡流。
因此，本文引入以下适配改进：
首先引入全局虚拟节点$``$，单向连接至子图中的所有孤立分量核心节点，
确保图连通。
其次，针对度数不平衡节点，添加标记为 $``$ 的回溯虚边。
不同于通用算法的随机加边，本文优先在属于同一资金链路的节点间添加回溯边，
在序列化时， 边会被分配特殊的Mask Token，
使模型在自注意力计算时能够区分真实交易与补图路径，
既满足了欧拉路径的数学存在性，又保留了真实资金流向的单向语义。
    \item {时序优先的深度搜索序列化:}在生成欧拉路径时，
节点遍历的顺序直接决定了序列的语义连贯性。针对金融场景，本文改进了路径搜索策略，
采用{时序优先的深度搜索}。具体而言：在节点 $u$ 选择下一条边 $(u, v)$ 进行遍历时，不进行随机选择，
    而是对所有出边按交易时间戳 $t$ 进行升序排列，优先遍历发生时间最早的交易。
    从而生成的结果序列 $ User_A -> Trans_1(t1) -> User_B -> Trans_2(t2) -> User_C $
    自然地蕴含了 $t1 < t2$ 的时序约束。这使得Transformer的位置编码
    能够隐式地捕捉到资金流动的因果链条，极大增强了模型对“快进快出”、“分层转账”模式的识别能力。
    \item {全属性模式序列构建:}为了承载5.3.2节定义的多模态丰富属性，
系统采用第3章定义的全属性模式进行最终的Token序列构建。
每个边步长被展开为包含节点、边及其属性的复合序列。
具体序列结构示例如\autoref{tab:sequence_token_input}所示。
这种极其稠密的编码方式虽然增加了序列长度，但最大限度地保留了风控所需的全部细节，
使基座模型能够同时利用拓扑结构和语义特征进行联合推理。

\end{itemize}

\textbf{3)风险推理样本的定义与生成体系}

为了支撑第4章所述的结合强化学习微调的图推理，
必须构建高质量、包含显式思维链的样本集。
在金融风控领域，这意味着模型不仅要输出“通过/拒绝”，
还要输出“因为A在短时间内从B处收到大额资金并立即转给高风险账户C，
且设备环境与历史习惯不符，判定为洗钱风险”的完整逻辑链条。

因此，本文将金融图推理任务形式化为三元组 $(G, q, y)$：
$G$表示为经欧拉路径序列化后的风控子图Token序列，
$q$是自然语言形式的风险排查指令以及包含思维链与答案的序列 $y = (c, a)$。
$c$是分步骤的推理过程，$a$代表结构化的结论，通常是JSON格式，便于下游系统解析。
针对图推理任务，本节的系统提示词覆盖三个方面，具体如下：
\begin{prompt}{风险感知类的风险排查指令}
请分析中心用户$User_X$是否存在异常，并给出风险评分（0-100）。
\end{prompt}
\begin{prompt}{归因解释类的风险排查指令}
$User_X$被标记为高风险，请列出3个关键交易和1个关联团伙，并说明理由。
\end{prompt}
\begin{prompt}{模式挖掘类的风险排查指令}
图中是否存在资金闭环或设备共享行为？请输出具体的节点路径$ID$。
\end{prompt}

\textbf{4)基于教师模型蒸馏的冷启动样本生成}

由于缺乏大规模的专家标注CoT数据，本系统采用
结合教师模型蒸馏和规则校验的策略生成冷启动样本库（参考章节 \ref{subsec:grpo_train_detail}）。
教师模型配置选用推理能力较强的通用大模型Qwen2.5-32B-Instruct作为教师。
提示词工程设计包含领域知识的系统提示词：

\begin{prompt}{基于教师模型蒸馏的冷启动样本生成系统提示词}
你是一名资深金融反欺诈/反洗钱专家。
给定输入的“欧拉序列文本”（将图事件按欧拉路径/游走序列化），
你需要{还原图结构}并{判断是否命中典型欺诈拓扑}，生成可用于教师模型蒸馏的推理样本。
\end{prompt}



最后将构建好的子图序列 $G$ 和指令 $q$ 输入教师模型，
要求其按照对应步骤生成思维链结果。
为了确保生成的推理样本格式正确且符合事实，
本文利用第4章提出的可验证奖励函数 $\mathcal{R}(G, q, y)$ 
对生成的思维链数据进行严格过滤，选取高样本纳入数据集，并
利用拓扑一致性校验解析所有交易链路，
检查其是否真实存在于输入图 $G$ 中。若模型凭空捏造事实，则该样本直接剔除。
最后使用图算法辅助验证，检查推理过程中的定性与最终评分是否一致。

通过上述流水线，本文构建了包含 5,000条 高质量图推理指令样本的数据集，称为Fin-CoT-5K。
样本包含40\%风险感知问题、35\%归因解释问题以及25\%的模式挖掘问题，
覆盖了洗钱、赌博、电信诈骗、信贷中介、设备农场等5大类典型黑产场景。
经过人工抽检，生成样本的准确率达到98.5\%，逻辑连贯性达到95\%以上，
该数据集用于后续模型在反欺诈垂直场景的微调训练，并集成于系统中。

\section{金融风控大模型训练与优化}

金融反欺诈任务面临着大海捞针般的挑战：
在海量的实时交易流中，欺诈行为往往占比极低（通常低于0.1\%）
，且欺诈者会通过伪装手段混淆视听 。
单纯依赖图神经网络进行节点分类，难以提供令人信服的判罚依据；
而直接对全量数据使用大语言模型进行推理，则面临不可承受的计算成本与延迟。   

为此，本系统设计了分类-推理级联协同的训练与推理框架
。该框架并非两个模型的简单串联，而是在共享底层图语义表征的基础上
，通过差异化的训练目标实现能力的互补与跃升。
级联训练框架包含两个核心模块：
\textbf{图结构感知模块（Graph Perception Module, GPM）}
与\textbf{逻辑推理归因模块（Reasoning \& Attribution Module, RAM）}。
两者共享由第3章所述的欧拉路径图编码器提取的底层图结构特征，
但在训练阶段采用分层优化的策略。

首先，在前文构建的预训练图结构编码器的参数基础上，
利用大量无标签的金融交易图数据，对图编码器进行微调训练。
不同于通用领域的掩码预测，
本阶段引入了资金流向预测和时序交互重建任务，
迫使编码器捕捉资金流转的拓扑模式
和时序依赖，形成对金融异构图的通用理解。
其次，在垂直场景微调的图编码器之上，接入轻量级分类头。
针对金融样本的极度不平衡性，引入结构化Focal Loss与原型对比学习，
重点优化模型在低召回率区间的表现。此阶段的目标是训练一个高吞吐、高敏感度的初筛器，
其输出不仅是风险评分，还包括结构异常度等中间指标，作为触发逻辑推理模块的门控信号。
对于初筛的高风险或高不确定性样本，
系统激活LLM解码器进行深度推理。
利用Fin-CoT数据进行冷启动微调，
随后通过GRPO强化学习框架，结合金融规则验证器，优化模型的推理策略。
此阶段的目标是训练一个逻辑严密、能够生成证据链的强推理模型。

在训练过程中，图结构感知模块
与逻辑推理归因模块并非完全解耦，而是通过难样本挖掘实现协同：
在前向协同中，图结构感知模块在训练过程中识别出的决策边界样本（即预测概率在0.4-0.6之间的样本），
会被标记并输送给逻辑推理归因模块模块作为重点训练数据。
这使得逻辑推理归因模块能够专注于解决那些仅靠结构特征难以判定的复杂案例。
逻辑推理归因模块经过强化学习优化后，
其生成的推理链中包含的关键路径，会被提取为显式的结构特征，
反哺给图结构感知模块模块作为增强输入。
这种机制使得轻量级的图结构感知模块也能隐式地学习到高阶的推理逻辑，从而提升初筛的准确率。   

\textbf{1)面向金融时序异构图的领域适应性微调}

金融图谱是典型的异构动态图，节点涵盖用户、设备、IP、商户等，
边包含转账、登录、授权等，且具有严格的时序因果性。
第3章提出的通用欧拉路径编码在此阶段进行了领域适配改进。
在构造图遍历序列时，严格遵循资金流向的时间先后顺序（$t_{transaction} < t_{next\_hop}$），
强制模型学习资金流转的因果逻辑，而非无向的拓扑连接。
针对金融交易的数值敏感性，我们在序列中引入了专门的金额分桶和时间间隔Token。
本文进一步增加微调任务适配，除了通用的掩码预测（SMTP）外，
增加了资金链路预测与异常属性还原任务。
模型需根据上下文预测资金的下一跳流向，
或识别被随机篡改的异常交易金额。
这迫使底层的GET编码器在微调前就已掌握了正常金融交易的统计规律与拓扑模式。

\textbf{2)对抗极度类别不平衡的感知层微调}

金融欺诈样本通常占比极低（往往低于0.1\%），
导致标准交叉熵损失函数失效，模型易对多数类如正常交易等过拟合。
在GPM模块的训练中，我们引入了针对图结构的结构化Focal Loss与原型对比学习策略。
结构化Focal Loss考虑到欺诈节点常通过伪装手段混迹于正常社群中，
我们改进了传统Focal Loss，引入结构异质性因子 $\alpha_{struct}$
。对于那些邻域多为正常节点但自身标注为欺诈的高隐蔽性节点，$\alpha_{struct}$ 
会动态放大其损失权重，迫使模型关注这些难以区分的伪装者，
而非简单地拟合易分样本。其公式如\ref{eq:loss_sft_focall}所示。

\begin{equation}
    \mathcal{L}_{S-FL} = - \alpha_{struct} (1 - p_t)^\gamma \log(p_t)
    \label{eq:loss_sft_focall}
\end{equation}


我们针对类别不平衡问题设计了基于原型的对比增强，在特征空间维护动态更新的欺诈原型与正常原型。
训练中增加对比正则项，要求欺诈节点的嵌入向量不仅要分类正确，
还要在流形空间中尽可能靠近欺诈原型中心，
远离正常原型。这有效缓解了少样本导致的决策边界模糊问题。

\textbf{3)基于Fin-CoT的推理能力冷启动}

对于被GPM筛选出的高风险样本，RAM模块需要生成解释性报告。
此阶段利用5.3节构建的Fin-CoT数据集进行监督微调。
训练目标不仅仅是输出标签，
而是学习从风险定性到路径回溯，从模式匹配到最终判罚的专家思维范式。
例如，针对洗钱场景，模型被训练去显式地输出：
“发现账户A在短时间内收到多笔小额转账分散转入，并立即汇聚至账户B，
符合分层清洗特征”。为了防止灾难性遗忘，我们采用了混合指令微调策略，
在Fin-CoT数据中掺入20\%的通用逻辑推理数据，
确保模型在学习金融领域知识的同时，保持通用的语言理解与生成能力。

\textbf{4)基于可验证合规奖励的策略优化}

这是本系统最核心的优化环节。为解决大模型在专业领域容易捏造交易记录等幻觉问题
，我们基于第4章的GRPO框架，
设计了金融特化的可验证奖励函数。
传统的RLHF依赖人工打分，成本高且主观性强。
在金融风控中，由于图数据和业务规则是客观存在的，
我们构建了由规则驱动的自动化奖励体系，该体系包含
包含拓扑真实性奖励$R_{topo}$、逻辑自洽性奖励$R_{logic}$
以及合规性约束奖励$R_{compliance}$。具体公式如\ref{eq:Financial_verifier_loss}所示：
\begin{equation}
    \mathcal{R}_{fin} = w_1 R_{topo} + w_2 R_{logic} + w_3 R_{compliance}
    \label{eq:Financial_verifier_loss}
\end{equation}


拓扑真实性奖励$R_{topo}$
系统解析模型生成的思维链，抽取其中提及的所有交易实体与链路，并实时查询图数据库。
凡是提及了不存在的边或节点，给予严厉惩罚。这强制模型言必有据，
确保推理完全基于真实数据。
逻辑自洽性奖励 $R_{logic}$
检查推理结论与图算法检测结果的一致性。
例如，如果模型声称发现了资金闭环，但相关子图中经算法检测并无环路，则给予负奖励。
合规性约束奖励 $R_{compliance}$
引入反洗钱业务规则库。如果模型对大额可疑交易未进行必要的风险提示，
或遗漏了关键的监管要素，则扣除相应分数。通过GRPO算法进行组式策略优化，
模型在数万次自我博弈与规则校验中，
逐渐习得了既符合图论事实、又满足金融合规要求的推理策略，实现了从模仿专家到内化规则的质变。

\section{本章小结}

本章立足于验证图结构基座模型在垂直领域的应用价值，设计并实现了一套融合节点分类与图推理的金融反欺诈原型系统。 
针对金融风控中数据异构性强、黑产对抗性高及决策可解释性弱的痛点，本章完成了从底层数据构建到上层交互决策的端到端落地：

首先，在数据表征层面，将第3章提出的欧拉路径编码技术针对金融场景进行了领域适配，
通过时序优先遍历与多模态属性嵌入，实现了资金流转拓扑的高保真序列化； 
其次，在模型优化层面，集成了第4章基于GRPO的强化学习推理框架，并通过设计拓扑真实性与业务合规性奖励函数，
成功将大模型的通用推理能力转化为符合金融逻辑的专业研判能力； 
最后，在系统交互层面，构建了高通量判别筛查和强逻辑生成归因的双阶段闭环，
通过可视化界面将黑盒模型的隐式特征转化为直观的风险传播路径与自然语言证据链。

本章工作不仅有力证明了本文所提图基座模型架构在复杂工业场景下的泛化能力与鲁棒性，
更为解决高风险决策领域中精准识别与逻辑可信难以兼得的难题，提供了一个具有示范意义的工程范式。
