\chapter{结合欧拉路径图表征和跨模态对齐的节点分类技术}

文本属性图（Text-Attributed Graphs, TAGs）上的节点分类要求模型联合利用拓扑关系与节点文本语义，
是评估图--语言模型结构表征与跨模态融合能力的典型任务。
以 LLaGA\cite{Chen2024LLaGALL} 为代表的主流图基座模型通常采用
邻域采样、模板线性化以及投影映射的范式，
将目标节点邻域按 ND、HO 等模板组织为文本序列输入 LLM。该方案实现简洁、迁移方便，
但粗暴采样与截断会削弱关键子结构与长程依赖；同时，单一线性模板难以兼顾全局拓扑模式与局部结构差异，因而在节点分类等分类任务上易形成性能上限。
另一类方法如 GraphGPT\cite{Tang2023GraphGPTGI} 
通过图--文接地与指令微调增强 LLM 的图理解能力，但其对齐信号多集中于样本级或全局语义层面
，对子结构单元和文本片段的细粒度绑定不足，限制了在 TAG 节点分类场景下对结构信息的有效利用。

针对上述问题，本章围绕 TAG 节点分类从结构表征与跨模态对齐两方面进行改进：一方面，基于（半）欧拉路径构造高保真图 token 序列并设计匹配的图结构编码器，以增强对局部子结构与多跳关系的表达；另一方面，构建多尺度跨模态对齐目标，通过全局对齐、局部结构--短语级对齐与生成式约束的联合优化，提升图表示与语言空间的相容性。实验部分将在多个公开基准上系统评估上述策略对节点分类性能与鲁棒性的影响，并通过消融分析刻画各模块贡献，为后续图推理后训练提供可靠的条件表征基础。

\section{概述}

本章围绕第~2.1~节提出的核心科学问题中的前两个子任务，
系统研究图结构表征方式优化、图编码器的自监督预训练以及图--文本跨模态对齐预训练，
在此基础上构建一个以预训练大语言模型为基座的节点分类完整解决方案。
本章所研究问题可形式化描述如下。

\textbf{输入：}
给定一张文本属性图
\(G=(V,E)\)，其中 \(V=\{v_1,\dots,v_N\}\) 为节点集合、\(E\subseteq V\times V\) 为边集合，
其拓扑可由邻接矩阵 \(A\in\{0,1\}^{N\times N}\)（或加权情形下 \(A\in\mathbb{R}^{N\times N}_{+}\)）表示。
每个节点 \(v\in V\) 关联一段文本属性 \(\mathcal{T}_v\)，
记整体文本集合为 \(\mathcal{T}=\{\mathcal{T}_v\}_{v\in V}\)。
当数据集同时提供额外的数值型节点属性时，记为初始节点特征矩阵
\(X\in\mathbb{R}^{N\times d_x}\)。
在半监督节点分类设定下，给定标注节点集合 \(V_{\mathrm{lab}}\subseteq V\)，其标签为
\(Y_{\mathrm{lab}}=\{y_v\mid v\in V_{\mathrm{lab}}\}\)，其中 \(y_v\in\{1,\dots,C\}\) 且 \(C\) 为类别总数。

\textbf{输出：}
对未标注节点集合 \(V_{\mathrm{unlab}}=V\setminus V_{\mathrm{lab}}\) 的类别预测结果。
模型输出每个 \(v\in V_{\mathrm{unlab}}\) 的类别概率分布
\(\hat{\mathbf{y}}_v\in[0,1]^C\)，满足 \(\sum_{c=1}^{C}\hat{y}_{v,c}=1\)，
并据此给出最终预测标签
\(\hat{y}_v=\arg\max_{c\in\{1,\dots,C\}}\hat{y}_{v,c}\)。
将所有未标注节点的预测汇总可得
\(\hat{Y}_{\mathrm{prob}}\in[0,1]^{|V_{\mathrm{unlab}}|\times C}\)
与
\(\hat{Y}_{\mathrm{unlab}}\in\{1,\dots,C\}^{|V_{\mathrm{unlab}}|\times 1}\)。

针对上述问题，本文以 LLaGA~\cite{Chen2024LLaGALL} 等现有图基座模型框架为基线，
提出一种面向文本属性图的多层次优化训练框架。
整体流程旨在：一方面通过改进图结构序列化方式，提高局部子图拓扑证据在序列输入中的保真度；
另一方面通过显式的跨模态对齐目标，缩小图结构表征与文本语义表征在大语言模型嵌入空间中的分布差异，
从而提升下游节点分类任务的泛化性能。
具体地，本章方法包含三个阶段：
（1）\emph{图编码器自监督预训练}：在大规模混合图数据上学习通用结构表征；
（2）\emph{图--文本跨模态对齐预训练}：通过多层次对齐损失联合优化图侧表征与文本语义表征；
（3）\emph{下游任务微调}：在 Cora\cite{Hu2020OpenGB}、PubMed\cite{Sen2008CollectiveCI} 与 OGB-Arxiv\cite{Hu2020OpenGB} 等基准的官方划分上进行监督微调与评测。

本章后续内容组织如下：

第~\ref{sec:graph_encoder_enhanced}~节详述基于（半）欧拉路径的图结构表征改进方案，
论证如何构造可逆的图序列化映射以实现对子图拓扑的高保真编码，并给出相应的结构预训练策略。

第~\ref{sec:multi_loss_enhanced}~节阐述图结构与文本语义的跨模态对齐机制，
重点介绍由全局 InfoNCE 对比、子结构--短语级局部匹配与生成式重建共同组成的多层次损失设计。

第~\ref{sec:three_total_Experiment}~节给出节点分类任务的系统测评与消融实验，
在 Cora\cite{Hu2020OpenGB}、PubMed\cite{Sen2008CollectiveCI} 与 OGB-Arxiv\cite{Hu2020OpenGB} 等基准上量化结构编码改进与对齐策略对性能的贡献。

第~\ref{sec:three_summerize}~节总结本章提出的节点分类技术方案，并讨论其对后续图推理阶段的支撑作用。


\section{基于欧拉路径的图结构表征方式改进}
\label{sec:graph_encoder_enhanced}

在传统图基座模型框架中，图结构常通过启发式邻域展开或模板化文本描述进行线性化。
该类方法虽然便于接入语言模型，但难以同时保证拓扑信息完整性与序列语法一致性，
从而易产生结构冗余或关键信息缺失。
为缓解上述问题，本文在 GraphGPT~\cite{Zhao2023GraphGPTGP} 的序列化思路基础上，
设计一种基于（半）欧拉路径解析的结构化图序列表示。
该方法以子图内可逆为设计准则：在固定采样子图范围内，
通过可标记的连通化与欧拉化预处理将图转化为满足语法约束的 token 序列；
由于合成边与复制边均携带显式类型标记，解码端可在重建增广多重图后将其过滤，
从而在同构意义下恢复原子图拓扑。整体架构如\autoref{fig:Euler_encoder_architecture} 所示。

\subsection{图到 Token 序列的高保真编码设计}
\label{sec:graph2token}
图到 token 序列的目标是构造映射 $\Phi:\mathcal{G}\rightarrow \mathcal{V}^\ast$，
其中 $\mathcal{G}$ 表示带属性图集合、$\mathcal{V}$ 为有限词表、$\mathcal{V}^\ast$ 为 token 序列集合。
本文从可实现与可检验角度，将编码设计约束为三项目标：
{(1) 子图内可逆}：存在解码算子 $\Psi:\mathcal{V}^\ast\rightarrow\mathcal{G}$，
使得对任意输入子图 $G$ 均有 $\Psi(\Phi(G))\cong G$（同构意义下），其中 $\Psi$ 显式剔除预处理引入的标记边；
{(2) 结构与属性完整性}：序列显式编码节点、边及其离散化后的属性；
{(3) 尺度可控性}：对大规模网络采用“子图采样 $\rightarrow$ 独立序列化”的分治策略，
使序列长度受上下文窗口上界约束，并保持训练/推理输入规范一致。
在不引起歧义的前提下，下文统一以 $G$ 表示待序列化的采样子图。
整体过程形式化如算法~\ref{alg:graph_to_token} 所示。

\begin{algorithm}[t]
\caption{图到Token序列的改进编码算法}
\label{alg:graph_to_token}
\KwIn{带属性图 $G=(V,E,X,A)$}
\KwOut{Token 序列 $s \in \mathcal{V}^\ast$}

\textbf{Step 1: 连通性增强}\;
检查 $G$ 是否连通\;
\If{$G$ 非连通}{
  添加合成边 $E_{\mathrm{syn}}$ 连接所有连通分量，标记为 \texttt{[EDGE\_JUMP]} 及默认属性\;
}
$\tilde{G} \leftarrow (V, E \cup E_{\mathrm{syn}}, X, A)$\;

\textbf{Step 2: 欧拉化预处理}\;
\If{$\tilde{G}$ 非(半)欧拉图}{
  通过 Eulerization 添加最少数量的边 $E_{\mathrm{dup}}$ 使其满足欧拉条件\;
}
$G^{\mathrm{eu}} \leftarrow (V, E \cup E_{\mathrm{syn}} \cup E_{\mathrm{dup}}, X, A)$\;

\textbf{Step 3: (半)欧拉路径采样}\;
计算 $G^{\mathrm{eu}}$ 上所有可行的(半)欧拉路径集合 $\mathcal{P}_{G^{\mathrm{eu}}}$，
从中随机采样 $P\sim\mathcal{U}(\mathcal{P}_{G^{\mathrm{eu}}})$\;
记 $P=(v_0,\dots,v_m)$，其中 $m=|E^{\mathrm{eu}}|$\;

\textbf{Step 4: 节点重索引}\;
令 $\pi(v)$ 为节点 $v$ 在 $P$ 中的首次出现位置；
采样偏移量 $r\sim \mathcal{U}\{0,\dots,N-1\}$，其中 $N > \max|V|$\;
循环重索引：$\pi_r(v) = (\pi(v)+r)\bmod N$\;

\textbf{Step 5: 属性附着与序列构造}\;
根据序列格式 $\textit{format} \in \{\text{short},\text{long},\text{prolonged}\}$ 构造 $s$：

\Switch{format}{
  \Case{short}{$s = (\pi_r(v_0),\dots,\pi_r(v_m))$;}
  \Case{long}{$s = (\text{node\_id},\text{edge\_type},\text{node\_id},\dots)$;}
  \Case{prolonged}{$s = (\text{node\_id},\text{edge\_type},\text{edge\_attrs},\text{node\_attrs},\dots)$;}
}

\Return{$s$}\;
\end{algorithm}

\subsubsection{基于（半）欧拉路径的图序列化}

\textbf{连通化与欧拉化预处理。}
为确保存在覆盖所有边的（半）欧拉路径，
首先对原始图 \(G\) 进行连通性与欧拉特性预处理。
记 \(\tilde{G} = (V, \tilde{E}, X, A)\) 为连通化后的图，
其中在不同连通分量之间添加合成边
\(E_{\mathrm{syn}}\)，使得
\(
\tilde{E} = E \cup E_{\mathrm{syn}}
\)
对应连通图，
合成边统一以特殊 token（如 \texttt{[EDGE\_JUMP]}）与默认属性标记。
若 \(\tilde{G}\) 仍非（半）欧拉图，则进一步构造欧拉多重图 \(G^{\mathrm{eu}}\)，
其公式如~\ref{eulerized-graph}\ 所示：
\begin{equation}
    G^{\mathrm{eu}} = (V, E^{\mathrm{eu}}, X, A),
    \label{eulerized-graph}
\end{equation}
其中
\(E \subseteq E^{\mathrm{eu}}\)，
通过最小边复制策略保证
\(G^{\mathrm{eu}}\) 满足所有节点度数为偶数或恰有两个奇度节点的条件。
在此基础上，存在一条（半）欧拉路径 $P$，如公式~\ref{elua_path}所示：
\begin{equation}
    P = (v_0, e_1, v_1, \dots, e_m, v_m),
    \label{elua_path}
\end{equation}
使得每条边 \(e_i \in E^{\mathrm{eu}}\) 恰好被遍历一次，
其中 \(m = |E^{\mathrm{eu}}|\)。
对应的节点序列记为
\(
P^{\mathrm{node}} = (v_0, v_1, \dots, v_m)
\)，
长度为 \(m+1\)。
在实际实现中，常以 \(m\) 近似表示节点序列长度，此时共有 \(m-1\) 条边与之对应。

\textbf{节点重索引与循环偏移。}
原始节点编号通常带有实现偏置，
若直接用于 token 化会导致结构 token 频率高度不均。
为此，首先基于路径首次出现顺序定义重索引映射，计算公式如~\ref{eq:reindex}\ 所示：
\begin{equation}
    \pi: V \rightarrow \{0, 1, \dots, n-1\},
    \label{eq:reindex}
\end{equation}
其中 \(n = |V|\)，
\(\pi(v)\) 表示节点 \(v\) 在 \(P^{\mathrm{node}}\) 中的首次出现位置。
进一步为缓解不同图尺度间的索引分布偏移，
引入循环重索引机制，其公式如~\ref{eq:cycle-reindex}\ 所示
\begin{equation}
    \pi_r(v) = (\pi(v) + r) \bmod N,
    \label{eq:cycle-reindex}
\end{equation}
其中 \(r\) 为在预设区间内均匀采样的随机整数,
\(N\) 为大于最大节点数的超参数。
该设计一方面在训练过程中均匀激活不同索引 token，
另一方面避免测试阶段出现大编号节点在预训练中从未出现的 OOD 情形。
基于上述重索引，可得到仅含结构信息的节点序列，其公式如~\ref{eq:struct-seq}\ 所示：
\begin{equation}
    s^{\mathrm{struct}} = 
    \big(\pi_r(v_0), \pi_r(v_1), \dots, \pi_r(v_{m-1})\big),
    \quad s^{\mathrm{struct}} \in \mathcal{V}^m.
    \label{eq:struct-seq}
\end{equation}

\textbf{属性附着与序列长度控制。}
在结构序列基础上，还需整合节点与边属性。
记每条边携带 \(d_e\) 维离散或量化后的属性，
每个节点携带 \(d_v\) 维属性。
在最一般的“prolonged” 格式下，
每对相邻节点 \((v_{i-1}, v_i)\) 被展开为：
“节点索引 + 边类型 + $d_e$ 个边属性 token + $d_v$ 个节点属性 token”，
对应每个“边步长”的 token 数量表示如~\ref{eq:edge-token-length}\ 所示：
\begin{equation}
    \ell = 2 + d_e + d_v.
    \label{eq:edge-token-length}
\end{equation}
由此可定义三类典型编码形式：
\begin{align}
    &\text{短格式（short）：} 
    &&L_{\mathrm{short}} = m, \\
    &\text{长格式（long）：} 
    &&L_{\mathrm{long}} = 2(m-1) + 1, \\
    &\text{扩展格式（prolonged）：} 
    &&L_{\mathrm{pro}} = \ell (m-1) + 1,
\end{align}
其中 \(L_{\cdot}\) 为最终序列长度。
本文在主要实验中采用接近 prolonged 的设定，
以最大程度暴露节点与边的语义属性，
同时通过上述长度公式显式控制不同图规模与属性维度下的最大序列长度，
便于在显存和上下文窗口约束下进行配置。

在上述构造下，图到序列的整体映射可以统一写为公式~\ref{eq:graph-to-seq}：
\begin{equation}
    s = \Phi(G) = 
    \Phi_{\mathrm{attr}}\!\big(P^{\mathrm{node}}, X, A; \pi_r, \text{format}\big),
    \label{eq:graph-to-seq}
\end{equation}
其中 \(\Phi_{\mathrm{attr}}\) 表示在固定欧拉路径与重索引策略下的属性附着算子。

\textbf{高保真可逆性与理论分析。}
本文提出的高保真可逆性指的是在给定子图 $G$ 上，
在解码端过滤 \texttt{[EDGE\_JUMP]} 与 \texttt{[EDGE\_DUP]} 等标记边后，有 $\Psi(\Phi(G))\cong G$ 成立。
由于欧拉路径遍历了图中每一条边，
且相邻结构 token 与边之间一一对应，
在给定边方向与特殊边类型标记的前提下，
可以从序列恢复出多重图
\(
\hat{G}^{\mathrm{eu}} = (V, \hat{E}^{\mathrm{eu}}, X, A)
\)。
进一步移除欧拉化引入的边复制与合成跳转边 \(E_{\mathrm{syn}}\)，
即可得到与原图 \(G\) 同构的图。
因此存在逆映射
\(
\Psi: \mathcal{V}^\ast \rightarrow \mathcal{G}
\)，
满足公式~\ref{eq:invertible}：
\begin{equation}
    \Psi(\Phi(G)) \cong G,
    \label{eq:invertible}
\end{equation}
从而在同构意义下实现图到序列的编码。
对于超大规模全图，本文通过子图采样获得局部视窗并分别序列化，
从而以可控序列长度实现对全图结构的{局部覆盖与统计性表征}，
这一理论性质为后续基于序列的生成式预训练与图重建任务提供了坚实基础。

\subsubsection{大图适配：子图采样与局部序列化}

对于节点与边数量高达数十亿规模的大图，
在全图上直接执行欧拉化与路径搜索不仅计算和内存开销难以接受，
得到的序列长度也往往远超上下文窗口。
因此，本文在大图场景下引入子图采样机制，
先将全图拆解为若干尺寸可控的局部子图，再对每个子图独立进行欧拉路径序列化。

记大图为 \(G^{\mathrm{big}}\)，
采样算子为
\(
\mathcal{S}_\theta
\)，
其中 \(\theta\) 表示采样超参数（如 hop 数与每层邻居数等）。
对一组中心节点或中心边 \(\{c_k\}_{k=1}^K\)，
采样得到局部子图集合，其公式如~\ref{eq:subgraph-sampling}\ 所示：
\begin{equation}
    H_k = \mathcal{S}_\theta(G^{\mathrm{big}}, c_k),
    \quad k = 1, \dots, K.
    \label{eq:subgraph-sampling}
\end{equation}
每个子图 \(H_k\) 通过上述欧拉路径编码获得局部序列，
其公式如~\ref{eq:subgraph-seq}\ 所示：
\begin{equation}
    s_k = \Phi(H_k),
    \quad |s_k| \leq L_{\max} \leq L_{\mathrm{ctx}},
    \label{eq:subgraph-seq}
\end{equation}
其中 \(L_{\mathrm{ctx}}\) 为 Transformer 的上下文窗口长度，
\(L_{\max}\) 由采样参数与属性格式联合决定。
在具体实现中，可采用 ShaDowKHop 等局部采样器，
通过调整 hop 深度与邻居数，使采样子图既覆盖足够的局部结构上下文，
又在序列长度与计算成本之间取得平衡。

与简单地对超长线性序列进行硬性尾部截断相比，
本文采用的‘子图采样→独立欧拉序列化’
方案优势在于保持了局部结构的语义完整性。
尽管采样限制了视窗范围，但欧拉路径编码保证了在采样出的子图内部，
所有边和节点关系都被无损地转化为序列，
避免了在视窗内部出现结构碎片化或语义断层。

综上，基于（半）欧拉路径的图到 token 序列化框架，
在形式上给出了从图到序列的可逆映射 \(\Phi\) 与 \(\Psi\)，
并通过序列长度上界分析与子图采样机制，
实现了在不同图尺度上的统一、可控编码。
在此基础上，下一小节将进一步介绍专用图结构编码器如何在 token 序列空间中提炼可迁移的结构语义表征。

\subsection{图结构编码器与节点表征抽取}

在获得图到序列的可逆映射 $\Phi:\mathcal{G}\rightarrow\mathcal{V}^\ast$ 之后，
本文构建专用的图结构编码器 $\mathrm{Enc}_G$，
旨在将由（半）欧拉化 路径生成的结构化 Token 序列映射为
蕴含丰富拓扑语义的节点级结构向量 $h_v^{\mathrm{struc}}\in\mathbb{R}^{d_g}$。
需要指出的是，鉴于大规模图的完整序列长度往往超出模型上下文限制，
本文在实际训练与推理中采用子图采样策略：
即以目标节点 $v$ 为中心提取局部子图 $G_v=S(v)\subseteq G$，
再对其执行序列化 $s_v=\Phi(G_v)$。
因此，下文所述的“可逆重构”特指在采样子图 $G_v$ 范围内的结构信息保留。

\textbf{输入嵌入与位置编码。}
对任意子图 $G_v$，
通过序列化得到离散 token 序列
$s_v=(w_1,\dots,w_L)$，其中 $w_i\in\mathcal{V}$、$L\le L_{\mathrm{ctx}}$。
为避免 token 语义歧义，本文将图序列中的 token 按类型函数 $\tau(\cdot)$ 划分为
节点/边/属性/特殊标记等类别，并引入类型嵌入以显式区分不同语法成分。
图结构编码器的第 $i$ 个位置输入表示由三部分叠加得到，
具体公式如\ref{eq:enc-input}\ 所示：
\begin{equation}
  X^{(0)}_i
  = E_{\mathrm{tok}}(w_i)
  + E_{\mathrm{pos}}(i)
  + E_{\mathrm{type}}\!\big(\tau(w_i)\big),
  \quad i = 1,\dots,L,
  \label{eq:enc-input}
\end{equation}
其中 $E_{\mathrm{tok}}:\mathcal{V}\rightarrow\mathbb{R}^{d_g}$ 为 token 嵌入矩阵，
$E_{\mathrm{pos}}:\{1,\dots,L_{\mathrm{ctx}}\}\rightarrow\mathbb{R}^{d_g}$ 为可学习位置编码，
$E_{\mathrm{type}}$ 为类型嵌入表。
从而得到输入张量
$X^{(0)}\in\mathbb{R}^{L\times d_g}$。
对不同长度序列，采用 padding 对齐到最大长度，并通过 attention mask 屏蔽 padding 位置。

\textbf{24 层双向 Transformer 编码器。}
由于序列化后的 token 流在局部上遵循路径遍历的邻接关系，
同时远距离 token 之间仍可通过多跳拓扑依赖建立关联，
本文采用 $L_{\mathrm{enc}}=24$ 层堆叠的双向 Transformer Encoder 作为骨干，
并将其注意力机制设为双向可见，以充分建模子图内部的长程依赖。
该结构与 GraphGPT-B24~\cite{Zhao2023GraphGPTGP} 的图编码器配置保持一致，
并在容量上与 BERT-Base ~\cite{BERT}规模相当，
其中$d_g=768,\,H=12,\,L_{\mathrm{enc}}=24$。

编码器采用 pre-norm 残差结构。记第 $l$ 层输入隐藏状态为
$H^{(l-1)}\in\mathbb{R}^{L\times d_g}$，
则更新为公式~\ref{eq:enc-update-1}和~\ref{eq:enc-update-2}：
\begin{align}
  \tilde{H}^{(l)}
  &= H^{(l-1)}
     + \mathrm{MSA}^{(l)}\!\big(\mathrm{LN}_1^{(l)}(H^{(l-1)}); M\big),
  \label{eq:enc-update-1}
  \\
  H^{(l)}
  &= \tilde{H}^{(l)}
     + \mathrm{FFN}^{(l)}\!\big(\mathrm{LN}_2^{(l)}(\tilde{H}^{(l)})\big),
  \label{eq:enc-update-2}
\end{align}
其中 $\mathrm{MSA}^{(l)}$ 为多头自注意力，$\mathrm{FFN}^{(l)}$ 为逐位置前馈网络。
注意力掩码 $M\in\mathbb{R}^{L\times L}$ 仅屏蔽 key 侧的 padding 位置，
具体如公式~\ref{eq:padding_case}\ 所示：
\begin{align}
M_{ij}=
\begin{cases}
0, & \text{若位置 } j \text{ 为有效 token},\\
-\infty, & \text{若位置 } j \text{ 为 padding}.
\end{cases}
\label{eq:padding_case}
\end{align}
该设计使任意有效位置均可双向聚合上下文信息，
从而适配后续的 SMTP 式掩码 token 预测预训练目标。

为便于表述，下文给出标准多头注意力形式。令
$\bar{H}^{(l-1)}=\mathrm{LN}_1^{(l)}(H^{(l-1)})$，
第 $h$ 个头的查询、键、值由公式~\ref{eq:attn-qkv} \ 给出：
\begin{align}
  Q_h &= \bar{H}^{(l-1)} W^{(l)}_{Q,h},\quad
  K_h = \bar{H}^{(l-1)} W^{(l)}_{K,h},\quad
  V_h = \bar{H}^{(l-1)} W^{(l)}_{V,h},
  \label{eq:attn-qkv}
\end{align}
对应注意力输出如公式~(\ref{eq:attn}) 所示：
\begin{equation}
  \mathrm{Attn}_h(H^{(l-1)})
  = \mathrm{Softmax}\!\left(
       \frac{Q_h K_h^\top}{\sqrt{d_g/H}} + M
     \right) V_h,
  \label{eq:attn}
\end{equation}
其中 $W^{(l)}_{Q,h},W^{(l)}_{K,h},W^{(l)}_{V,h}\in\mathbb{R}^{d_g\times(d_g/H)}$ 为可学习参数。
各头输出在最后一维拼接后，经线性映射得到多头自注意力模块输出，其形式可写为
公式~\ref{eq:msa}：
\begin{equation}
  \mathrm{MSA}^{(l)}(H^{(l-1)})
  = \mathrm{Concat}\!\left(\mathrm{Attn}_1,\dots,\mathrm{Attn}_H\right) W^{(l)}_O,
  \label{eq:msa}
\end{equation}
其中 $W^{(l)}_O\in\mathbb{R}^{d_g\times d_g}$ 为输出投影矩阵。

前馈网络采用两层 MLP，其形式如公式~\ref{eq:ffn}\  所示：
\begin{equation}
  \mathrm{FFN}^{(l)}(x)
  = W^{(l)}_2\, \sigma\!\left(W^{(l)}_1 x + b^{(l)}_1\right) + b^{(l)}_2,
  \label{eq:ffn}
\end{equation}
其中 $W^{(l)}_1\in\mathbb{R}^{d_g\times d_{\mathrm{ff}}}$，
$W^{(l)}_2\in\mathbb{R}^{d_{\mathrm{ff}}\times d_g}$，
$\sigma(\cdot)$ 为非线性激活函数（如 $\mathrm{GELU}$）。
经过 $L_{\mathrm{enc}}$ 层堆叠，得到 token 级结构表征如公式~\ref{eq:enc-output}\  所示：
\begin{equation}
  H^{(L_{\mathrm{enc}})} = \mathrm{Enc}_G(s_v)\in \mathbb{R}^{L\times d_g}.
  \label{eq:enc-output}
\end{equation}



\textbf{多粒度图结构表征提取。}
基于编码器输出，本文设计了统一的读出接口 $\mathrm{Pool}_g(\cdot)$，
以灵活适配不同粒度的下游任务。
本文采用查询标记追加（Query Token Appending）策略，
利用注意力机制的全局聚合能力提取特定表征：\begin{itemize}\item \textit{图级表征：} 在序列尾部追加全局汇总标记 $[\mathrm{GSUM}]$。
图级向量定义为该位置的输出 
$h_G^{\mathrm{struc}} = H^{(L_{\mathrm{enc}})}_{i_{\mathrm{gsum}}}$，
它在训练中自适应地聚合了子图的整体拓扑特征。\item \textit{节点级表征：} 
对于目标节点 $v$，将其对应的节点 Token 追加至序列末端（位置 $i_v$）。
由于采用双向注意力，该位置能够“看到”序列中该节点的所有历史出现及其邻域信息，
从而输出一个去歧义的、融合了完整上下文的节点向量 $h_v^{\mathrm{struc}} =
 H^{(L_{\mathrm{enc}})}_{i_v}$。\item \textit{边级表征：} 对于连边 $(u,v)$，
 依次追加两个端点的 Token，并将对应的输出表征通过聚合函数（如拼接后线性投影）
 融合：$h_{(u,v)}^{\mathrm{struc}} = \mathrm{Agg}(H^{(L_{\mathrm{enc}})}_{i_u}, 
 H^{(L_{\mathrm{enc}})}_{i_v})$。\end{itemize}
 
 综上，图结构编码器 $\mathrm{Enc}_G$ 将局部子图的（半）欧拉化 路径序列化结果
$s_v=\Phi(G_v)$ 映射到统一隐藏空间 $\mathbb{R}^{d_g}$，
并为不同粒度图任务提供结构表征接口。
该设计一方面在固定子图范围内最大化保留拓扑与属性信息，
另一方面利用双向 Transformer 的全局上下文建模能力，
为后续自监督预训练与下游节点分类微调提供可迁移的结构语义基底。

\subsection{基于混合数据集的图表征预训练}

在完成基于（半）欧拉路径的图到序列编码 $\Phi(\cdot)$ 以及图结构编码器
$\mathrm{Enc}_G$ 的构建之后，本文进一步在大规模混合图语料上开展自监督表征预训练，
以提升编码器在不同图类型与不同数据域上的结构建模通用性与泛化能力。

\textbf{混合图语料与统一编码。}
本文选取引文网络（Cora\cite{Hu2020OpenGB}、PubMed\cite{Sen2008CollectiveCI}、OGB-Arxiv\cite{Hu2020OpenGB}）、电商协同图（Amazon-*） \cite{Wan2018ItemRO}以及分子图集合
PCQM4Mv2\cite{Hu2021OGBLSCAL} 等作为预训练语料来源。
不同来源的数据在组织形式上存在差异：引文网络与电商图通常对应单一大图，
而 PCQM4Mv2 \cite{Hu2021OGBLSCAL}为由大量分子小图构成的图集合。
为在统一框架下训练 $\mathrm{Enc}_G$，本文将上述数据统一规约为训练样本集合
$\mathcal{D}_{\mathrm{pre}}=\{G_n\}_{n=1}^{N}$，其中每个样本图 $G_n\in\mathcal{G}$ 由以下两种方式产生：
（1）对单一大图数据集，通过子图采样策略
抽取满足长度约束的局部子图；
（2）对 PCQM4Mv2 \cite{Hu2021OGBLSCAL}等小图集合，
直接以单个分子图作为训练样本。
在实现中，本文对不同数据源进行重标号与必要的采样筛选，
因此，混合语料的节点/边规模来自实际构建结果，而非简单等于各单一数据集规模之和。

对任意训练样本图 $G_n$，通过图到序列映射 $\Phi$ 得到离散 token 序列，
公式如~\ref{eq:s_n_token}所示：
\begin{equation}
s_n = \Phi(G_n) = \big(w^{(n)}_1,\dots,w^{(n)}_{L_n}\big), \quad w^{(n)}_i\in\mathcal{V},
\label{eq:s_n_token}
\end{equation}
其中 $\mathcal{V}$ 为统一词表，$L_n$ 为序列长度。
为适配编码器上下文长度上限 $L_{\mathrm{ctx}}$，本文在样本构建阶段通过“采样-校验-重采样”
保证 $L_n\le L_{\mathrm{ctx}}$，从而避免超长序列引起的训练不稳定与计算开销失控。

\textbf{SMTP 式掩码 token 预测目标。}
在预训练阶段，本文采用调度掩码 token 预测（SMTP）
作为统一自监督目标，
其本质是对图序列中的被掩码 token 进行分类预测，
使编码器从上下文中恢复被遮蔽的结构与语义信息。
形式上，对于序列 $s_n$，
首先根据调度策略
采样一组掩码位置集合 $\mathcal{I}_n \subseteq \{1,\dots,L_n\}$，
并将这些位置的 token 替换为特殊标记 $[\mathrm{MASK}]$，得到输入序列
$\tilde{s}_n$。
记 $\mathrm{Enc}_G$ 以及其后的 token 分类头联合定义的条件分布
如式~\ref{eq:smtp-pred}\  所示：
\begin{equation}
  p_\theta(w \mid \tilde{s}_n, i),
  \quad w \in \mathcal{V},\; i \in \mathcal{I}_n,
  \label{eq:smtp-pred}
\end{equation}
即在给定被掩码序列 $\tilde{s}_n$ 与位置 $i$ 的条件下，
对该位置原始 token 的预测分布。
对单个序列 $s_n$ 的 SMTP 损失定义为所有掩码位置的平均交叉熵，
形式如式~\ref{eq:smtp-loss}\  所示：
\begin{equation}
  \mathcal{L}_{\mathrm{SMTP}}(s_n)
  = \frac{1}{|\mathcal{I}_n|}
    \sum_{i \in \mathcal{I}_n}
    - \log p_\theta\big(w^{(n)}_i \mid \tilde{s}_n, i\big).
    \label{eq:smtp-loss}
\end{equation}
当序列采用“短／长编码格式”表示多维节点或边属性时，
对于属于同一属性维度的 token 列，
本文在同一列上的所有非 padding 位置共同参与掩码与损失累计，
并先在列内取平均再在图间取平均，
以保证多维属性 token 在预测时的一致性与协同性。最终，
整个混合语料上的预训练目标为所有图损失的期望，
形式化描述如式~\ref{eq:pretrain-loss}\  所示：
\begin{equation}
  \mathcal{L}_{\mathrm{pre}}
  = \frac{1}{N}
    \sum_{n=1}^{N}
    \mathcal{L}_{\mathrm{SMTP}}(s_n),
    \label{eq:pretrain-loss}
\end{equation}
其优化过程等价于在统一词表下对所有结构、属性与特殊 token
进行多分类交叉熵最小化。

\section{图结构和文本的跨模态对齐损失函数改进}
\label{sec:multi_loss_enhanced}

尽管图结构编码器 $\mathrm{Enc}_G$ 与文本特征编码器 $\mathrm{Enc}_T$
分别能够学习有效的结构表征与语义表征，
两种模态在表示空间的几何结构与分布形态上仍存在显著偏移。
在此情况下，若仅通过浅层线性投影将图向量接入预训练语言模型，
模型往往只能获得弱相关的跨模态耦合，难以稳定建立
结构信息到文本语义的可追溯对应关系。
为此，本节面向图-文跨模态对齐过程
构建多层次对齐目标，对共享表示空间施加更强约束。

具体而言，本文以 GraphGPT\cite{Tang2023GraphGPTGI} 的跨模态对比学习范式为基础，
采用基于 InfoNCE 的全局对比损失作为对齐基线，
在此基础上，本文进一步引入两类针对图结构特性的对齐改进：
一是面向局部子结构的细粒度对齐约束，用于强化局部结构模式与局部语义片段之间的对应关系；
二是基于交叉熵的生成式对齐约束，以图结构表示为条件驱动语言解码，
将对齐信号直接注入自回归生成行为，以提升图表征的语言可用性。

综合而言，如\autoref{fig:multi_cross_modal_alignment} 所示，
本节的总体目标由全局对比对齐、局部细粒度对齐与生成式重建对齐三部分组成，
其具体形式与训练细节将在后续小节中给出。

\subsection{基于 InfoNCE 损失的全局表征对齐}
\label{subsec:global_align}

在完成图结构编码器 \(\mathrm{Enc}_G\)、
文本特征编码器 \(\mathrm{Enc}_T\) 以及对齐网络 \(N_A\) 的构建之后，
本文首先采用基于 InfoNCE 损失的全局对齐作为跨模态对齐的基线方案。
该方案借鉴视觉--语言预训练中的对比学习范式，
将同一节点的图结构表征与文本语义表征视作一对语义一致的正样本，
同一批次内其他跨模态组合视作负样本，
从而在共享对齐空间中压缩并对齐两种模态的几何结构。

如第~3.2 节所述，图结构编码器与文本特征编码器分别输出节点级表征
 \(h_i^{\mathrm{struc}} \in \mathbb{R}^{d_g}\) 与 
 \(h_i^{\mathrm{text}} \in \mathbb{R}^{d_t}\)。
 在对齐网络 \(N_A\) 中，通过投影函数 \(f_g\) 和 \(f_t\) 
 将二者映射到共享对齐空间 \(\mathbb{R}^{d_a}\)，
 如式~\ref{eq:align-proj}\ 所示：
\begin{equation}
  \tilde{h}_i^{\mathrm{struc}} = f_g\bigl(h_i^{\mathrm{struc}}\bigr), 
  \qquad
  \tilde{h}_i^{\mathrm{text}} = f_t\bigl(h_i^{\mathrm{text}}\bigr),
  \label{eq:align-proj}
\end{equation}
其中 $f_g:\mathbb{R}^{d_g}\!\rightarrow\!\mathbb{R}^{d_a}$、
$f_t:\mathbb{R}^{d_t}\!\rightarrow\!\mathbb{R}^{d_a}$ 为可学习投影；
本文采用两层 MLP 作为默认实现。

为采用余弦相似度作为对比学习的相似性度量，
本文对投影后的向量进行 $\ell_2$ 归一化，
其计算过程如式~\ref{eq:normalize}\ 所示：
\begin{equation}
  u_i = \frac{\tilde{h}_i^{\mathrm{struc}}}{\bigl\|\tilde{h}_i^{\mathrm{struc}}\bigr\|_2},
  \qquad
  v_i = \frac{\tilde{h}_i^{\mathrm{text}}}{\bigl\|\tilde{h}_i^{\mathrm{text}}\bigr\|_2},
  \label{eq:normalize}
\end{equation}
其中 \(u_i, v_i \in \mathbb{R}^{d_a}\)。
在此基础上，跨模态相似度自然定义为二者的内积，如式~\ref{eq:sim}\  所示：
\begin{equation}
  \mathrm{sim}(u_i, v_j) = u_i^\top v_j.
  \label{eq:sim}
\end{equation}

在训练阶段，设一个批次的样本索引集合为 $\mathcal{B}$，
其中每个样本 $i\in\mathcal{B}$ 对应一对配对的图--文输入，
从而得到一对对齐向量 $(u_i, v_i)$。
对于任意 $i\in\mathcal{B}$，$(u_i, v_i)$ 构成正样本对，
而 $\{(u_i, v_j)\}_{j\in\mathcal{B},\,j\neq i}$ 构成负样本集合。
给定温度系数 \(\tau > 0\)，从“图 \(\rightarrow\) 文本”方向定义的 InfoNCE 损失
如式~\ref{eq:infonce-g2t}\ 所示：
\begin{equation}
  \mathcal{L}_{g \rightarrow t}
  =
  - \frac{1}{|\mathcal{B}|}
    \sum_{i \in \mathcal{B}}
    \log
    \frac{\exp\bigl(\mathrm{sim}(u_i, v_i) / \tau\bigr)}
         {\sum_{j \in \mathcal{B}} \exp\bigl(\mathrm{sim}(u_i, v_j) / \tau\bigr)}.
  \label{eq:infonce-g2t}
\end{equation}

该目标驱动每个图结构向量 \(u_i\) 在对齐空间中靠近其语义对应的 \(v_i\)，同时与其他节点的文本向量保持足够区分度，从图侧约束语言模态的语义几何结构。

为缓解单向对齐带来的偏置并增强训练稳定性，
本文对称地引入“文本 \(\rightarrow\) 图”方向的 InfoNCE 损失。
其形式如式~\ref{eq:infonce-t2g}\ 所示：
\begin{equation}
  \mathcal{L}_{t \rightarrow g}
  =
  - \frac{1}{|\mathcal{B}|}
    \sum_{i \in \mathcal{B}}
    \log
    \frac{\exp\bigl(\mathrm{sim}(v_i, u_i) / \tau\bigr)}
         {\sum_{j \in \mathcal{B}} \exp\bigl(\mathrm{sim}(v_i, u_j) / \tau\bigr)}.
  \label{eq:infonce-t2g}
\end{equation}

综合两种方向，基于 InfoNCE 的全局表征对齐基线损失定义为对称损失的平均，
其形式如式~\ref{eq:global-align}\ 所示：
\begin{equation}
  \mathcal{L}_{\mathrm{global}}
  =
  \frac{1}{2}
  \bigl(
    \mathcal{L}_{g \rightarrow t}
    +
    \mathcal{L}_{t \rightarrow g}
  \bigr).
  \label{eq:global-align}
\end{equation}

在优化过程中，冻结图编码器\(\mathrm{Enc}_G\) 和
文本编码器\(\mathrm{Enc}_T\) ，
仅训练投影网络 \(N_A\) 中的 \(f_g, f_t\) 模块参数，
从而在统一的对齐空间中获得互为检索和互相约束的全局跨模态表征。

需要指出的是，本小节的 InfoNCE 对齐仅在节点级全局向量上施加约束，
并未显式建模子结构级对应关系或生成式一致性，
因此可视作一种标准的跨模态对齐基线。
下一小节将在此基础上进一步引入面向子结构的局部表征对齐机制，
以提升对细粒度图结构语义的区分与建模能力。



\subsection{子结构-短语级的局部语义对齐机制}
\label{subsec:local_align}

仅依赖前文基于 InfoNCE 的节点级全局对齐，
虽然能够在整体上拉近图结构表征与文本表征的语义距离，
但其约束主要作用于节点级全局向量，
难以显式刻画欧拉路径上\emph{局部子结构}与\emph{细粒度语言片段}之间的一致性。
为进一步提升模型对边邻域模式与关系语义的捕获能力，
本文在欧拉路径解析基础上引入子结构-短语级局部对齐机制，
借鉴 GraphTranslator \cite{Zhang2024GraphTranslatorAG}的多粒度对齐思想，
在统一对齐空间内对局部子图与局部文本描述施加更强的对应约束。
整体流程如算法~\ref{alg:local_match_algorithm}\ 所示。

\begin{algorithm}[t]
\caption{子结构-短语级 token 匹配损失 $\mathcal{L}_{\mathrm{match}}$ 的计算流程}
\label{alg:local_match_algorithm}
\KwIn{子结构序列集合 $\{s_{i,k}\}$ 及其对应文本片段 token 序列 $\{x^{(u)}_{i,k}\}$；
图结构编码器 $\mathrm{Enc}_G$；
文本编码骨干 $\Phi_{\mathrm{LM}}$；
token 级投影层 $W_g, W_t$；
匹配温度 $\tau_{\mathrm{m}}$ 与缩放系数 $\gamma$；
负样本采样算子 $\mathcal{N}(\cdot)$（默认 in-batch）}
\KwOut{token 匹配损失 $\mathcal{L}_{\mathrm{match}}$}

初始化样本集合 $\mathcal{B}\gets\emptyset$\;

\ForEach{正样本对 $(s_{i,k}, x^{(u)}_{i,k})$}{
  $H^{\mathrm{g}}_{i,k} \gets \mathrm{Enc}_G(s_{i,k})\, W_g$\;
  $H^{\mathrm{t}}_{i,k} \gets \Phi_{\mathrm{LM}}(E(x^{(u)}_{i,k}))\, W_t$\;
  计算相似度矩阵 $a_{i,k}(\ell,j)=\mathrm{sim}(H^{\mathrm{g}}_{i,k}[\ell],H^{\mathrm{t}}_{i,k}[j])$\;
  计算 softmax 权重 $\pi_{i,k}(\ell,\cdot)=\mathrm{softmax}(a_{i,k}(\ell,\cdot)/\tau_{\mathrm{m}})$\;
  计算匹配得分 $m_{i,k}\gets \frac{1}{L_{i,k}}\sum_{\ell}\sum_{j}\pi_{i,k}(\ell,j)a_{i,k}(\ell,j)$\;
  将 $(m_{i,k}, y{=}1)$ 加入 $\mathcal{B}$\;

  \ForEach{$x^{(u)}_{j,l} \in \mathcal{N}(x^{(u)}_{i,k})$}{
    $H^{\mathrm{t}}_{j,l} \gets \Phi_{\mathrm{LM}}(E(x^{(u)}_{j,l}))\, W_t$\;
    以同样方式计算错配得分 $m^{\mathrm{neg}}_{(i,k)\rightarrow(j,l)}$\;
    将 $(m^{\mathrm{neg}}_{(i,k)\rightarrow(j,l)}, y{=}0)$ 加入 $\mathcal{B}$\;
  }
}

基于 Sigmoid 的二元交叉熵计算
$\mathcal{L}_{\mathrm{match}}= -\frac{1}{|\mathcal{B}|}\sum_{(m,y)\in\mathcal{B}}\bigl[y\log\sigma(\gamma m)+(1-y)\log(1-\sigma(\gamma m))\bigr]$\;
\Return{$\mathcal{L}_{\mathrm{match}}$}\;
\end{algorithm}



\textbf{局部子结构与文本片段的构造。}
对每个目标节点 $i$，首先提取其局部邻域子图 $S_i=(V_i,E_i,X_i,A_i)$，
并通过子结构采样算子 $\mathcal{S}_{\mathrm{sub}}$
将其划分为尺寸可控的若干子结构 $\{S_{i,k}\}_{k=1}^{K_i}$，
如式~\ref{eq:sub_sampling}\ 所示：
\begin{equation}
  S_{i,k}
  = \mathcal{S}_{\mathrm{sub}}\bigl(S_i,\, c_{i,k},\, \theta_{\mathrm{sub}}\bigr),
  \quad k=1,\dots,K_i.
  \label{eq:sub_sampling}
\end{equation}
其中 $c_{i,k}$ 为子结构中心（节点或边），
$\theta_{\mathrm{sub}}$ 为采样超参数（如 hop 数与邻居数），并用于显式控制 $|E_{i,k}|$ 以保证序列长度可被上下文窗口容纳。
对每个子结构 $S_{i,k}$，利用欧拉路径序列化映射 $\Phi$ 得到局部结构序列
$s_{i,k}=\Phi(S_{i,k})$。

在语义侧，参考 GraphTranslator \cite{Zhang2024GraphTranslatorAG}中 Producer 的分解式文本构造范式，
本文为每个子结构 \(S_{i,k}\) 设计局部描述模板，将中心节点属性、
邻域属性与局部关系模式整合为一段自然语言片段
\(
u_{i,k}
\)，并由文本编码器 \(\mathrm{Enc}_T\) 映射至语义空间。
记局部文本序列为
\(
x^{(u)}_{i,k} = \tau(u_{i,k})
\)，
则相应的语义表示如式~\ref{eq:sub_text_embed} 所示：
\begin{equation}
  h^{\mathrm{text}}_{i,k}
  = \mathrm{Pool}_t\!\bigl(\Phi_{\mathrm{LM}}\bigl(E(x^{(u)}_{i,k})\bigr)\bigr)
  \in \mathbb{R}^{d_t},
  \label{eq:sub_text_embed}
\end{equation}
其中 \(\Phi_{\mathrm{LM}}, E, \mathrm{Pool}_t(\cdot)\) 的定义与前文文本编码器一致。

\textbf{子结构级对齐向量与局部 InfoNCE。}
对于每个子结构序列 \(s_{i,k}\)，
图结构编码器 \(\mathrm{Enc}_G\) 给出 token 级编码表示
\(
H_{i,k} = \mathrm{Enc}_G(s_{i,k}) \in \mathbb{R}^{L_{i,k}\times d_g}
\)。
为获得子结构级结构表示，
本文在序列尾部为每个子图附加特殊标记 \([\mathrm{SSUM}]\)，
并从对应位置读取局部聚合向量，或对该子图内的结构 token 进行平均池化，
得到\( h^{\mathrm{struc}}_{i,k}\)，其公式如~\ref{eq:sub_graph_embed}\ 所示：

\begin{equation}
  h^{\mathrm{struc}}_{i,k}
  = \mathrm{Pool}_g\!\bigl(H_{i,k}\bigr)
  \in \mathbb{R}^{d_g},
  \label{eq:sub_graph_embed}
\end{equation}
其中 \(\mathrm{Pool}_g(\cdot)\) 为子图级读出算子。
与全局节点级对齐类似，
局部对齐网络 \(N_A\) 通过一组可学习投影函数
\(f_g, f_t\) 将结构与文本表征映射至共享对齐空间
\(\mathbb{R}^{d_a}\)；
在子结构层面，
得到局部结构表征\(z^{\mathrm{g}}_{i,k}\)
与文本片段表征\(z^{\mathrm{t}}_{i,k}\)，如式~\ref{eq:sub_proj}\ 所示：
\begin{equation}
  z^{\mathrm{g}}_{i,k} = f_g\bigl(h^{\mathrm{struc}}_{i,k}\bigr),
  \qquad
  z^{\mathrm{t}}_{i,k} = f_t\bigl(h^{\mathrm{text}}_{i,k}\bigr)
  \in \mathbb{R}^{d_a}.
  \label{eq:sub_proj}
\end{equation}
设 \(\mathrm{sim}(\cdot,\cdot)\) 基于余弦相似度归一化相似度度量，
\(\tau_{\mathrm{sub}}>0\) 为温度系数，
则在一个批次内，
每个 \((i,k)\) 对应一组正样本 \((z^{\mathrm{g}}_{i,k},z^{\mathrm{t}}_{i,k})\)，
其余子结构间跨模态组合视作负样本。局部 InfoNCE 损失定义如式~\ref{eq:sub_infonce}\ 所示：
\begin{equation}
  \mathcal{L}_{\mathrm{sub}}^{\mathrm{g\rightarrow t}}
  = - \frac{1}{\sum_i K_i}
    \sum_{i,k}
    \log
    \frac{
      \exp\bigl(\mathrm{sim}(z^{\mathrm{g}}_{i,k}, z^{\mathrm{t}}_{i,k}) / \tau_{\mathrm{sub}}\bigr)
    }{
      \sum\limits_{(j,l)} \exp\bigl(\mathrm{sim}(z^{\mathrm{g}}_{i,k}, z^{\mathrm{t}}_{j,l}) / \tau_{\mathrm{sub}}\bigr)
    },
  \label{eq:sub_infonce}
\end{equation}
并可对称地定义文本到图的对齐损失
\(\mathcal{L}_{\mathrm{sub}}^{\mathrm{t\rightarrow g}}\)，
从而得到双向局部对齐目标，如式~\ref{eq:sub_bidirectional} 所示：
\begin{equation}
  \mathcal{L}_{\mathrm{sub}}
  = \frac{1}{2}
    \bigl(
      \mathcal{L}_{\mathrm{sub}}^{\mathrm{g\rightarrow t}}
      + \mathcal{L}_{\mathrm{sub}}^{\mathrm{t\rightarrow g}}
    \bigr).
  \label{eq:sub_bidirectional}
\end{equation}
与仅依赖节点级全局对齐的情形相比，
\(\mathcal{L}_{\mathrm{sub}}\) 将欧拉路径上的局部子图窗口与对应的局部自然语言片段一一对齐，
显式强化模型对局部邻域模式和关系语义的建模。

\textbf{基于 token 级匹配的细粒度局部约束。}
在子结构级对齐之外，
本文进一步引入 token 级匹配损失，以刻画子图内部结构 token 与文本 token 之间的细粒度对应关系。
本文通过对 \(H_{i,k}\) 与 \(\Phi_{\mathrm{LM}}(E(x^{(u)}_{i,k}))\) 施加线性变换获得
对齐空间中的结构侧token表示\(H^{\mathrm{g}}_{i,k} \in \mathbb{R}^{L_{i,k}\times d_a}\)
与文本侧 token 表示\(H^{\mathrm{t}}_{i,k} \in \mathbb{R}^{L^{(u)}_{i,k}\times d_a}\)，
则第 \(\ell\) 个结构 token 与第 \(j\) 个文本 token 之间的相似度，如式~\ref{eq:token_sim}\ 所示：
\begin{equation}
  s_{i,k}(\ell,j)
  = \mathrm{sim}\!\bigl(H^{\mathrm{g}}_{i,k}[\ell],\, H^{\mathrm{t}}_{i,k}[j]\bigr).
  \label{eq:token_sim}
\end{equation}

借鉴 GraphTranslator \cite{Zhang2024GraphTranslatorAG}中细粒度匹配目标的设计思想，
本文采用最大匹配聚合策略将 token 级相似度汇总为子结构匹配得分，
如式~\ref{eq:local_match_score}\ 所示：
\begin{equation}
  m_{i,k}
  = \frac{1}{L_{i,k}}
    \sum_{\ell=1}^{L_{i,k}}
      \max_{1\le j \le L^{(u)}_{i,k}} s_{i,k}(\ell,j),
  \label{eq:local_match_score}
\end{equation}
即每个结构 token 只与最相似的文本 token 对齐，
并在子结构内求平均以得到整体匹配度。
在训练时，
对正样本对 \((i,k)\) 赋予标签 \(y_{i,k}=1\)，
对由不同子结构或不同节点构成的负样本对 \((i,k),(j,l)\) 赋予标签 \(0\)，
构造二元交叉熵损失，其公式表示如式~\ref{eq:local_match_loss}\ 所示：
\begin{equation}
  \mathcal{L}_{\mathrm{match}}
  = - \frac{1}{|\mathcal{B}|}
    \sum_{(i,k)\in\mathcal{B}}
    \bigl[
      y_{i,k} \log \sigma(m_{i,k})
      + (1-y_{i,k}) \log \bigl(1-\sigma(m_{i,k})\bigr)
    \bigr],
  \label{eq:local_match_loss}
\end{equation}
其中 \(\sigma(\cdot)\) 为 Sigmoid 函数，
\(\mathcal{B}\) 为构造好的正负样本集合。
该匹配损失鼓励结构 token 与语义 token 在局部一一对齐，
从而避免仅依赖子图级 pooling 带来的语义过度平滑。

\textbf{局部对齐损失的总体形式。}
综合子结构级 InfoNCE 与 token 级匹配约束，
面向子结构的局部对齐损失定义如式~\ref{eq:local_total}\ 所示：
\begin{equation}
  \mathcal{L}_{\mathrm{local}}
  = \lambda_{\mathrm{sub}} \mathcal{L}_{\mathrm{sub}}
  + \lambda_{\mathrm{match}} \mathcal{L}_{\mathrm{match}},
  \label{eq:local_total}
\end{equation}
其中 \(\lambda_{\mathrm{sub}},\lambda_{\mathrm{match}}\ge 0\) 为权重系数。
在总体训练目标中，
\(\mathcal{L}_{\mathrm{local}}\) 与前文节点级全局对齐损失
\(\mathcal{L}_{\mathrm{global}}\) 共同作用：
前者强调局部子结构与局部文本片段的细粒度一致性，
后者保证整体节点类别语义与文本描述的一致性，
二者协同使得跨模态表示在全局语义、局部拓扑与细粒度属性三个层面均保持对齐，
为后续基于交叉熵的跨模态生成对齐奠定基础。



\subsection{图到文本重建与联合训练目标}
\textbf{图到文本重建。}
在完成图结构与语义文本的对比对齐之后，本文进一步引入基于交叉熵的图到文本重建目标，
以强化图结构表征对节点语义信息的保留与还原能力。
具体地，对于带有文本属性的节点 $v$，记其标准化后的图结构条件表示为 $H_{\mathrm{cond}}^{(v)}$，
对应节点文本被分词为序列
\(
\mathbf{w}_v = (w_{v,1},\dots,w_{v,L_v}),
\)
其中 $L_v$ 为文本长度。
在此条件下，文本解码器 $\mathrm{Dec}_T$ 对节点文本建模的自回归条件分布可写为
式~\ref{eq:graph2text_prob}\ ：
\begin{equation}
  p_\theta(\mathbf{w}_v \mid G,T,q_{\mathrm{rec}})
  =
  \prod_{t=1}^{L_v}
  p_\theta\big(w_{v,t} \mid w_{v,<t}, H_{\mathrm{cond}}^{(v)}\big),
  \label{eq:graph2text_prob}
\end{equation}
其中 $q_{\mathrm{rec}}$ 为用于重建任务的统一提示模板，$w_{v,<t}$ 表示第 $t$ 个位置之前的所有词片。
该式显式刻画了在图结构条件 $H_{\mathrm{cond}}^{(v)}$ 下，解码器按时间步依次生成文本 token 的过程。

在训练阶段，采用教师强制（Teacher Forcing）策略，
以真实文本序列
\(
\mathbf{w}_v^\star = (w_{v,1}^\star,\dots,w_{v,L_v}^\star)
\)
作为解码器输入，最小化基于负对数似然的交叉熵损失。
对一个包含若干节点的 mini-batch $B$，图到文本重建损失定义如式~\ref{eq:graph2text_ce}\ 所示：
\begin{equation}
  \mathcal{L}_{\mathrm{CE}}
  =
  -\frac{1}{|B|}
  \sum_{v \in B}
  \sum_{t=1}^{L_v}
  \log
  p_\theta\big(
    w_{v,t}^\star
    \,\big|\,
    w_{v,<t}^\star,
    H_{\mathrm{cond}}^{(v)}
  \big).
  \label{eq:graph2text_ce}
\end{equation}
该目标在样本维度与时间维度上对预测对数概率求和，并对 batch 大小进行归一化。
直观上，$\mathcal{L}_{\mathrm{CE}}$ 约束由图编码器与跨模态投影模块得到的结构表征
能够在不访问原始文本编码器的情况下“重述”节点的语义描述，
从而鼓励图空间中保留与文本空间一致的细粒度语义信息，
并为后续基于图结构条件的生成式节点分类与图推理奠定基础。

\textbf{联合训练目标。}
在此基础上，本文采用多目标联合优化策略，将节点级全局对齐损失、局部对齐损失与图到文本重建损失进行加权组合。
记第~\ref{subsec:global_align} 节中定义的节点级 InfoNCE 全局对齐损失为 $\mathcal{L}_{\mathrm{global}}$，
第~\ref{subsec:local_align} 节中定义的局部对齐损失为 $\mathcal{L}_{\mathrm{local}}$，
则跨模态对齐阶段的总体训练目标可表示为式~\ref{eq:joint_align_loss}\ ：
\begin{equation}
  \mathcal{L}_{\mathrm{align}}
  =
  \lambda_{\mathrm{g}} \,\mathcal{L}_{\mathrm{global}}
  +
  \lambda_{\mathrm{loc}} \,\mathcal{L}_{\mathrm{local}}
  +
  \lambda_{\mathrm{ce}} \,\mathcal{L}_{\mathrm{CE}},
  \label{eq:joint_align_loss}
\end{equation}
其中 $\lambda_{\mathrm{g}},\lambda_{\mathrm{loc}},\lambda_{\mathrm{ce}} \ge 0$ 为可调权重系数，
用于平衡全局对齐、局部对齐与重建目标在训练过程中的相对贡献。
式~(\ref{eq:joint_align_loss}) 给出了三个损失项在整体跨模态对齐框架中的联合建模形式。

联合优化的直观作用可以概括为：
(i) $\mathcal{L}_{\mathrm{global}}$ 通过 InfoNCE 约束节点级图--文表示在全局语义空间中对齐，
确保图结构向量与对应节点文本在嵌入空间中的一致性；
(ii) $\mathcal{L}_{\mathrm{local}}$ 通过子结构--短语级对齐进一步细化约束，
避免仅依赖全局池化导致的语义过度平滑，使关键子图模式与文本短语之间建立更精细的对应关系；
(iii) $\mathcal{L}_{\mathrm{CE}}$ 则从生成建模角度反向检验图表示的语义完备性，
要求图编码在被送入解码器时能够恢复出高质量的节点描述文本。
三者在式~(\ref{eq:joint_align_loss}) 中协同作用，使得最终得到的图结构表征既适合下游节点分类任务，
又具备良好的跨模态语义对齐与生成能力。

在具体实现中，训练阶段采用基于 AdamW 的随机梯度优化器对图编码器高层与跨模态投影层参数进行更新，
而文本编码器及大部分语言模型主干参数保持冻结，
以避免破坏原有语言知识并降低训练开销。
权重系数 $\lambda_{\mathrm{g}},\lambda_{\mathrm{loc}},\lambda_{\mathrm{ce}}$ 选取为同一量级，
并在验证集上通过网格搜索确定其相对比例；
除非特别说明，后续实验均采用在验证集上表现最优的一组固定配置，
具体数值将在第~\ref{sec:three_total_Experiment} 节的消融实验中给出。

统一转化为欧拉路径结构序列用于结构掩码预测训练。
通过混合产生规模受控子图序列样本的构造方式可迫使编码器学习跨领域共享的拓扑不变量，
而非依赖单一领域统计偏差。

第二阶段跨模态对齐则聚焦于文本属性丰富的真实场景图（Cora、PubMed、OGB-Arxiv），
严格遵循原始数据集的节点文本属性与图结构关联，构建图-文对齐样本对。
所有数据集均采用官方划分标准，节点采样策略与邻域范围保持一致，
以消除预处理差异对实验结果的影响。
在输入格式上，图结构经欧拉路径序列化后统一截断至256 tokens，
文本属性经SentencePiece分词后限制在128 tokens以内，确保模型输入的标准化与可比性。

阶段三监督微调实验回到具体节点分类任务，
严格使用官方训练集进行有监督训练，并在验证集早停，最终报告测试集指标。

\textbf{（4）实验细节配置}

为保证实验可重复性与结果的可比性，
本节统一给出三阶段训练的核心超参数配置。若无特殊说明，
所有实验均在 8 张 A100 80GB GPU 上进行，
采用 DeepSpeed ZeRO-2 混合精度训练，随机种子固定为 42。

{阶段一：图编码器预训练实验细节：}
模型参数如下：图编码器采用 GET-Base24：隐藏维度 \(d_g = 768\)，Transformer 层数为 24，多头注意力头数为 12，前馈层维度 \(d_{\mathrm{ff}} = 4d_g = 3072\)，激活函数为 GELU；注意力层 Dropout 取 0.1，MLP 与嵌入层 Dropout 取 0。
图 token 序列最大长度设为 \(L_{\mathrm{ctx}} = 512\)，对超过该长度的样本通过子图采样截断。
SMTP 掩码比例从 15\% 线性增加到 30\%，并对同一节点在欧拉序列中的全部出现位置同步掩码。
优化器采用 AdamW，\(\beta_1 = 0.9\)、\(\beta_2 = 0.95\)，\(\epsilon = 10^{-8}\)，权重衰减 0.1。学习率采用“预热 + 线性衰减”，最大学习率 \(\mathrm{lr}_{\max} = 3\times10^{-4}\)，最小值为 0，预热步数占总训练步数的 5\%。全局梯度裁剪阈值为 1.0。
全局 batch size 为 256，对短序列采用样本打包策略。总训练步数为 150k，可覆盖约 \(10^8\) 级别的图 token。按固定步长在验证集上监控 SMTP 损失及线性探针性能，并选取验证损失最优模型作为阶段一最终结果。

{阶段二：跨模态对齐实验细节：}
阶段二文本编码器 \(\mathrm{Enc}_T\) 采用 RoBERTa-base，隐藏维度 \(d_t = 768\)，
与图侧一同更新。跨模态投影头 \(f_G:\mathbb{R}^{d_g}\rightarrow\mathbb{R}^{d_z}\)、\(f_T:\mathbb{R}^{d_t}\rightarrow\mathbb{R}^{d_z}\) 及局部匹配线性层从随机初始化开始训练，公共语义空间维度设为 \(d_z = 768\)。\(\mathrm{Dec}_T\) 采用 Qwen2.5-7B-Instruct，在本阶段保持冻结。
LLM 侧最大输入长度为 2048 token。全局 batch size 为 16。
节点文本在输入 \(\mathrm{Enc}_T\) 时截断至 256 token 并聚合为节点级表示。
 联合优化全局图–文对比损失 \(\mathcal{L}_{\mathrm{global}}\)、
 局部子结构匹配损失 \(\mathcal{L}_{\mathrm{local}}\) 与
 文本生成损失 \(\mathcal{L}_{\mathrm{gen}}\)，
 权重分别为 \(\lambda_{\mathrm{global}} = 1.0\)、\(\lambda_{\mathrm{local}} = 0.5\)、
 \(\lambda_{\mathrm{gen}} = 0.5\)。
所有可训练参数使用 AdamW。编码器主干学习率 \(\mathrm{lr}_{\mathrm{enc}} = 2\times10^{-4}\)，
跨模态投影头与任务头学习率 \(\mathrm{lr}_{\mathrm{proj}} = 2\times10^{-3}\)，
\(\beta_1 = 0.9\)、\(\beta_2 = 0.95\)，\(\epsilon = 10^{-8}\)，权重衰减 0.01。
学习率采用“预热 + 余弦退火”，预热步数占 3\%，之后按余弦曲线衰减至初始值的 1/10；
全局梯度裁剪阈值同样为 1.0。
综上，除特别说明外，所有基于图–文联合表征的实验均默认采用上述超参数配置。

{阶段三：图基座模型节点分类测评实验细节：}
训练目标为标准交叉熵损失，以正确类别对应的标签词或类别描述作为监督信号，
对 \(\mathrm{Dec}_T\) 输出的分类 token 概率分布计算损失；不额外引入对比或生成项。
各节点分类数据集统一采用 AdamW 优化器，
学习率设置为 \(\mathrm{lr}=2\times10^{-5}\)，\(\beta_1 = 0.9\)、\(\beta_2 = 0.95\)，
\(\epsilon = 10^{-8}\)，权重衰减 0.01；学习率调度采用“预热 + 余弦退火”策略，
预热步数占总训练步数的 3\%，之后按余弦曲线衰减至初始值的 \(1/10\)。
训练轮数上，默认对每个数据集进行 5 个 epoch 的全量训练，
因Cora数据集样本规模较小，所以将其训练样本重复 3 次，以缓解数据不足问题；
早停策略基于验证集 Micro-F1 表现，
选取验证集指标最优的模型用于最终测试与对比。


\subsection{面向节点分类任务的基准对比实验}
\label{subsec:node_classification_analysis}

\subsubsection{实验设置与基准}

为系统测评本文提出的通用图结构基座模型在节点分类任务上的有效性，
本文在 Cora、PubMed 与 OGB-Arxiv 三个经典基准上进行对比实验。
实验重点关注两类改进：{（1）基于欧拉路径的结构序列化与结构预训练}，
以及{（2）多层次图--文对齐目标}，
并检验二者在节点分类任务中的贡献。
本节以测试集准确率（Test Accuracy, \%）作为评价指标。

为构建可对照的比较基准，本文将对比方法分为三类：
\begin{enumerate}
  \item \textbf{传统图神经网络（GNNs）}：
  包括 MLP、GCN\cite{Kipf2016SemiSupervisedCW}、SAGE\cite{Sun2021ScalableAA} 与 RevGAT\cite{Li2024SimilaritybasedNS}，
  代表基于消息传递的监督学习范式。

  \item \textbf{图基座模型（GFMs）}：
  包括 LLaGA（ND/HO）\cite{Chen2024LLaGALL}、GraphGPT\cite{Tang2023GraphGPTGI}、
  GraphPrompter\cite{Lv2025GraphPrompterMA}、GraphTranslator\cite{Zhang2024GraphTranslatorAG} 与 GraphICL\cite{Sun2025GraphICLUG}，
  代表将 LLM 引入图任务的主流框架。

  \item \textbf{本文方法的三种配置}：
  \begin{itemize}
    \item \textbf{方案1（Euler Path + Structural Pre-training）}：
    仅替换图结构输入表示与结构预训练目标。
    具体地，在 LLaGA\cite{Chen2024LLaGALL} 的整体框架保持不变的前提下，
    用欧拉路径结构序列化方式替代邻域模板作为图结构输入，
    并在混合图数据上引入 SMTP 自监督目标进行结构预训练，仅优化图结构编码相关模块。
    该配置用于验证高保真结构序列化以及大规模混合图预训练对下游任务的增益。
    
    \item \textbf{方案2（Multi-level Alignment）}：
    仅引入多层次图--文对齐机制，不改变原始 LLaGA 的图结构线性化策略。
    在保持 ND/HO 模板输入与基础训练流程不变的情况下，
    引入全局对比、局部匹配与生成式重建等多层次图--文对齐损失。
    该配置用于验证对齐损失设计带来的独立贡献。
    \item \textbf{方案3（Graph Foundation Model）}：
    集成方案1与方案2形成完整的图基座模型。
    即以欧拉路径结构序列作为图结构输入，
    先进行 SMTP 结构预训练，
    再进行多层次图--文对齐，
    最后在下游任务上进行监督微调。
    该配置用于评估两类核心设计的叠加协同效应，并作为本文最终方法。
  \end{itemize}
\end{enumerate}

\subsection{欧拉路径图表征的对比和消融实验}
\label{subsec:ablation_encoding}

\subsubsection{不同序列表征机制对下游节点分类任务的性能影响}

为分析图结构序列化方式对节点分类性能的影响，
并在控制变量条件下评估欧拉路径序列化带来的增益，
本文设计了针对图结构编码方式的消融实验。
实验保持语言模型主干（Qwen2.5-7B）与跨模态对齐策略不变，
仅替换“图 $\rightarrow$ 序列”的结构输入构造方式。
为保证对比公平，三种编码策略均在相同的子图采样预算下构造结构输入，
并采用一致的最大结构序列长度上限与截断规则。

本文选取三类代表性的图到序列（ Graph-to-Sequence ）编码范式进行对照：
\begin{enumerate}
  \item \textbf{朴素线性化（Naive Linearization, BFS）}：
  对采样子图进行 BFS 遍历，输出节点序列作为结构输入；
  该策略在输入中\emph{不显式编码边或邻接关系}，因此结构信息主要体现为节点集合及其排列次序。

  \item \textbf{邻域采样编码（Neighbor Sampling, LLaGA-ND/HO）}：
  复现 LLaGA\cite{Chen2024LLaGALL} 框架中的 ND 与 HO 模板，
  以目标节点为中心采样固定数量邻居并组织为文本化结构描述；
  在固定输入长度预算下，该策略对应的结构信息来自\emph{局部邻域的截断/限量采样}。

  \item \textbf{欧拉路径编码（Ours）}：
  对采样得到的诱导子图构造覆盖其边集的（半）欧拉路径序列，
  将子图结构映射为可重构的 token 序列；
  因而在\emph{子图尺度}上提供更完整的边连接信息。
\end{enumerate}

    朴素线性化（BFS） & 节点序列（不含边） & 否 & 78.45 & 71.56 \\
    邻域采样（LLaGA） & 截断邻域（边覆盖部分） & 否 & \underline{88.56} & \underline{74.02} \\
    \textbf{欧拉路径（Ours）} & \textbf{诱导子图边集覆盖} & \textbf{是} & \textbf{89.97} & \textbf{76.12} \\
    \bottomrule
  \end{tabular}
\end{table}

从表~\ref{tab:ablation_encoding} 可以得到以下可检验结论。

1）结构 token 的引入带来稳定的性能增益。
相较于“仅文本”基线，
加入结构序列输入后准确率均提升。
以 Cora 为例，BFS、邻域采样与欧拉路径分别提升 15.33、25.44 与 26.85 个百分点。
以 OGB-Arxiv 为例，三者分别提升 2.36、4.82 与 6.92 个百分点。
该结果表明，在相同训练配置下，结构输入为节点分类提供了额外有效信息来源。

2）仅节点序列的线性化不足以达到边显式编码方法的性能上限。
BFS 线性化在两数据集上均低于后两种策略：
在 Cora 上，BFS 相较邻域采样与欧拉路径分别低 10.11 与 11.52 个百分点；
在 OGB-Arxiv 上分别低 2.46 与 4.56 个百分点。
结合三种编码的定义可知，BFS 输入未显式包含边或邻接关系 token，
因此模型主要基于节点集合及其访问顺序进行分类，
而难以直接利用连通关系模式作为分类证据；
相应地，其准确率低于包含边关系信息的两类方法。

3）在相同结构预算下，欧拉路径编码相较邻域采样获得额外增益。
在 Cora 与 OGB-Arxiv 上，
欧拉路径分别达到 89.97\% 与 76.12\%，
相较邻域采样提升 1.41 与 2.10 个百分点。
由于两者在实验中采用相同的子图采样预算与序列长度上限，
该差值对应于结构输入表达方式的差异：
邻域采样在固定长度预算下对邻域进行限量采样，
从而仅覆盖部分边关系；
欧拉路径在子图尺度覆盖其诱导边集，并以可重构的序列形式提供连通信息。
因此，在统一评测配置下，欧拉路径编码在两数据集上均体现出更高的节点分类准确率。


\subsubsection{欧拉路径图表征机制的关键参数消融实验}
\label{subsec:ablation_parameters}

在前节对比不同图到序列编码策略的基础上，
本节进一步分析欧拉路径序列化内部关键配置对节点分类性能的影响。
欧拉路径序列化涉及两个直接影响输入 token 组成与长度预算的因素：
{序列构建格式（Sequence Format）}与{节点重索引机制（Node Re-indexing）}。
本文在保持模型主干与训练配置不变的条件下，
通过受控实验分别消融上述因素在 OGB-Arxiv 节点分类任务上的贡献。

\textbf{(1)序列构建格式：属性注入与长度预算的权衡}

在固定的子图采样预算与最大结构序列长度上限下，
不同的属性附着策略会改变结构输入中拓扑 token 和属性 token 的比例，
从而影响模型可利用的分类证据类型。
参考 GraphGPT\cite{Zhao2023GraphGPTGP}工作中的序列化设计思想，
本文对比了三种序列化变体：
\begin{itemize}
    \item {紧凑模式 (Short Format)}：仅保留欧拉路径上的节点索引序列
    （$v_0 \to v_1 \to \dots$），不显式包含边类型或节点/边属性 token，序列长度最短（$L \approx |E|$）。
    \item {冗余模式 (Long Format)}：在路径的每一步显式插入边类型 Token，
    并重复目标节点索引以增强注意力机制的定位能力，序列长度约为紧凑模式的 2 倍。
    \item {全属性模式 (Prolonged Format)}：本章默认采用的模式。
    在每一步跳转中，不仅包含节点和边索引，还完整嵌入了离散化的边属性与节点特征 Token。
    虽然序列长度最长（$L \approx k|E|$），但保留了最完整的图语义。
\end{itemize}

表 \ref{tab:ablation_format} 展示了不同序列格式在 OGB-Arxiv 数据集上的性能对比，
采用Accuracy \%为测评指标，
其中加粗表示最佳结果，下划线表示次优结果。

该结果说明，当结构 token 中显式提供边类型与节点/边属性线索时，
模型能够在节点分类训练中利用更多与类别判别相关的输入证据；
同时，Prolonged 格式的收益发生在更长的结构序列预算下，
反映了“属性注入量”与“上下文长度”之间的实际权衡。

\textbf{(2)节点重索引机制的鲁棒性分析}

图的节点排列在定义上不应影响其结构语义。
然而，在图到序列映射中若将节点编号作为离散 token 输入，
不同的编号分配可能引入与任务无关的绝对数值模式。
为降低模型对特定编号方案的依赖，
本文消融 GraphGPT\cite{Zhao2023GraphGPTGP} 中采用的循环重索引策略。
具体包含以下消融方案：
\begin{itemize}
    \item {静态索引 (Static)}：按照节点在欧拉路径中首次出现的顺序从 0 开始固定编号。
    \item {循环索引 (Cyclic)}：在训练过程中，对节点索引施加随机循环偏移 $\pi_r(v) = (\pi(v) + r) \pmod N$，作为一种动态的数据增强手段。
\end{itemize}

该提升表明：对序列化输入中的绝对编号进行随机平移扰动，
可在训练过程中弱化编号选择带来的偶然相关性，
从而使模型更侧重于由相对连通关系与属性线索所决定的判别信息。

\subsection{跨模态对齐优化的对比和消融实验}
\label{sec:ablation_alignment}

为分析本文多层次跨模态对齐策略中各损失分量对表征学习的贡献，
本文设计了系统性消融实验。
在对齐预训练阶段，实验保持图结构编码器 $\mathrm{Enc}_G$ 与语言模型骨干 $\mathrm{Dec}_T$ 的结构配置不变，
仅改变训练目标的损失组合；
以仅包含全局 InfoNCE 损失 $\mathcal{L}_{\mathrm{global}}$ 的模型作为基线，
逐步引入细粒度匹配损失 $\mathcal{L}_{\mathrm{match}}$ 与生成式交叉熵损失 $\mathcal{L}_{\mathrm{gen}}$，
以刻画不同监督信号对语义对齐与结构保持的影响。

\textbf{实验设置与参数说明：} 除特殊说明外，消融实验的基础超参数配置（批次大小、优化器设置等）
与第~\ref{subsec:Experiment_setup}~节一致。
在下游任务评测阶段，为减少微调过程对骨干参数的干扰，
本文统一冻结预训练得到的 $\mathrm{Enc}_G$ 与 $\mathrm{Dec}_T$ 主干参数，
仅微调任务适配层（分类头及对齐投影层）。
优化器采用 AdamW，学习率设为 $2\times10^{-5}$，训练 5 个 epoch。
在该设置下，不同对齐策略的差异主要来自预训练阶段所学习到的表示质量差异。

\section{本章小结}
\label{sec:three_summerize}

本章围绕图基座模型在节点分类任务中的两类关键瓶颈展开：
其一为图序列化过程中由采样与线性化带来的拓扑信息缺失，
其二为图拓扑表征与文本语义表征之间的分布异构导致的对齐不足。
针对上述问题，本章从“结构保真表征”与“跨模态语义对齐”
两条主线提出并验证了相应改进。

针对图结构序列化的拓扑损耗问题，
本章引入基于（半）欧拉路径的可逆编码机制，
在子图层面通过显式记录边遍历顺序与节点复现模式，
使序列表示在同构意义下保留可重构的连边信息，从而为结构建模提供更完整的输入依据。在此基础上，本章进一步在混合图语料上开展自监督结构预训练，使图编码器获得跨图域的结构表征初始化，并作为后续跨模态对齐与下游任务的结构基座。

针对图拓扑特征与文本语义特征的对齐问题，
本章构建多层次跨模态对齐框架：
以全局 InfoNCE 对比目标作为对齐基线，
并引入子结构/Token 级匹配约束与生成式重建约束，
联合优化目标，以提升共享潜在空间中结构单元与语义片段的可对齐性与可检索性。

在 Cora、PubMed 与 OGB-Arxiv 等标准基准上的实验结果表明，集成两项改进后的完整模型在节点分类准确率上取得稳定提升；相较于仅采用全局对齐的配置，引入局部匹配与生成式约束后，下游性能增益在多数据集上呈现一致趋势。进一步的消融与检索/结构一致性分析显示：局部匹配项主要改善首位检索相关指标，而生成式约束对排序质量与邻域一致性指标带来更显著的增益，两者联合能够同时提升语义可检索性与结构一致性。

综上，本章得到的结构保真且语义可对齐的图基座模型，为后续更复杂的图推理任务提供了统一的结构输入形式与跨模态接口。下一章将在此基座之上引入强化学习范式，进一步面向复杂图推理与逻辑决策任务构造可验证奖励信号与策略优化过程，以分析模型在推理链可追溯性与决策可靠性方面的能力边界。
